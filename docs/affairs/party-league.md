## 团员教育评议

### 评议对象与周期

- **对象**：除**当年新生外**的所有在校团员（如 2025-2026 学年的评议对象是除 2026 级新生外的所有在校团员）
- **保留团籍的共产党员**：应积极参加党的组织生活，**可不参加**团员教育评议和年度团籍注册，自愿参加者不限
- **周期**：一学年一次

### 会议怎么开

一般应召开**团支部大会**。团员人数较多的支部，可先由各团小组会议评议并提出初步意见，提交支部大会研究确定。

**到会团员超过应到会团员总数的三分之二，会议方可召开。**

### 四个评议等次

| 等次 | 比例/条件 |
| --- | --- |
| **优秀团员** | **30% 左右** |
| **合格团员** | 满足基本要求 |
| **基本合格团员** | 评议年度内受过**警告、严重警告或撤销团内职务**处分，但尚未有不合格表现 |
| **不合格团员** | 有明确情形之一（见下） |

**优秀团员**需满足七项要求，包括理想信念坚定、四个意识强、践行社会主义核心价值观、遵守团章积极参加组织生活、**学习成绩良好**、工作本领过硬能发挥模范作用、**成为注册志愿者**积极参加公益活动。

**不合格团员**的五种情形：

1. 理想信念动摇，严重违反政治纪律、政治规矩和组织纪律
2. 组织意识淡漠，不能履行团员义务、不执行团的决议，**长期无故不参加团的组织生活和活动，长期拒绝参加"青年大学习"等政治学习**
3. 有违法违纪行为
4. 道德水平低下，行为失当，造成不良影响
5. 评议学期内受过**留团察看**处分且无明显改进

::: warning ⚠️ 长期不参加青年大学习 = 不合格

注意第 2 条：**长期拒绝参加"青年大学习"等政治学习**属于不合格情形。青年大学习不是可做可不做的。

:::

### 评议程序：自评 → 互评 → 综评

1. **自评**：团员个人作总结，撰写自我评价材料，围绕思想政治、工作学习等方面，突出团员身份
2. **互评**：支部大会，每人依次汇报思想总结，其他团员评议，以支部为单位投票测评
3. **综评**：支部委员会综合自评、互评、测评投票结果和日常表现，研究提出建议等次，报**学院团委批准**

结果填入《郑州航院团员教育评议登记表》，**归入团员档案**。

::: tip 💡 优秀团员是评优的门槛

每学期评选的**优秀共青团干部、优秀共青团员，一般应从上一周期评议为优秀的团员中产生**。想评上，评议这关得过。

:::

## 团员年度团籍注册

**注册时间**：于团员教育评议后**两周内**完成。

### 注册规则

| 评议等次 | 处理结果 |
| --- | --- |
| 优秀 / 合格 / 基本合格 | **给予注册**，在团员证"团籍注册"栏填写注册时间、评议等次，加盖注册印章 |
| **不合格** | **暂缓注册 3 至 6 个月** |

暂缓注册期满后：再次评议为**合格**的及时注册；**依然不合格**的按相关规定处理，**不予注册**。

### 受处分团员的注册

| 处分 | 处理 |
| --- | --- |
| 团内警告、严重警告、撤销团内职务 | 如能正常参加团的活动、按时交纳团费，**一般可予以注册** |
| **留团察看** | 察看期间**团员证由学院团委收回**；期满恢复团员权利后发还并及时注册 |
| **开除团籍** | **不再注册**，团员证由学院团委收回，并书面报校团委备案 |

### 其他要点

- **流动团员**：外出不满 6 个月的，在原团组织参加评议和注册；**6 个月以上**的，一般应将组织关系转入外出地或工作单位相应团组织
- **超龄离团**：团员年满 **28 周岁**且没有担任团内职务，应当办理离团手续。加入共产党后仍保留团籍，但**年满 28 周岁且未担任团内职务的，不再保留团籍**
- 注册后团支部要修订团员花名册，并书面报告学院团委

### 已知的关键规则

来源：[《关于开展2026-2027学年第一学期团员推优入党工作的通知》](https://tuanwei.zua.edu.cn/info/1003/5224.htm)（校团委 2026-09-15）、团员教育评议通知第六部分、第二课堂办法第四条

- **推优的前提**：对于表现突出并积极要求入党的**优秀团员**，团支部应按推荐优秀团员作入党积极分子的有关规定，及时向上级委员会推荐
- **评议等次是硬门槛**：推优条件之一为「团员教育评议等次**或最近一次先进性评价**等次为**优秀**」
- **推优比例 ≤ 团员总人数的 7%**（四舍五入），不能机械分配名额
- **候选人数 ≈ 名额的 1.5 倍**；支部大会须**到会有表决权团员超应到总数三分之二**才能开
- **当选门槛**：无记名投票，得票须**超过到会有选举权人数的二分之一**，按票数由高到低排序
- **不能参加推优的情形**：已被推荐为入党积极分子的不再重复推荐；**处分期内**不能参加
- **公示**：学院范围内集中公示，**不少于 3 个工作日**
- **第二课堂成绩单是依据之一**：校团字〔2022〕2号明确，第二课堂成绩单将作为**团员评议、推优入党**的重要依据；推优条件也明确要求「二课积分符合学院相关规定」

::: warning ⚠️ 本页不写完整入党流程

发展党员的完整流程（入党申请人 → 入党积极分子 → 发展对象 → 预备党员 → 正式党员）由**党委组织部**和各学院党委（党总支）按《中国共产党发展党员工作细则》执行，**各环节时间要求以官方文件和学院党委规定为准**。

本页不凭经验描述"大概多长时间""要交几份材料"，以免误导。请以：

- 所在**学院党委（党总支）**的具体安排
- [《团员推优入党工作流程图》](https://tuanwei.zua.edu.cn/info/1006/4999.htm)（校团委官方 PDF）

为准。

:::

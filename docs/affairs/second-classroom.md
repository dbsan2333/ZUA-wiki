# 第二课堂学分 <Badge type="tip" text="持续维护" />

**不修满毕不了业**的那 5 个学分。怎么算、去哪儿查、别等到大四才发现不够。

::: danger ⚠️ 这不是选修，是毕业要求

第二课堂成绩单制度是**学校培养方案的组成部分**。从 **2017 级本科生、2022 级专升本学生**开始，**必须修满第二课堂学分方可毕业**。

很多同学到大四才发现第二课堂学分不够，临时补会很被动。

:::

## 要修多少学分

来源：校团字〔2022〕2号 第六条、第七条

| 学生类别 | 最低第二课堂学分 | 换算成积分 |
| --- | --- | --- |
| **本科学生** | **5 学分** | **25 积分** |
| **专升本学生** | **2 学分** | 10 积分 |

**换算规则**：每 **5 个积分** = **1 个学分**。

::: warning ⚠️ 还有一个"至少三类不为零"的隐藏条件

光凑够 25 积分不够。要求在**思想引领、团学履历、实践服务、科技创新、文体活动、技能培训**六大类中，**至少有三类活动不为零分**。

也就是说，不能全靠"当观众"攒积分 —— 观众分很低（校级 0.8、院级 0.3），而且你得在至少三个不同类别里有分。

:::

### 2️⃣ 团学履历类

**当学生干部就有分**，按学年完成任期且无违规违纪失职为准。**仅担任一学期的不予加分**；**同时担任多个职位可累积加分**。

| 职务 | 积分 |
| --- | --- |
| 校级以上干部（全国或省学联任职） | **25** |
| 校级组织学生干部 · 主席团成员 | **10** |
| 校级组织学生干部 · 部门负责人/副负责人 | **6** |
| 校级组织学生干部 · 干事 | **3** |
| 院部学生干部 · 主席团成员 | **8** |
| 院部学生干部 · 部门负责人/副负责人、班长、团支书、党（团）支部委员/小组长 | **4** |
| 院部学生干部 · 干事、其他班委 | **2** |
| **优秀社团** · 会长/副会长 | **5** |
| 优秀社团 · 部长/副部长 | **3** |
| 优秀社团 · 干事/委员 | **2** |
| **良好社团** · 会长/副会长 | **4** |
| 良好社团 · 部长/副部长 | **2** |
| 良好社团 · 干事/委员 | **1** |

**申请时间**：每年 **6–7 月**在系统提交考核证明。

::: info 📌 社团分"优秀"和"良好"两档

同样是当会长，优秀社团 5 分、良好社团 4 分。社团的**年度考核评级**直接影响你的团学履历分。社团有哪些、怎么加入见[学生组织与社团](club-org)。

:::

::: warning ⚠️ 目录的 A+／A／B／C 不是上面积分表里的"国家级 A 类 / B 类"

两套口径不同、名单也不完全重合，**别看到 A+ 就直接套 25 分**，实际积分以第二课堂服务中心的认定结果为准。

## 积分怎么录入

依托**大学生第二课堂服务平台（PU 口袋校园）**实施。三种方式：

| 方式 | 适用 |
| --- | --- |
| **活动签到自动录入** | 校内组织单位组织的活动（主流方式） |
| **组织单位录入** | 同上，活动一般需在一周之内完结并发放学分 |
| **学生自主录入** | 个人荣誉证书、专业水平能力证书、职业资格证书、论文、专利、软著、社会实践等 |

**认定流程**：

- **活动类积分** → 各学院团委（团总支）认定 → 提交终审申请 → **第二课堂服务中心**审核完结发放
- **证书类荣誉** → 统一由**第二课堂服务中心**认定、发放

::: tip 💡 证书记得自己去录

比赛获奖、考了证，**不会自动进系统**。属于"学生自主录入"范畴，要在 PU 口袋校园里自己提交证书。别等毕业审核才发现没分。

:::

## 预警与毕业审核

- **每年 11 月**：校团委将各学院学生第二课堂学分情况通报给各学院团委（团总支），并开展**毕业年级的第二课堂学分预警**
- **毕业资格审核时**：校团委将未达标学生信息反馈给各学院

::: warning ⚠️ 大四 11 月才知道就晚了

11 月才开始预警，毕业审核在次年 6 月。中间只有半年，而很多竞赛、实践一年才一次。**建议大一大二就开始攒**，大三上学期自查一次。

:::

## 它还有什么用

第四条写得很清楚，第二课堂成绩单将作为以下事项的**重要依据**：

- 学生**综合素质测评**
- **评奖评优**
- **团员评议**
- **推优入党**

学生毕业时，成绩单**装入学生档案**，作为求职就业的重要推荐材料。

## 监督与举报

- 学校对第二课堂各项活动进行督查与总结，**凡发现弄虚作假者，查实后严肃处理并通报全校**
- 举报电话：**0371-61912650**（校团委）

## 规划建议：按学年倒排

**大一上**：先把**零门槛**的拿满 —— 借书攒分、当观众（校级 0.8）、进 1 个社团当干事，团学履历类就算起分了。

**大一下到大二**：参加学科竞赛、争取暑期社会实践（校级 **6 分**）、社团竞聘部长。这几件事一年就一次，错过要等一年。

**大三上**：**必须自查一次** —— 算清够不够 25 分，六大类里是否已有三类不为零，缺哪类补哪类。

**大三大四**：考证（六级/计算机/普通话，单项最高 **15 分**），争取省级以上奖项。

::: tip 💡 最容易翻车的三种情况

1. **只当观众**：一次 0.3–0.8 分，要刷三十多场才够 25 分，而且凑不出"三类不为零"
2. **只在一类里堆**：科技创新拿了 20 分，其他两类全零 → 依然不达标
3. **证书不自己录**：考完就忘，毕业审核时系统里查无此证

:::

# 请假与留校 <Badge type="tip" text="2026年10月更新" />

请假的审批权限、销假与续假、旷课怎么算、休学复学与寒暑假留校。

来源：[《郑州航空工业管理学院本科生学籍管理规定（修订）》校教字〔2024〕44号](https://jwc.zua.edu.cn/info/1199/6468.htm)（2026-04-16 发布，自 2024 级起执行）、[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)（2025-06-24）

::: warning ⚠️ 特别提醒

校教字〔2024〕44号**从 2024 级学生开始执行**。2023 级及更高年级适用校教字〔2022〕51号，两版在个别条款上有差异。本页写的是 44 号文。

具体审批以**你所在学院的实际要求**为准 —— 很多学院有自己的线上请假系统和额外规定。

:::

## 请假：谁能批多久

来源：校教字〔2024〕44号 第十六条

| 请假时长 | 审批 |
| --- | --- |
| **3 日以内** | **辅导员批准** |
| **3 日以上、2 周以内** | 辅导员**审核**，报**学院研究批准** |

::: warning ⚠️ 事假最长两周

**事假不得超过两周。** 超过两周的不叫请假了，得走**休学**手续。

:::

### 病假 vs 事假

- **病假**：应当有**校医院或者县级以上医院诊断书**
- **事假**：应当写出**书面申请**

::: tip 💡 病假条去哪儿开

校医院就能开诊断书，不用专门跑大医院。体温 38 度以上或者确实起不来床，去[校医院](../health/hospital)挂个号。

:::

## 销假与续假

来源：校教字〔2024〕44号 第十六条（二）

- **请假期满**，应当**及时向辅导员销假**，并报学院备案
- **需要续假**的，手续与请假**完全相同**（不是口头说一声就行）
- 续假批准与否，**应回复学生本人** —— 没收到回复就默认没批，别想当然

::: warning ⚠️ 不销假 = 旷课

请假到期不销假、又不续假，剩下的天数全部按**旷课**处理。很多人栽在这：以为请了三天就万事大吉，第四天没回来也没说，结果三天变旷课。

:::

## 旷课怎么算

来源：校教字〔2024〕44号 第十四、十五条

| 情形 | 折算 |
| --- | --- |
| 迟到、早退 **5 次** | 折算为旷课 **1 学时** |
| 理论授课时间旷课 1 天 | 按**实际授课学时**计 |
| 学校统一组织的活动（劳动）旷课 1 天 | 按 **4 学时**计 |
| 未请假/请假未准而不参加学习、考核或统一活动 | 一律按**旷课** |

**处分门槛**：一学期内旷课累计 **10 学时以内** → 批评教育；**达到或超过 10 学时** → 按学校违纪处分相关规定给予**相应处分**。

::: danger ⚠️ 10 学时是红线

10 学时大概就是两三天的课。**一学期旷课满 10 学时就要给处分了**，别以为是小事。而且处分会影响学位授予 —— 详见[毕业与学位](../future/graduation)。

:::

**考勤范围**不只是上课：理论课、实验、上机、实习、参观、劳动、军训、时事政治教育和思想品德教育**都算**。老师会不定期抽点名。

## 请假累计太多的后果

来源：校教字〔2024〕44号 第十六条（三）、第二十四条

| 累计情况 | 后果 |
| --- | --- |
| 一学期请病、事假累计**超过 1 个月** | 应报**教务处备案** |
| 累计超过本学期总学时**三分之一或六周（含）以上** | 应当办理**休学**，否则按**旷课**处理 |

::: warning ⚠️ 别小看这条

请假超过六周就得休学。如果你因为实习、生病等原因需要长期离校，**主动去办休学**，别硬扛着不办 —— 不办的话后面全算旷课，直接往退学走。

:::

另外，**未经请假、请假未获批准擅自离校或请假逾期返校**，按第十四、十五、三十六、三十八条处理 —— 最重可到**退学**。

## 擅自离校的终极后果

来源：校教字〔2024〕44号 第三十六条（四）

**未经批准连续两周未参加学校规定的教学活动的，应予退学处理。**

这不是吓唬人，是真的会退学。有事情离校一定走请假流程。

## 休学与复学

### 什么情况应当/可以休学

**应当**办理休学（第二十四条）：

1. 因伤、病经学校指定的**二级甲等以上医院**诊断，须停课治疗、休养时间占一学期总学时**三分之一或六周（含）以上**
2. 一学期请假（含病、事假）时间超过该学期总学时三分之一或六周（含）以上
3. 学期报到、注册后**无正当事由不选修课程**
4. 学校认为应当休学的

**可以**申请休学（第二十五条）：

1. 在最长学习年限内因特殊原因及困难需暂时中断学业
2. **创业**
3. **自愿申请**休学

::: info 📌 创业休学有特殊优惠

**休学创业的学生，可连续申请休学 2 年**，且**休学时间不计算在最长学习年限内**。这是明确的政策鼓励。

普通休学则是：以 **1 年**为期，在校期间累计**不得超过 2 年**，且计入学习年限。

:::

### 时间限制与办理

| 项目 | 规定 |
| --- | --- |
| 休学期限 | 以 **1 年**为期，累计不超过 **2 年** |
| 续休 | 须在休学期满**前 2 周内**办理 |
| 申请时机 | 只能在**春、秋季学期正常教学周内**申请，**考试周原则上不受理** |
| 办理方式 | 通过**教务管理系统**上传提交书面申请书和证明材料 |
| 离校 | 批准后**一周内**办完离校手续，**不得在校内留住** |

::: warning ⚠️ 休学期间不能上课

学生休学期间**不得来校上课**，**自行来校上课所取得的成绩一律无效**。学校保留学籍，但不享受在校生待遇，休学期间发生的事故学校也不负责。

:::

### 复学

来源：校教字〔2024〕44号 第二十九条

- 应当于学期开学**两周内**向所在学院提出复学申请 —— **注意是两周内，不是随时**
- 通过**教务管理系统**提交复学申请和证明材料
- 因伤、病休学的，须由学校指定的**二级甲等以上医院**诊断证明确已恢复健康，并经**校医院确认**
- 参军退役复学持**退役证明**
- **休学到期两周内无故不办理复学手续的，取消复学资格，按退学处理**

::: tip 💡 复学窗口很短

开学**两周内**，过了就没了。休学的同学务必在开学前就联系学院，别等开学后才想起来。

:::

**取消复学资格的情形**：休学期间有严重违法违纪行为；复查不合格；**伪造诊断证明**。

### 参军保留学籍

在校学生应征参加中国人民解放军（含武警），学校保留其学籍**至退役后 2 年**，**服役时间不计入学习年限**。

入伍新生则保留入学资格，退役 **2 年内**可办理入学手续（校教字〔2024〕44号 第六条）。

## 寒暑假留校

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)

::: info 📌 官方原文

后勤指南《学生宿舍住宿相关管理规定》第 3 条写得很直接：

> **寒暑假期原则上不安排学生住宿**，如有特殊情况者，需办理相关手续。

:::

也就是说，**假期留校不是默认选项，需要申请**。

::: warning ⚠️ 本页不编流程

后勤指南只说了"需办理相关手续"，**没有公布统一的线上申请入口或表格名称**。各学院、各年份的留校申请方式不一样（有的学院在钉钉/学工系统，有的交纸质表），本页不做推测。

**正确做法**：放假前 2–3 周问**辅导员或学院学工办**，他们会发本学院的通知。同时留意：

- [党委学生工作部](https://xsc.zua.edu.cn/)
- 班级群通知
- 宿舍楼公告栏

:::

留校期间要注意：

- 宿舍 **6:00 开门、23:00 关门**（周五周六及节日推迟 30 分钟）—— 假期通常也执行
- 热水供应时段不变：早 06:00–08:00、中 11:30–13:30、晚 16:00–23:30
- **寒暑假期间热水根据学校安排供水**，可能缩减
- 食堂假期开放窗口会减少，以[食堂指南](../life/canteen)和现场公告为准

## 校外住宿

如果你考虑在校外租房，这条必须看。来源：后勤指南《学生宿舍住宿相关管理规定》第 4 条：

::: danger ⚠️ 校外住宿要审批

学校要求学生在校内住宿。确有困难需校外住宿的，须：

1. 出具有关证明，**个人写出书面申请**
2. 填写《**郑州航院学生校外住宿审批表**》
3. **家长（监护人）提供身份证复印件两份**（一份附于书面承诺上，另一份粘贴在审批表上）和联系方式
4. 由所在院（系、部）**党总支签署意见**
5. 经**学生宿舍管理委员会**集体研究批准
6. 在规定时间内统一办理校外住宿手续

**每次申请校外住宿期限最长为一年。** 除特殊情况外，学生宿舍管理委员会**每年 10 月集中研究审批**。学生在校外住宿发生的相关问题，**责任自负**。

:::

延长学制学生申请校外住宿：于当年延长学制名单确认后向所在院（系、部）申请，以院（系、部）为单位统一报学生宿舍管理委员会，委员会于**当年毕业生离校前**集中审批，**超出规定期限不予办理**。

## 军训期间外出

军训期间离校需填写[军训期间学生外出请假条](https://bwc.zua.edu.cn/info/1096/3684.htm)（保卫处），按流程审批。

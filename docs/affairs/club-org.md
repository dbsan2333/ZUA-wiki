# 学生组织与社团 <Badge type="tip" text="持续维护" />

学生会、社团、学社联，以及**怎么找到现在还在活动的社团**。

**第二课堂学分单独成页** —— 那是毕业硬要求，规则细节多，别在这里翻：👉 **[第二课堂学分](second-classroom)**。

::: warning ⚠️ 本页不列完整社团名单

社团**每年注册、年审、增减**，名单变得很快。学校也未公开发布完整名录，网上流传的"总数"互相打架（见下文）。所以本页只收录**有官方出处、且标注了日期**的社团名称，作为"大概长什么样"的样本，**不当名录用**。

想看当下真实有效的名单：开学后**社团招新现场**、[校团委官网](https://tuanwei.zua.edu.cn/)、或问**学生社团联合会**。

:::

## 先分清三类组织

| 类型 | 归谁管 | 特点 |
| --- | --- | --- |
| **学生社团** | 校团委指导，**学生社团联合会**（学社联）统筹 | 按兴趣成立，人数不定，活动由社团自己安排 |
| **学生组织** | 校团委 | 学生会、青年志愿者协会、红十字会等，有固定岗位和任期 |
| **院级团学组织** | 各学院团委（团总支） | 院学生会、院青协、班级团支部 |

::: info 📌 学社联是什么

**学生社团联合会**是校团委指导下的校级学生组织，**社团招新活动就是它承办**的。找社团、问社团注册，第一站就是它。

:::

## 招新什么时候

::: warning ⚠️ 两类组织招新时间不一样，别搞混

这是最容易搞错的一点。**学生组织**和**社团**不是一回事，招新时间也不同：

| 类别 | 招新时间 | 说明 |
| --- | --- | --- |
| **校级学生组织**（学生会、青协、红十字会等） | **开学后 9–10 月** | 面向大一招新，一般有面试 |
| **社团集中招新**（"百团大战"） | **3 月下旬** | 全校各社团集中亮相，大一下学期开学后 |
| **实验室、科创团队** | 时间不固定 | 部分学期中或春季补招 |

社团集中招新有官方报道可查：**2026 年 3 月 25–26 日**举办年度社团招新，"全校各社团集中亮相"，同步举行**百团大"绽"青春启"航"嘉年华主题晚会**（[学校新闻网 2026-03-29](https://news.zua.edu.cn/info/1011/9907.htm)）。

所以**别只盯着开学那两周** —— 学生组织那波在秋天，社团集中纳新在**第二年 3 月**。秋季是否有额外场次，官方未见报道，**以当年团委通知为准**。

:::

::: tip 💡 大一新生最容易踩的坑

刚开学那几天**到宿舍推销、拉群、"帮你办卡"的人，多半不是学生组织**。真正的学生组织不会上门收钱、不会让你在走廊扫码登记身份证。辨认方法见[开学防坑](../community/faq-antifraud)。

:::

## 怎么找到你要的那个社团

| 途径 | 靠不靠谱 |
| --- | --- |
| **招新摊位挨个问**（3 月下旬） | 最准，当场能确认**还在不在**、招不招 |
| **问辅导员 / 班级群 / 学院团委** | 靠谱 |
| **[校团委官网](https://tuanwei.zua.edu.cn/) 通知公告** | 通知以这里为准，但不含社团名录 |
| 群聊（QQ 搜索、贴吧、小红书） | **谨慎**——大量是营销、卖卡、中介建的假群，见[社团与部门招新群](../community/clubs-groups) |

::: tip 💡 为什么站内坚持不列名单

写一个"社团 + QQ 群号"的静态表，**每学期都会烂掉**：社团注销了群还在、群主换人了、改名了。与其给一张必然过时的表，不如给一条稳定的找法：**去招新现场，或问学社联**。

:::

## 加几个合适

1. **1–2 个足矣**。大一下学期课程密度会陡增，社团多了直接影响绩点和精力
2. **想学技术**：找实验室、科创类（数学建模协会、机器人科创实验室、软件开发协会、众创家园）
3. **想锻炼组织与文书能力**：学生会、青协
4. **纯兴趣**：文艺、体育类社团，压力最小
5. **有升学/求职打算**：优先能出竞赛成绩的（挑战杯、互联网+、建模）—— 第二课堂积分与复试履历都吃这个

::: info 📌 想清楚"为了什么加"

当干部能拿**团学履历类积分**、办比赛能拿**科技创新类积分**，但这些只是副产品；**只为攒分加社团，通常坚持不到第二年**。积分规则见[第二课堂学分](second-classroom)。

:::

## 常见疑问

**Q：加入社团要交会费吗？**
A：各校社团情况不一，本页无官方统一口径。**收钱的一律先问清去向、要收据**，对不上就找校团委 **0371-61912650** 核实。

**Q：一个社团能加几个部门？**
A：按社团自己的章程，通常**申报时选一个**，能否兼报看招新现场说明。

**Q：中途想退可以吧？**
A：可以，直接跟负责人说。但要留意：如果冲着**团学履历类积分**去的，**仅担任一学期不予加分**（见[第二课堂学分](second-classroom)）。

**Q：想自己创建一个社团？**
A：属新社团成立审批事项，走校团委/学社联。本页未检索到公开的设立流程与材料清单，**不凭经验描述**，直接问校团委 **0371-61912650**。

**Q：社团活动算第二课堂分吗？**
A：算，但按**社团自己的加分细则**执行；**社团授课不加分**。见[第二课堂学分](second-classroom)。

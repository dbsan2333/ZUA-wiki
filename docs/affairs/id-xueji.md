学生证怎么办、丢了怎么补、学信网学籍怎么确认——办证件类的看这页。

::: warning ⚠️ 特别提醒

本页流程来自[教务处学籍科](https://jwc.zua.edu.cn/jgsz/xjgk.htm)官方通知，具体以教务处当年通知为准！

## 学生证

来源：[《关于办理2026级新生学生证的通知》](https://jwc.zua.edu.cn/info/1155/6827.htm)（学籍科 2026-10-09 发布）

### 新生办理

每年 10 月上旬统一办理，**费用由学校承担，不收学生一分钱**。三步走：

1. **填登记表**：填《新生学生证信息登记表》，重点核对**火车乘车区间**
2. **填学生证**：领空白证后本人用黑色签字笔填写，学院审核
3. **盖章**：以班级学院为单位统一盖钢印、校章、注册章

::: tip 💡 填写防翻车指南

官方原话：「因不看说明随意填写而导致学生证无法正常使用的，或者影响乘火车的，由学生本人负责」。

- **不能涂改**——建议先用铅笔填，确认无误再擦掉用签字笔重写
- 一寸**蓝底**彩照自己贴
- 班级填 8 位班级代码；学制：四年制本科填「4」、专升本和二学位填「2」
- 发证日期统一「2026年10月」、入学时间统一「2026年9月」

:::

### 乘车区间怎么填

这是最容易填错、错了对乘火车优惠影响最大的地方：

- 「火车终点站」填**回家最方便的火车站**，必须与家庭所在地匹配（家庭住址审核依据是高考生源地址）
- 站名严格按学校发的《火车站标准站名字典》写，**不带「站」字**；不能填机场、汽车站
- 家在郑州市区就填「郑州」，登封就填「登封」——不坐火车回家的填家庭所在城市名
- 家附近没有火车站可以跨省填邻近大站（如张家口填北京、广西梧州填广州），**不需要证明材料**
- 父母长期在外地打工想填工作地的，需要**居住证/户籍证明/单位证明**三者之一
- **严禁随便填北京上海广州**，查出来不予盖章

### 补办

学生证遗失、破损需补办（换发），**要缴工本费**（初次办理学校出钱，补办自己掏）。

来源：[《关于2026年9月补办学生证的通知》](https://jwc.zua.edu.cn/info/1155/6761.htm)（学籍科 2026-09-05）

### 补办流程（以2026年9月为例）

1. **网上报名**（9月5日12:00–9月8日12:00）：登录教务系统申请补办，**过期系统关闭**
2. **填乘车信息**：网上报名时同时填写家庭所在地和乘车区间（用于学生证打印，过期填写无效）
3. **两级审核**（9月8–9日）：辅导员审家庭所在地与乘车区间 → 学院教学办终审
4. **缴费**：学院统一收工本费
5. **打印盖章**：学院打印 → 学校盖公章 → 学院盖注册章
6. **领取**：教务系统状态变「已发放」后，到学院教学办领，**领时检查注册章盖没盖**

::: danger ⚠️ 这几条会直接作废

- 教务系统里**没有在校照片**的不允许补办（按作废处理）——先去补拍在校照片
- 家庭所在地**不能带"省""市""县"字**（如填「河南郑州」不填「河南省郑州市」），否则打印错乱、补办作废
- 火车站名严格按《火车站标准站名字典》写、不带"站"字，乱填一律作废
- 网上报名**过期不候**，每学期开学初留意通知

:::

::: warning ⚠️ 补办不发火车票优惠卡磁条

自 2023 年秋季学期起不再统一购买/补发火车票优惠卡（磁条）。买学生票走**铁路 12306 学生优惠资质线上核验**：在 12306 客户端学生专区填写与学生证一致的乘车区间，系统与学信网比对通过即可购学生票（一个优惠年度 = 每年10月1日至次年9月30日）。旧磁条卡仍可继续用。详见[《关于2026年9月补办学生证的通知》](https://jwc.zua.edu.cn/info/1155/6761.htm)第 1 条（2）、[《关于进一步便利普通全日制本专科生购买优惠火车票的通知》](https://jwc.zua.edu.cn/info/1155/5138.htm)。

:::

## 教务系统在校照片

来源：[《教务系统上传照片要求》](https://jwc.zua.edu.cn/info/1156/4433.htm)（学籍管理科）

教务系统照片用于**所有校内考试、四六级、办学生证，甚至毕业证学位证辅助照片**。

- **蓝底**、素颜、脱帽摘镜、露耳朵、刘海不遮眉、不戴美瞳饰品、不修图
- 尺寸 **480×640px**、**.jpg**、以**学号命名**、**10–40KB**
- 禁止手机自拍、生活照、艺术照、翻拍、水印

::: danger ⚠️ 一旦审核通过不允许更换

不按要求上传 → 考试成绩无效、学生证无法使用、**影响毕业证学位证**，后果自负。补办学生证的前提也是系统里有合规在校照片（没照片不予补办）。

:::

## 学信网学籍确认

来源：[《关于做好2026级新生学信网确认学籍信息的通知》](https://jwc.zua.edu.cn/info/1180/6823.htm)（学籍科 2026-09-30 发布）

每年秋季学校组织新生**学信网确认学籍信息**，核对姓名、电子照片、院校名称、专业名称、性别、民族、出生日期、身份证号。2026 级为 **9月30日–10月14日**，学校 **10月15日**导出未确认名单，各学院一对一帮扶确保 100% 确认。

::: danger ⚠️ 必须本人确认

若本人未及时查询核对、或发现信息错误未及时上报，将导致注册错误的信息不能更改、漏注册的学籍不能注册，**可能影响毕业证书发放**。几分钟的事，务必认真做。

三种情况要及时报学院：① 查不到自己学籍 ② 学籍状态不是「在籍（注册学籍）」 ③ 学籍信息有误。详见[新生入学须知](../enroll/starting)。

:::

## 学籍异动（休学、复学、退学等）

依据《郑州航空工业管理学院本科生学籍管理规定（修订）》（校教字〔2024〕44号）和教育部令第41号。每学期开学初教务处发通知集中办理（2026年秋季学期通知发布于 9月6日）。

来源：[《关于做好2026-2027-1学期学籍异动工作的通知》](https://jwc.zua.edu.cn/info/1155/6764.htm)

| 类型 | 办理方式 |
| --- | --- |
| **复学、休学、保留学籍** | 线上办理：[线上学籍异动办理指南](https://jwc.zua.edu.cn/info/1156/4103.htm) |
| **退学、转学** | 线下办理：[线下学籍异动办理指南](https://jwc.zua.edu.cn/info/1156/4130.htm) |

::: danger ⚠️ 这些红线碰不得

- **复学仅限开学后 2 周内申请**，过期不办
- **休学期满不复学的，直接退学处理**（学籍管理规定第三十六条第2款）
- **未经批准连续两周未参加教学活动的，退学处理**（第三十六条第4款）——别不办手续就离校！
- 附件材料必须**原件扫描成清晰 PDF** 上传（个人申请、家长知情同意书、入伍通知书/病例单等），模糊歪斜审核不通过
- 办理期间要**跟进流程直到审核结束**，否则影响选课、成绩查询、毕业，后果自负

:::

::: tip 💡 参军入伍的同学

入伍要办**保留学籍**手续——有学生入伍了却没办手续，学校还要专门排查这种异常学籍。退役复学按时间节点办，特殊情况提前通过学院教学办与学籍科沟通。转专业也属学籍异动范畴，流程见[转专业](../study/changing-majors)。

:::

学籍异动生效后，**及时对照新培养方案检查选课**（见[选课指南](../study/select-course)），复学、转专业学生可在第三轮选课补修。

## 户口与身份证

- **户口迁移**：自愿原则，按录取通知书里的说明办理，具体咨询学校保卫处或辖区派出所
- **身份证补办**：离学校最近的补办点是**博学路便民服务中心**（郑东新区博学路派出所辖区，龙子湖高校区身份证业务都在这里办），异地身份证补办带上户口页或原身份证信息即可；或趁假期回户籍地办。考试、报销都要用身份证，别等到过期
- 身份证临期的同学建议**开学前就换好**——学信网确认、医保参保、考试都用得上

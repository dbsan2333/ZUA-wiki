## 就业信息网能干什么

[郑州航院就业信息网](https://zhjyb.zua.edu.cn/) 是学校就业信息发布的主阵地（『工作啦』平台），分学生、用人单位、教师三种登录身份。主要栏目：

| 栏目 | 内容 |
| --- | --- |
| **通知公告** | 招聘活动、补贴申领、求职指导通知 |
| **招聘信息** | 企业岗位发布 |
| **宣讲会 / 双选会 / 空中宣讲会** | 线下线上招聘活动日程 |
| **实习资讯** | 实习岗位 |
| **就业日历** | 活动日程视图 |
| **办事流程** | 网签、档案转递等操作指南 |
| **就业简报** | 学校就业工作简报 |

::: tip 💡 有学生端小程序

就业信息网提供**学生端就业小程序**（页面下方有二维码），也有服务号。手机上刷宣讲会比开电脑方便。

:::

## 校招活动长什么样

从就业信息网实际发布的内容看，郑航的招聘活动主要有三类：

### 🎤 宣讲会

企业进校专场，通常在**东校区**各场地举行。例如 2026 年 10 月有京东、安踏、中石化河南油建、贵州安吉航空精密铸造等专场。

### 🤝 双选会

多企业集中招聘，规模最大的一类。场地包括：

- **图书馆北侧广场**（东校区）
- **中心广场**（东校区）
- **东体育馆**（东校区）

2026 年 10 月就有"豫荐未来 青春启航"河南省高校毕业生就业市场**航空航天类分市场**周五双选会、**中国航空工业集团郑州航院专场招聘会**、2026 年秋季校园双选会等。

::: info 📌 航空航天类分市场在郑航

河南省高校毕业生就业市场**航空航天类分市场**设在郑州航院，这是学校的行业优势 —— **航空航天类企业会专门来郑航招人**。航空工业、中国航发、商飞、南航、海航、厦航等都在就业信息网的用人单位列表中。

:::

### 💻 空中宣讲会 / 网络双选会

线上进行，也有录播回看。

上面这些指南是**图文操作手册**，本页不复述具体点击路径 —— 平台界面会改，复述反而误导。**签约前直接打开对应指南照着做**，或咨询 0371-61912535。

::: danger ⚠️ 三方协议不是儿戏

三方协议（毕业生、用人单位、学校）具有**法律效力**，违约可能涉及违约金。**签字前务必**：

- 看清薪资构成（税前/税后、底薪+绩效+补贴各多少）
- 确认工作地点、岗位、试用期时长
- 问清五险一金缴纳基数和比例
- 看清违约金条款
- 有疑问就问就业办 0371-61912535，别怕麻烦

:::

- [毕业生档案转递填写操作指南——电脑端](https://zhjyb.zua.edu.cn/module/newsdetail/id-140131/nid-6110)（2025-02-21）

就业信息网还有[学生档案邮寄信息查询](https://zzhy.goworkla.cn/module/archives_query/nid-1242)入口。

::: warning ⚠️ 档案别自己拿

档案必须通过**机要通道**转递，个人不能保管、更不能拆封。暂存到期学校会安排邮寄（就业网有相关通知）。**档案在自己手里超过一定期限会变成"死档"**，影响考公、落户、退休。

:::

## 求职创业补贴

来源：[就业信息网通知公告](https://zhjyb.zua.edu.cn/module/newslist/id-2153/nid-6109)

学校每年组织**一次性求职创业补贴**申领，会发布通知和通过人员名单公示。例如：

- 《关于做好 2027 届毕业生一次性求职补贴申领发放工作的通知》（2026-07-16）
- 《2027 届毕业生求职创业补贴申请通过人员名单公示》（2026-08-28）

::: tip 💡 符合条件的别错过

这类补贴通常面向困难毕业生群体，**名额有限、需主动申请**。留意大四上学期的[就业网通知](https://zhjyb.zua.edu.cn/module/newslist/id-2153/nid-6109)和辅导员转发，看到就赶紧交材料。

具体条件、金额以当年通知为准，本页不编。

:::

就业网列出的：智联招聘、前程无忧、BOSS 直聘、应届生求职网、天基人才网、中原人才网、国聘网、中华英才网、猎聘类站点等。

::: danger ⚠️ 求职也是诈骗高发区

**凡是要求先交钱（培训费、服装费、押金、体检费代收）的"招聘"，一律是诈骗。**

其他注意：要求提供银行卡密码/验证码、扣押身份证原件、"高薪轻松"明显不合理、公司地址在居民楼或酒店。

详见[电信诈骗与防骗](../health/antifraud)。

:::

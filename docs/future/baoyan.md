郑航有没有推免资格、怎么确认、没有推免时该怎么办。

::: danger ⚠️ 本页最重要的结论

**到2026年10月为准郑州航空工业管理学院还没有获得具有"推荐优秀应届本科毕业生免试攻读硕士学位研究生"（推免）资格。**

## 为什么"没推免"

推免资格不是学校自己说了算的，需要**教育部批准**，而且**有推免资格的高校都会高调宣传**—— 招生章程、招生简章里一定会写"我校接收推免生""具有推免资格"，并公布推免办法和名额。

郑航 2027 年招生章程的"报考条件"部分只列了四类学业水平条件（应届本科、已毕业、同等学力、已获硕博），**通篇走全国统考通道**，没有推免入口。这与学校 2013 年才获批硕士学位授予单位的办学层次是吻合的。

## 如果目标是"免试读研"

还有几条路，但**都不是学校层面的保研**，条件各不相同，本页只列方向、不编细节：

| 途径 | 说明 |
| --- | --- |
| **支教团/西部计划等专项** | 部分高校有研究生支教团推免专项，通常要求学校本身具备推免资格，**郑航是否可参加本页无依据** |
| **参军入伍** | 退役大学生士兵可报考"退役大学生士兵计划"，郑航 2027 年在 4 个专业领域招生，详见[考研全流程](kaoyan#退役大学生士兵计划) |
| **硕师计划、辅导员专项** | 同样依赖推免资格，本页无依据 |
| **直博 / 本硕博连读** | 郑航目前无博士点，2025 年获批河南省博士学位授予**重点立项培育单位**，尚未成为博士学位授予单位 |

## 不管走哪条路，这些是通用的

想在推免或考研复试里占优，本科期间能提前准备的东西是一样的：

**成绩是地基**。郑航的学位授予要求课程平均学分绩点 **≥ 2.0**（详见[毕业与学位](graduation)），但想有竞争力，得往 3.0 以上走。

**第二课堂是硬要求也是加分项**。[第二课堂成绩单](../affairs/second-classroom)要修满本科 **5 学分**（25 积分），且**六大类中至少三类不为零**。它同时是综合素质测评、评奖评优、团员评议、推优入党的重要依据。

::: tip 💡 值钱的积分来源

- **发明专利**第一作者 **25 积分**（= 5 学分，直接拉满）
- **发表论文**：中文核心第一作者 **25 积分**，一般期刊第一作者 15 积分
- **国家级 A 类竞赛**三等奖及以上 **25 积分**
- **英语六级 / 计算机四级 / 普通话一级甲等**各 **15 积分**
- **入伍参军、西部计划**各 **25 积分**

完整积分表见[第二课堂学分](../affairs/second-classroom)。

:::

**绩点、竞赛、科研、英语**这四项，无论保研还是考研复试都是核心筹码。大一就开始攒，别等大三。

## 本科期间怎么准备

不管最终走不走推免，这些准备对考研复试同样有用。

### 绩点是地基

郑航学位授予要求课程平均学分绩点 **≥ 2.0**（详见[毕业与学位](graduation)），但想有竞争力，得往 **3.0 以上**走。考研复试时，本科成绩单是必交材料，导师会看。

### 英语要早过

- **四级 425 分**是毕业门槛（部分学院要求更高）
- **六级 425 分**才能报考，复试时导师会问
- 雅思 6.5 / 托福 90 以上在复试里是加分项

详见[考证与竞赛](certificates)的免修对照表。

### 竞赛和科研是硬通货

第二课堂科技创新类积分最高的几项：

| 项目 | 积分 |
|---|---|
| **发明专利**第一作者 | **25** |
| **中文核心论文**第一作者 | **25** |
| **国家级 A 类竞赛**三等奖及以上 | **25** |
| 国家级 B 类竞赛一等奖 | **25** |
| 省级竞赛一等奖 | **20** |

完整积分表见[第二课堂学分](../affairs/second-classroom)。

### 第二课堂别落下

本科须修满 **5 学分（25 积分）**，且**六大类中至少三类不为零**。它同时是评奖评优、推优入党的依据——这些又是推免的参考材料。

### 参军入伍也是一条路

退役大学生士兵可报考"退役大学生士兵计划"，郑航 2027 年在 **4 个专业领域**招生（机械、新一代电子信息技术、图书情报、电气工程）。详见[考研全流程](kaoyan#退役大学生士兵计划)。

## 常见误区

::: danger ⚠️ 别等大四才想这事

推免/考研的准备从**大一**就开始了。绩点是四年累积的平均值，大一挂科会一直拖后腿。竞赛、论文、专利也需要时间周期，大三才开始准备来不及。

:::

::: warning ⚠️ "保研"和"考研"不是二选一

郑航学生读研的主渠道是**全国统考**（考研）。即使未来获得推免资格，推免也只是免去初试，复试仍然要参加。两条路不是互斥的——很多同学同时准备考研，给自己留后路。

:::

## 为什么要考证：第二课堂学分

这是最实际的一点。郑航**第二课堂成绩单是毕业要求**，本科生须修满 **5 学分（25 积分）**，且六大类中**至少三类不为零**。而**技能培训类**就是靠证书拿分。

来源：[第二课堂积分评定参照表](https://tuanwei.zua.edu.cn/info/1004/2616.htm)

| 证书 | 等级 | **二课积分** |
| --- | --- | --- |
| **外语** | 六级、专八、雅思 6 分以上、托福 90 以上 | **15** |
| 外语 | 四级、专四 | **10** |
| **计算机** | 四级 | **15** |
| 计算机 | 三级 | **10** |
| 计算机 | 二级 | **8** |
| **普通话证** | 一级甲等 | **15** |
| 普通话证 | 一级乙等 | **8** |
| 普通话证 | 二级甲等 | **5** |
| 普通话证 | 二级乙等 | **2** |
| **国家职业资格**（教师资格证、造价员、会计证等） | 与专业相关 | **10** |

::: tip 💡 两个 15 分就能凑够一半

英语六级 **15 分** + 计算机四级 **15 分** = 30 积分 = **6 学分**，直接超过本科 5 学分的要求。当然还需要满足"至少三类不为零"。

反过来，**线上获得的任何类型证书一律不认定**（第二课堂办法第十八条）。花钱买的网课证书没用。

:::

::: details 📄 查看《第二课堂成绩单制度实施办法（修订）》（校团字〔2022〕2号）原文

校团委官方 PDF（16 页），含六类积分评定参照表和《创新创业类竞赛分类》附件（国家级 A 类 9 项、B 类 31 项全清单在附件 2 第 13–15 页）。

::: danger ⚠️ 国家职业资格证书需与专业相关

技能培训类明确要求：**国家职业资格考试的证书需与专业相关**。跨专业的证书（比如工科生考会计证）可能不予认定，建议先在 PU 口袋校园提交时咨询。

## 英语四六级

### 与学业直接挂钩

来源：[郑州航院普通本专科学生大学英语、计算机类、体育课程免修实施细则（教发〔2024〕21号）](https://jwc.zua.edu.cn/info/1199/5386.htm)

四六级成绩不只是加分，还能**免修大学英语课程**：

| 考试 | 成绩 | 可免修 | 认定成绩 |
| --- | --- | --- | --- |
| **四级** | 631 及以上 | 英(三) / 英(四) | **95 / 90** |
| 四级 | 611–630 | 英(三) / 英(四) | 90 / 85 |
| 四级 | 581–610 | 英(三) / 英(四) | 85 / 80 |
| 四级 | **550–580** | 英(三) / 英(四) | **80 / 75** |
| **六级** | 581 及以上 | 英(四) | **95** |
| 六级 | 561–580 | 英(四) | 90 |
| 六级 | 541–560 | 英(四) | 85 |
| 六级 | 520–540 | 英(四) | 80 |
| **托福** | 100 及以上 | 英(四) | 95 |
| 托福 | 95–99 | 英(三) | 90 |
| 托福 | 90–94 | 英(二) | 85 |
| 托福 | 85–89 | 英(一) | 80 |
| **雅思** | 6.5 及以上 | 英(四) | 95 |
| **计算机** | 优秀 / 良好 / 合格 | 计算机课程 | 95 / 85 / 75 |

::: warning ⚠️ 免修的门槛是四级 550

注意：现行教发〔2024〕21号要求**四级 550 分**才够免修门槛。**此前 2021 年旧版（教发〔2021〕30号）门槛更低（四级 480），但已被明确废止**，别再按旧标准算。

:::

**六级报考门槛**：四级达到 **425 分**才能报考六级。

完整免修规则、申请时间（每学期开学 **4 周内**）、一份成绩只能免一门等限制，详见[考试与成绩](../study/exam-score)。

## 计算机等级考试

除了第二课堂加分，计算机等级考试成绩可用于**免修计算机类课程**（优秀 95 / 良好 85 / 合格 75，见上表）。

具体等级对应关系以免修细则原文为准，详见[考试与成绩](../study/exam-score)。

## 普通话、教资等

- **普通话证**：一级甲等 15 分最高，师范类、想当老师的同学值得考到一乙以上
- **教师资格证**：属"国家职业资格考试"，**与专业相关**的认定 10 分
- 其他与专业相关的国家职业资格证书（造价员、会计证等）同样 10 分

::: info 📌 本页不编考试时间

普通话、教资、计算机等级等考试由各自主管部门组织，**报名时间和频次每年不同**。本页不推测，请以：

- [教务处教务通知](https://jwc.zua.edu.cn/jwgl/jwtz.htm)（四六级、计算机）
- 各考试官方网站（教资：中小学教师资格考试网；普通话：各地语委）为准。

:::

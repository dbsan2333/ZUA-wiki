## 郑航研究生招生规模

2027 年共有 **16 个学院**招生，覆盖：

- **8 个一级学科**（学术学位）
- **19 个专业学位类别**
- 设置了 **55 个二级学科和专业领域**

学校拥有 2 个省特色骨干学科群、1 个省特需急需特色骨干学科群、15 个省重点学科；**材料科学、工程学 2 个学科进入 ESI 全球排名前 1%**。

::: warning ⚠️ 招生计划数仅供参考

章程明确：2027 年招生计划尚未下达，**研招网及章程中的拟招收计划数仅供参考**，实际招生人数将根据 2027 年国家最终下达计划和报考情况**动态调整，可能增加也可能减少**。

具体各专业招生人数见[附件 1：2027 年硕士研究生招生专业目录](https://yjsc.zua.edu.cn/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=1596054530&wbfileid=12403600)。

:::

## 报考条件

### 基本条件

1. 拥护中国共产党的领导，遵守宪法和法律，**诚实守信**
2. 身体健康状况符合国家和学校规定的体检要求
3. 学业水平符合下列之一：

| 类别 | 条件 |
| --- | --- |
| 应届本科毕业生 | 含普通高校、成人高校、成人高等学历教育应届生，及自考和网络教育**届时可毕业**本科生 |
| 已毕业 | 具有国家承认的本科毕业学历 |
| **同等学力** | 高职（专科）毕业满 **2 年及以上**（到录取当年 9 月 1 日前），或本科结业生，且符合学校具体学业要求 |
| 已获硕博 | 已获硕士、博士研究生学历或学位 |

::: danger ⚠️ 两条红线

- 因违反国家教育考试规定被**暂停参加国家教育考试**且在停考期内的，**不得报考**
- 学校对**考试作弊受处罚情况**认真核查，诚信状况是思想品德考核的重要内容和**录取的重要依据**，贯穿初试、复试、调剂、录取、新生复查**各环节**

发现伪造、变造证件的，**立即向公安机关报案**。

:::

### 特殊专业要求

**工商管理、公共管理、工程管理**专业学位，须满足：

- 本科毕业后有 **3 年以上**工作经验；**或**
- 高职（专科）毕业或本科结业后达到同等学力并有 **5 年以上**工作经验；**或**
- 已获硕士、博士学历或学位后有 **2 年以上**工作经验

### 退役大学生士兵计划

- 须为**高校学生应征入伍退出现役者**
- 复试前须提供《**入伍批准书**》和《**退出现役证**》（限士兵）复核
- **2027 年在 4 个专业领域招生**：机械（航空宇航学院）、新一代电子信息技术（电子信息学院）、图书情报（信息管理学院）、电气工程（自动化学院）
- ⚠️ 报考该计划的考生，**不再享受初试加分、少数民族照顾政策**
- 一志愿进入复试要求：初试单科和总分达到 **A 类考生**基本要求

## 报名注意事项

来源：章程第四部分

1. 登录**中国研究生招生信息网**（[yz.chsi.com.cn](https://yz.chsi.com.cn)）报名
2. 如实填写信息、提供真实材料，签署《**考生诚信考试承诺书**》
3. 按时提交补充材料（要求由各省级教育招生考试机构确定公布），**逾期不得补办**
4. **在读研究生**（含报考定向就业类型）报考须在报名前**征得所在培养单位同意**
5. 改过姓名、身份证号的，**务必使用变更后的信息报名**；如学历（学籍）校验不通过，尽快联系学校（0371-61912520）
6. 学习方式均为**全日制**，就业方式分"**定向就业**"和"**非定向就业**"，**慎重填报**
7. 残疾考生如需合理考试便利，报名阶段就与省级招生考试机构和学校沟通申请

::: warning ⚠️ 信息填错后果自负

章程原话：**考生因报名信息填写错误、填报虚假信息而造成不能考试（含初试、复试）或录取的，后果由考生本人承担。**

提交前逐项核对，特别是姓名、身份证号、学历学籍、报考点、定向/非定向。

:::

## 复试与录取

来源：章程第六部分

| 事项 | 规定 |
| --- | --- |
| 同等学力考生 | 复试中须**加试至少两门**与报考专业相关的本科主干课程，**笔试** |
| 跨学科专业复试 | **不加试** |
| 思想政治理论考试 | **工商管理、会计、图书情报、工程管理、审计** 5 个专业学位复试中组织，**成绩计入复试总成绩** |
| 外语听力及口语 | 在复试中进行，学校组织，**成绩计入复试总成绩** |
| **破格复试** | **我校不开展** |
| 再次复试 | 如有必要，学校可对考生再次复试 |
| 思想政治素质和品德考核 | **不合格的坚决不予录取** |
| 入学前未取得本科毕业证书 | **录取资格无效** |
| 体检 | 拟录取后组织 |
| 档案 | 拟录取后，**全日制非定向就业**考生须将个人档案和组织关系**调入学校统一管理** |

学校复试工作办法、调剂工作办法，各学院实施细则**预计于复试前陆续公布**，关注[研究生处网站](https://yjsc.zua.edu.cn/zsgz.htm)。

## 学制与学费

来源：章程第七、八部分

### 学制

| 类别 | 学制 |
| --- | --- |
| 学术学位硕士 | **3 年** |
| 翻译、工商管理、公共管理专业学位 | **2 年** |
| **其他专业学位硕士** | **3 年** |

学习方式**均为全日制**，全脱产学习，均安排住宿。

### 培养校区

研究生培养及住宿分布在**龙子湖校区和航空港校区**。具体培养校区、住宿地点以学校最终统一部署为准。

### 学费

章程未直接列出金额，指向[《郑州航空工业管理学院收费公示》](https://cwc.zua.edu.cn/info/1104/2718.htm)。**本页不猜数字，以财务处公示为准。**

### 奖助政策

奖助类型包含：**国家奖学金、国家助学金、学业奖学金、"三助"（助学、助研、助管）补助、国家助学贷款、临时困难补助**等；部分学院设有**专项奖学金**资助符合条件的新生。

详情见[研究生处奖助文件](https://yjsc.zua.edu.cn/info/1090/5019.htm)。

## 考外校：通用流程

::: info 📌 郑航作为考点

学校研究生处设有[考点工作](https://yjsc.zua.edu.cn/zsgz/kdgz.htm)栏目，每年发布报考点相关安排。

**郑航应届生能否在本校考点考试，以当年报考点公告为准**，本页不做推测。

:::

无论考哪里，全国统考流程一致：

1. **确定目标**：学校、专业、学硕/专硕
2. **9 月**：研招网公布招生简章、专业目录、考试大纲
3. **9 月下旬**：预报名
4. **10 月**：正式报名（[中国研究生招生信息网](https://yz.chsi.com.cn/)）
5. **11 月**：网上确认 / 现场确认（按报考点要求）
6. **12 月中下旬**：初试
7. **次年 2–3 月**：查分、国家线公布
8. **3–4 月**：复试、调剂（[调剂服务系统](https://yz.chsi.com.cn/)）
9. **6 月**：录取通知书

::: tip 💡 复试和调剂看这里

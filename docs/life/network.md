# 校园网络 <Badge type="tip" text="持续维护" />

校园网、机房账号、WebVPN、校园卡、

::: tip 💡 先看结论

**校园网和校园卡是两回事**，都可以不办。所有校内资源都能用 **webvpn** 在校外访问，不开校园网不影响正常学习生活。

:::

## 校园网 vs 校园卡

这是新生最容易混淆的一点：

| | 校园网 | 校园卡（电话卡） |
| --- | --- | --- |
| 运营方 | 学校信息管理中心 | 中国移动 / 联通 / 电信 |
| 是什么 | **校内 WiFi 热点** | 普通手机卡 + 套餐 |
| 关系 | 可单独购买，价格稍贵 | 套餐可加 10 元/月开通校园网 |
| 不办的影响 | 无 | 无 |

来源：[信息管理中心](http://xxglzx.zua.edu.cn/)、郑航贴吧迎新群答疑整理。

## 校园网

- **覆盖**：校园内 WiFi 热点
- **特点**：限速不限量
- **开通方式**：
  - 已办校园卡：套餐 **+10 元/月**即可开通
  - 单独购买：价格稍贵
- **试用**：开学第一周通常可试用

::: info 📌 需要校园网吗？

**不需要。** 学校仅部分校内资源限制访问，而这些都能通过 [webvpn](https://webvpn.zua.edu.cn/) 访问。流量够用的话不必开校园网。

:::

## 机房上网账号

在机房上课用的上网账号**和校园网没关系**，所有人都能使用，无需额外开通。

## **WebVPN**

[WebVPN资源访问系统](https://webvpn.zua.edu.cn/)

校外访问校内资源的正规通道，**不需要校园网**：

- 图书馆电子资源（知网、万方等数据库）
- 教务系统
- 其他仅校内可访问的系统

::: tip 💡 建议

在校外查文献、登教务系统，直接用 WebVPN。登录账号通常为学号/统一身份认证，与[智慧门户](https://sfrz.zua.edu.cn/)一致。

:::

## 校园卡避坑

::: danger ⚠️ 开学别急着办卡

开学那几天是办卡高峰，各种抢人头、文字游戏。**建议等人少了、了解清楚了再决定。**

常见套路：

1. **把活动优惠算进月租** —— 三家套餐本身月租基本一致（早年 39 元/月，近年约 49 元/月），各家用叠活动让实付变低。**活动不在套餐内，到期可能要换卡。**
2. **预存话术** —— "预存 xx 元，每月扣 10 元，多少月扣清"。把预存的钱也算进月租，显得月费很低，实际是自己提前消费。
3. **中介让利** —— 部分中介拿提成后让利充进你话费，属于一次性，别当成长期优惠。

**办卡前必问**：
- 什么套餐？原本月资费多少？
- 活动什么时候到期？到期后要不要换卡？
- 承诺的优惠能否兑现、找谁兑现？

**记住**：只要是能开校园网的校园卡套餐，月租就是统一价，其他低价要么是叠活动、要么是文字游戏。

:::

以上经验来自郑航贴吧迎新群学长姐分享（[开学防坑](../community/faq-antifraud)有更多）。

## 一个容易被忽略的硬理由：宿舍门锁

前面说"校园卡可以完全不办"，这句话没有错。但**在决定办哪家之前**，有一条官方规定值得知道：

> **确认是否为联通校园卡，如果是，可到联通营业厅进行绑定。若非联通校园卡，则无法绑定门禁开门。**

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)"宿舍智能门锁使用指南"

::: info 📌 这意味着什么

- 想**用手机 NFC 开宿舍门**（不用掏门卡），前提是持有**联通校园卡**
- 指南同时写明：**2025 级新生使用联通校园卡可以开智能门锁**
- **这不影响你上课、选课、吃饭、进图书馆** —— 只影响"手机能不能当宿舍门卡"这一件事

:::

::: warning ⚠️ 但别被这条话术反向推销

这条是**已核实的事实**，不是"必须办联通卡"的理由。没有联通校园卡，你**照样有门卡开门、照样能进门**。如果推销员拿这条当"不办就进不了宿舍"来吓你，那是**夸大**——门卡是入学时按宿舍规定开通的，跟手机绑定是两回事。

:::

### 门锁和门卡的常见故障（官方问答）

来源：《后勤服务指南》智能门锁常见问题。这些**都归联通营业厅管**，跟校园网、校园卡套餐是两个窗口：

| 问题 | 官方答法 |
| --- | --- |
| **补办门卡** | 工作时间到**后勤楼一楼联通营业厅**补办 |
| 刷卡"滴滴"报警 | 2023 级：营业厅**重新授权**；2024 级：营业厅**填报修表** |
| **门锁没电** | 2023 级：门外锁下有充电口可自行充电，**门内侧端电池盖向上推也能充（建议用内侧端）**；2024 级：营业厅填报修表，有人上门修 |
| **手机开锁失效** | 打开手机 NFC，**支付方式改为 SIM 卡支付**即可 |

**报修**：王闯 **15516920410**；办公时间 周一至周五 **10:00–21:00**；地点 **后勤楼一楼联通营业厅**。

宿舍门锁的更多细节（6:00 开门、人脸门禁、押金）见[宿舍](hostel)。

## 校园卡用不用办：一张决策表

| 你的情况 | 建议 |
| --- | --- |
| 手机流量本来就够用 | **不用办**，也不用开校园网 |
| 想让手机能开宿舍门 | 需要**联通校园卡**（见上） |
| 需要在宿舍用 WiFi 大流量下载 | 考虑开校园网，或用**随身 WiFi / 手机热点** |
| 只想访问校内系统（教务、图书馆数据库） | **不用办**，[webvpn](https://webvpn.zua.edu.cn/) 全搞定 |
| 家里已办过同运营商副卡 | 先对比资费再决定，**别重复消费** |

::: tip 💡 最省钱的路径

**一卡通（入学统一发，必办）+ webvpn（免费）+ 自己原有的手机卡**。这条组合走完，四年都不用为"校园网/校园卡"多掏钱，唯一放弃的是手机开宿舍门。

:::

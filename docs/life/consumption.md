# 日常消费 <Badge type="tip" text="持续维护" />

在校园中，主要的消费场景为在食堂、商业街、商店的消费和洗澡热水、饮用水消费。

其中，食堂和校医院等场所只允许使用统一的卡机，因此需要使用一卡通或完美校园APP（可绑定支付宝或微信）支付。饮用水机可以使用支付宝扫码或者刷水卡使用。

## 一卡通

[一卡通](https://xxglzx.zua.edu.cn/info/1220/1645.htm)与[完美校园APP](https://app.59wanmei.com/new/index.html)同源，是每个人校内唯一的消费账户。

除了消费场景，一卡通载有学生信息，还作为学生的凭证，可以刷~~学校大门、宿舍~~、图书馆等场所的门禁。（学校大门和宿舍的门禁现已改为人脸识别，图书馆门禁仍需使用一卡通）。期末考试时一卡通可代替学生证（以考试时具体要求为准）。

![alt text](/img/docs/life/consumption/本科生一卡通.png)

*本科生一卡通*

一卡通与完美校园的绑定、使用、充值、挂失等操作，详见：

- [信息管理中心：校园一卡通使用说明](https://xxglzx.zua.edu.cn/info/1220/2673.htm)
- [信息管理中心：校园一卡通常见问题解答](https://xxglzx.zua.edu.cn/info/1220/3202.htm)

一卡通由学校信息管理中心负责，如有问题可以在工作日工作时间前往`02A104`[信息管理中心](https://xxglzx.zua.edu.cn/)咨询。

::: info 📌 电话有两个，别搞混

- **一卡通相关业务**：**0371-61912710**（信息管理中心《校园一卡通使用说明》文末给的联系方式）
- **信息管理中心总机**：**0371-61912718**，邮箱 xxglzx#zua.edu.cn，地点 `02A104`

:::

::: info 💡 NFC拷贝

目前大部分手机都支持NFC拷贝功能。由于一卡通是加密卡，NFC拷贝仅能复制卡号，因此在消费场景下无法使用。但对于门禁场景，如图书馆门禁可以正常使用。

:::

## 领卡与身份认证

来源：[信息管理中心《校园一卡通使用说明》](https://xxglzx.zua.edu.cn/info/1220/2673.htm)（2022-08-26 发布）

| 步骤 | 怎么做 |
| --- | --- |
| **领实体卡** | **新生入学报到时，到所在学院安排地点领取** |
| **装 APP** | 安卓应用市场 /苹果 App Store 搜索安装「**完美校园**」APP |
| **身份认证** | 支付宝「完美校园」小程序，或微信「完美校园」公众号，认证并绑定一卡通 |
| **认证后能干嘛** | 直接用**支付宝首页"付钱/收钱"、微信"收付款"的二维码**在校内商超、餐厅 POS 机消费 |

官方还单独给了[认证步骤页面](https://xxglzx.zua.edu.cn/info/1013/2968.htm)，跟着点就行。

::: tip 💡 融合支付：认证前后差别很大

| 状态 | 支持的支付方式 |
| --- | --- |
| **已认证绑定个人信息**（推荐） | 实体卡、完美校园**虚拟卡**、**支付宝校园卡**、**微信校园卡** |
| 未绑定信息（不推荐） | **只支持**实体卡、完美校园虚拟卡 |

**开学第一件事就是做身份认证**——不然卡丢了手机上也刷不了，食堂排队还得掏实体卡。

:::

## 充值：官方给了四种方式

来源：《校园一卡通使用说明》

| 方式 | 路径 |
| --- | --- |
| **① 支付宝** | 支付宝「完美校园」小程序 → 点击「充值」→ 选金额 → 付款 |
| **② 微信** | 微信「完美校园」公众号 → 点击「充值」→ 选金额 → 付款 |
| **③ APP** | 完美校园 APP → 「充值」→ 金额 → 付款 |
| **④ 圈存机** | 每次圈存须输入**建行银行卡密码**和**校园卡密码**，严格按屏幕提示操作 |

::: warning ⚠️ 圈存机上这两个坑，官方特意提醒

1. **校园卡密码默认为身份证后六位**
2. **圈存过程中，在提示换卡之前，勿将卡片移出读卡区** —— 提前拿卡是圈存失败的头号原因

:::

### 圈存失败了，钱去哪了：自助领款

圈存中途失败，钱会卡在设备上。官方流程：

```
校园卡放圈存机读卡区 → 校园卡服务 → 「自助领款」 → 提示领款金额 → 领款成功
```

::: tip 💡 别慌，钱没丢

遇到"扣了银行卡的钱、校园卡却没到账"，**先按上面路径自助领款**，多数情况当场就能拿回来。搞不定再找 02A104 或拨 61912710。

:::

## 挂失与补办

| 事项 | 怎么办 |
| --- | --- |
| **挂失**（方式一） | 完美校园 APP →「我的」→ 校园卡 → **卡挂失** → 输入密码 |
| **挂失**（方式二） | 圈存机 → 校卡服务 → **校卡挂失**，按提示操作直至显示"**挂失成功**" |
| **解挂** | 携带**身份证原件和校园卡**到 `02A104` 信息管理中心办理 |
| **补办** | 携本人身份证到 **`02` 实验楼 A 座一楼大厅自助补卡机**办理；或带**身份证原件**到 `02A104` 信息管理中心办理 |

::: danger ⚠️ 发现丢了立刻挂失

一卡通是**校内唯一消费账户**，余额就在里面。**APP 挂失最快，不用出门**——先挂失，再决定要不要补办。

补办要**本人带身份证**，两条路（自助补卡机 / 02A104），别找同学代办。

:::

## 密码与余额

| 事项 | 说明 |
| --- | --- |
| **消费初始密码** | **身份证后六位**；**身份证最后一位是 X 则输入 0** |
| **改密码**（方式一） | 完美校园 APP →「我的」→ 我的校园卡 → 修改密码 → 原密码一次、新密码两次 |
| **改密码**（方式二） | 圈存机 → 校园卡服务 → 修改密码 |
| **忘了原密码** | 携带**有效身份证和一卡通**到信息管理中心修改 |
| **查余额** | ① 食堂刷卡时放到刷卡机即可查看 ② 圈存机 → 校园卡服务 → 余额查询 ③ 完美校园 APP |

::: tip 💡 X 结尾的同学记住这点

身份证末位是 **X** 的，密码里那一位**填 `0`**，不是填 X。每年都有人在这儿反复输错。

:::

## 饮用水

学校宿舍、教学楼、实验楼、图书馆、办公楼等场所都安装有饮用水机，提供净化过的直饮冷水和热水。

使用支付宝扫码饮水机上的二维码或者NFC碰一碰，弹出小程序即可使用。也可以去后勤服务大厅免费办理实体水卡，刷卡使用。

但这里更推荐直接绑定一卡通或NFC，一是减少卡片数量，~~二是扫码小程序会有烦人的广告~~。

::: details 💡 一卡通/NFC绑定饮水机教程

饮水机饮水使用的支付宝小程序的账号扣款，但该小程序可以绑定“云卡”，本质是将卡片的ID（并非学号）与你的支付宝小程序账号相绑定。当放上卡片时，机器读取ID，系统将自动从对应的账户扣款（前提是支付宝对该小程序授权了免密支付）。

**操作步骤：**

将一卡通（或其他卡片）放置在饮水机上的IC卡区域，机器上将显示一串数字并提示“无效卡”，该串数字即为`卡片ID`。

![将卡片放在饮水机上](/img/docs/life/consumption/将卡片放在饮水机上.jpg)

*将卡片放在饮水机上*

登录支付宝小程序，进入“我的”-“云卡”-“添加云卡”，选择“添加”-“添加云卡”，输入`卡片ID`，并完成添加。

![小程序选择云卡](/img/docs/life/consumption/小程序选择云卡.jpg)

*小程序选择云卡*

绑定成功后即可直接使用该卡刷卡用水。同时**建议设置每日限额，以防卡片丢失后被盗刷损失过多**。

![绑定云卡](/img/docs/life/consumption/绑定云卡.jpg)

*绑定云卡*

如果想要使用手机NFC刷卡饮水，手机复制该卡片即可。

:::

## 食堂

龙子湖校区有`东苑`和`西苑`2个食堂，其中东苑2楼有`民族餐厅`，提供清真饭菜。另外东苑、西苑三楼均有包间或教师餐厅。不同的餐厅由不同的公司承包。

食堂窗口消费统一使用卡机，只能刷一卡通或完美校园或绑定完美校园的支付宝/微信扫二维码。窗口价格不贵，品种多样，可自行选择，一日三餐日均消费20~30左右。

当在食堂中遇到问题，可以当场向餐厅经理寻求帮助，或向学校官方[伙管会](https://mp.weixin.qq.com/s/T6YyfIU_E7Vah4a_QR_G6A)（官方学生组织）反映。

## 其他商业体

除食堂外，学校还有“商业街”、超市、药店、水果店、干洗店、打印店等，宿舍楼附近也有小商店。这些不限制使用卡机，可自由支付。

### 商业街

位于学校南门口。2024年初开业，由原洗浴中心改造而来，属于综合商业体，共2层。

一楼主要为餐饮小吃，有肯德基、瑞幸、蜜雪冰城等众多品牌入住。二楼除餐饮外，还有台球厅、打印店、考研机构、理发店、“郑航映像”文创店等。

### 超市

学校南门有校内最大的超市。部分宿舍楼附近也有小商店。

### 理发店

校内有3家理发店：西苑餐厅东边2号宿舍楼下、东苑餐厅北边8号宿舍楼下、商业街2楼。

# 食堂指南 <Badge type="tip" text="持续维护" />

龙子湖校区（东校区）有 **东苑餐厅** 和 **西苑餐厅** 两个餐厅，都是三层，另有**民族餐厅**和**教工餐厅**。不同的餐厅由不同的公司承包。

## 营业时间

| 餐厅 | 供餐时间 |
| --- | --- |
| 东苑餐厅 | 7:00 – 22:00 |
| 西苑餐厅 | 7:00 – 22:00 |
| 民族餐厅 | 7:00 – 22:00 |
| 教工餐厅 | 11:30 – 13:00 |

## 楼层分布

### 东苑餐厅

- **二层有民族餐厅**，提供清真饭菜
- 三层为包间或教师餐厅

### 西苑餐厅

- 三层为包间或教师餐厅
- 2018 年曾做**航空主题**布置（见[学校新闻网报道](https://news.zua.edu.cn/info/1034/3901.htm)）

## 支付方式

食堂窗口消费**统一使用卡机**，只能刷一卡通、完美校园 APP，或绑定完美校园的支付宝/微信二维码。

| 方式 | 说明 |
| --- | --- |
| **一卡通** | 校园卡，主要支付方式 |
| **完美校园 APP** | 可绑定支付宝/微信，扫码支付 |

::: tip 💡 一卡通怎么办
见[日常消费](../life/consumption)。食堂和校医院等场所只允许统一卡机，需一卡通或完美校园 APP。
:::

窗口价格不贵、品种多样，一日三餐日均消费 **20~30 元**左右。

## 吃出问题怎么办

| 情况 | 怎么办 |
| --- | --- |
| 就餐意见、建议 | 找**当层餐厅负责人**，或打餐饮监督投诉电话 |
| 吃出异物 | 当场找餐厅经理，或拨打监督电话 |
| 其他问题 | 向学校[伙管会](https://mp.weixin.qq.com/s/T6YyfIU_E7Vah4a_QR_G6A)反映 |

**餐饮监督及投诉**：0371-61912811（东苑餐厅四楼）

各层负责人手机号见[常用部门与电话](../quick/phones)。

## 就餐建议

1. **错峰就餐**。下课高峰排队久，早 10 分钟或少 10 分钟差别很大
2. **注意卫生**。选择看起来干净的窗口，肠胃敏感慎吃生冷
3. **军训期间**。人多且热，提前去

## 收件地址怎么填

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm) 收发室章节

官方给出的标准收件格式：

```
河南省郑州市郑东新区文苑西路15号 郑州航院龙子湖校区
+ XX院系 + XX班级 + 姓名 + 电话
```

::: warning ⚠️ 别只写"郑州航院"

学校有**两个校区**，快递只按地址分拣。只写校名不写校区，**很可能被送到大学路校区**。

## 取件与寄件的一般建议

这些是通行经验，不是学校规定：

- **及时取件**。驿站包裹通常有免费保管期（7天），超期限可能被退回
- **大件/重物**（行李、家电）看清驿站是否代收，有些快递放快递柜、有些放驿站
- **生鲜**尽快取，坏了驿站不赔
- **退货**先在平台下单，再按驿站要求交寄，保留单号
- **毕业季/开学季**包裹量暴增，避开高峰时段

::: tip 💡 开学前别太早寄

新生**录取后才确定宿舍**，太早寄到驿站会堆很久。建议报到前 3–5 天寄，或人到了再寄。

:::

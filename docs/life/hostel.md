## 宿舍环境

龙子湖校区宿舍主要为6人间，其次有少量4人间。宿舍楼配有卫生间、洗澡间、洗衣机、洗鞋机、直饮水机等，宿舍内有暖气和空调。

六人间均为4上下铺+2上铺+2桌子。每层楼有公共卫生间和洗澡间。

### 六人间 vs 四人间

| 对比项 | 六人间 | 四人间 |
| --- | --- | --- |
| 床位形式 | 4 上下铺 + 2 上铺 | 4 个**上床下桌** |
| 桌子 | 2 张（共用） | 每人 1 张 |
| 卫生间 | 楼层公共 | **独立卫生间**（无独浴） |
| 洗澡 | 楼层公共洗澡间 | 楼层公共洗澡间 |
| 主要分布 | 大多数宿舍楼 | `10`~`13` 号楼为主 |
| 空调租赁费（4 年制） | **273.5 元/人** | **410 元/人** |

费用口径来自[洗浴与洗衣](bath-laundry)的空调租赁表——**四人间摊到每个人头上更贵**，但独卫和上床下桌确实舒服很多。

::: tip 💡 想住四人间，得靠抢

床位是**网上选床**决定的，先到先得。想挑到四人间或好床位，报到前盯紧[智慧迎新系统](https://yx.zua.edu.cn/)公布的选床开放时间，见[开学前必做](../enroll/freshman-before)。

:::

## 入住第一天：公物要点清、责任书要签

来源：《后勤服务指南》"公物管理"

学生入住时，**要与公寓管理员当面点清宿舍内所有公有财产，签定《学生宿舍公有财产使用管理责任书》**。

::: danger ⚠️ 这一步别嫌麻烦

入住当天没点清、没拍照，**退房时被认定是你弄坏的，就得照价赔偿或自付修理费、材料费**。建议当场把家具、门窗、锁具、窗帘轨道的已有破损指给管理员看，自己再拍几张照片存着。

自然损坏的家具和室内设施，及时报告**宿舍服务部**维修；未经公寓管理员同意，**不擅自搬动、调换**公寓里的家具设备。

:::

## 门禁与作息

来源：《后勤服务指南》"宿舍智能门锁使用指南"

学校全面实施**公寓人脸识别系统**，二级学院、辅导员、研究生处及学生处**有权限进行门禁查询，了解学生出入公寓楼情况**。

| 项目 | 时间 |
| --- | --- |
| 宿舍开门 | **6:00** |
| 宿舍关门 | **23:00**（周五、周六、节日推迟 30 分钟） |
| 宿舍供电 | **6:00 – 23:00**（周五、周六顺延 30 分钟，**节日全天供电**） |
| 寒暑假 | 根据实际情况另行安排 |

::: warning ⚠️ 你的出入记录是能被查到的

封闭管理 + 人脸门禁，意味着**几点进几点出都有记录**，辅导员和学院随时能查。别抱侥幸心理翻门、晚归代打卡，被查出来很难解释。

真要晚归，**提前跟辅导员说明**，别等出事了再补。寒暑假留校需要办理手续，见[请假与留校](../affairs/leave-stay)。

:::

## 宿舍智能门锁

从2023级开始，宿舍均配有智能门锁，需在入学时支付押金开通智能门锁卡，等效于钥匙，刷卡开锁。联通校园卡用户可使用手机NFC开门（需要手机有NFC功能）。

截至《后勤服务指南》发布时，**2023级、2024级学生房间已安装智能门锁，剩余房间逐步分批更换**；**2025级新生使用联通校园卡可以开智能门锁**。

### 门卡与门锁的问题怎么办

来源：《后勤服务指南》智能门锁常见问题

| 问题 | 怎么办 |
| --- | --- |
| **门卡要补办** | 工作时间到**后勤楼一楼联通营业厅**补办 |
| 刷卡时"滴滴"报警 | 2023 级门禁卡失效 → 营业厅重新授权；2024 级门锁不能用 → 营业厅填报修表 |
| **门锁没电** | 2023 级：门外锁下面有充电口可自行充电，门内侧端电池盖向上推也能充（**建议用内侧端**）；2024 级：营业厅填报修表，有人上门修 |
| **手机开锁失效** | 打开手机 NFC，**支付方式改为 SIM 卡支付**即可 |
| 手机怎么绑门禁 | 确认是**联通校园卡**才能到营业厅绑定；**非联通校园卡无法绑定**开门 |

**报修**：王闯 **15516920410**；办公时间 周一至周五 **10:00–21:00**；地点 **后勤楼一楼联通营业厅**。不满意可找后勤管理处质量监督科 **0371-61913110**。

::: tip 💡 手机能开门，但别只靠手机

**只有联通校园卡用户能绑定门禁**，没办校园卡就只能用门卡。所以门卡**别丢**——丢了得跑营业厅补办，赶时间很麻烦。

:::

## 宿舍里有什么、没什么

| 有 | 没有（自己准备） |
| --- | --- |
| 床、桌子、柜子、门窗窗帘 | 床上用品（被褥、床单、枕头、蚊帐） |
| 暖气、空调（需租赁开通） | 洗漱用品、盆、衣架 |
| 楼层公共卫生间、洗澡间 | 台灯、排插 |
| 洗衣房（每层 2 台洗衣机）、洗鞋机 | 吹风机（**宿舍内违禁**，楼道有公用） |
| 直饮水机（宿舍楼每层 5 台） | 暖壶、晾衣杆 |

床的常见尺寸是 **1.9m × 0.9m**，买床垫、蚊帐前先量一下实际床位。

## 住宿纪律：官方明文禁止的这些

来源：《后勤服务指南》"住宿纪律"。违反者情况较轻给予**通报批评**，情节严重者按学校规定**给予处分**。

| 别做 | 说明 |
| --- | --- |
| **男女生互串宿舍** | 明文禁止 |
| **私自留宿非本寝室人员** | 包括同学、朋友、亲戚 |
| 上课时间在宿舍睡觉 | 自觉遵守作息制度 |
| 大声喧哗、高声放音响、拍球踢球 | 保持公寓安静 |
| 在公寓内打麻将、赌博、迷信活动 | 禁止 |
| **私拉乱扯电源线、电话线、网线** | 用电安全红线 |
| **存放、使用违规电器** | 「住宿纪律」列明：电炉、微波炉、电磁炉、热得快、电饭锅、电热杯、电吹风、洗衣机等 |
| 使用燃炉具、在宿舍生火点蜡烛 | 煤油炉、酒精炉、燃气炉、燃煤炉等 |
| 把饭菜、酒精类饮品带进公寓区 | 禁止 |
| **在宿舍内吸烟** | 禁止 |
| **在宿舍喂养宠物** | 包括仓鼠 |
| 向窗外和楼道扔杂物、泼水 | 禁止 |
| **在公寓内推销、贩卖等经商活动** | 未经许可不得张贴、散发宣传品和广告 |
| 存放、携带易燃易爆剧毒品和管制刀具 | 禁止 |
| 私自调整住宿 | 学生、管理人员都不得私自调整 |

::: warning ⚠️ 关于"洗衣机"别理解错

住宿纪律的违规电器清单里带了**洗衣机、电吹风**，指的是**别自己往宿舍搬一台用**——学校本来就在**每栋楼每层配了 2 台公用洗衣机**、楼道配了公用吹风机。所以不是"学校不让洗衣服/吹头发"，而是"用楼里的公用设备，别在房间私接大功率电器"。

处分口径看下一段。

:::

::: warning ⚠️ 违规电器的处分很重

在宿舍使用违规电器（**电热水壶、电热锅、电吹风、卷发棒等**）或私自改变室内电压电路：视情节给予**警告以上处分**；**拒不承认的，宿舍全体成员一起受处分**；造成火险**记过以上**；造成火灾事故**开除学籍**并赔偿全部损失，涉及法律责任的移交司法机关。违禁电器一经发现**予以没收**。

特殊情况（如医疗设备用电）可向学院**申请专项用电许可**。买插排、台灯认准 **3C 认证**。学校有**免费开水房**和**公用吹风机（0.2 元/分钟）**，没必要冒险。详见[校园安全](../health/safety)、[洗浴与洗衣](bath-laundry)。

:::

::: tip 💡 "不许推销"这条对新生也适用

开学那几天到宿舍卖电话卡、卖化妆品、"帮忙看行李"的，很多就是利用你不熟悉环境。**公寓内禁止经商**，正规渠道在校园卡和运营商营业厅，见[开学防坑](../community/faq-antifraud)。

:::

## 内务与查寝

来源：《后勤服务指南》"内务规定"

- 地面、窗台、桌面无杂物；门窗、墙壁、天花板无灰尘、无蜘蛛网、无脚印、无污迹
- **被子、枕头摆放整齐统一，鞋整齐摆放在床铺下面**；书籍摆放整齐
- 暖瓶、香皂盒、漱口杯、毛巾等放在适当位置；暂不用的物品整齐放进柜子
- **每周排定宿舍值日表，每天设专人值日**
- 宿舍服务部配合学校有关部门实施**学生宿舍日常内务检查**

::: tip 💡 值日表第一天就排好

六个人谁也不想天天打扫。开学头一周把值日表贴出来（谁拖地、谁倒垃圾、轮流），比后面吵架省心得多。

:::

## 想换宿舍怎么办

来源：《后勤服务指南》"学生宿舍调换服务流程"

1. **新生住宿安排结束后 30 天内**，根据住宿实际情况**可进行个别宿舍调整**，其他时间一般不作调整
2. 有调整需求的学生，在条件允许的情况下**提出书面申请**
3. 先由**学院审核**，经**后勤管理处宿舍服务部**批准后办理住宿调整
4. 同时按退宿管理规定进行**公物验收**并变更住宿档案
5. **只在本年级、本学院范围内调整，不得跨年级、跨学院**

::: danger ⚠️ 别自己搬

未正常办理调整手续的，**必须按宿舍管理部门分配的宿舍住宿，不得私自调整**。房间空闲床位是公共使用资源，**不得私自占用**。

转专业学生可在条件允许时申请调整；**休学学生复学后，原则上随相应年级专业安排住宿**。

:::

**宿舍服务部**：0371-61912820、0371-61912821（后勤楼 201、202 室）

## 退宿

来源：《后勤服务指南》

**休学和毕业学生或其他原因无学籍学生应退宿**。退宿时由宿舍服务部会同所在院（系、部）及有关部门**对退宿房间进行验收**，出现公物损坏的按公物管理规定处理；验收后办理退宿手续。

::: tip 💡 毕业退宿前先把空调押金退了

空调**押金 600 元/台**（毕业时退还），流程是：交回遥控器 → 线下登记**支付宝账号** → 无异常 **15 个工作日**退费到账。遥控器丢了要按 **60 元/个**赔偿。详见[洗浴与洗衣](bath-laundry)。

:::

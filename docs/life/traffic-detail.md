## 电动车 / 自行车

### 登记：走保卫处非机动车业务

来源：[保卫处《非机动车业务》](https://bwc.zua.edu.cn/info/1096/3485.htm)（2023-11-08，内含附件）

校内非机动车（电动车、自行车）相关手续由保卫处办理，**具体要求和表格见附件**。

从25级开始，校内不再发放电动车车牌，仅有开学班级里少量发放自行车名额，有需要车牌的需及时关注班级群内消息或者联系辅导员。

**没有车牌有概率被没收**，电动车的概率更大。

### 充电：校内充电桩

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)

校内充电桩**扫码或刷卡**支付，**24 小时**可用，按功率计价：

| 功率 | 价格 |
| --- | --- |
| 150W 以内 | 0.15 元/小时 |
| 150–300W | 0.25 元/小时 |
| 300–400W | 0.35 元/小时 |
| 400–600W | 0.5 元/小时 |
| 600–1000W | 0.75 元/小时 |
| 电动汽车服务费 | 0.45 元/小时度 |

**充电桩报修**：朱风光 13937173137

::: danger ⚠️ 安全充电五条（官方原文要点）

1. **停稳再充**：车停指定充电区域，确保完全静止
2. **检查设备**：充电枪、线缆有无破损裂口松动，指示灯是否正常
3. **插紧**：插入直至保险锁扣紧
4. **远离火源**：充电站内严禁吸烟，不使用明火
5. **人离车**：充电时尽量离开车辆

充电站**不负责车辆看管**，发生碰撞、剐蹭、丢失立即报警。触摸充电设备前确保双手干燥。

:::

::: warning ⚠️ 别在宿舍充电

电动车电池**严禁带入宿舍充电** —— 这是全国高校火灾的头号原因，郑航宿舍违禁电器规定里也明令禁止私拉电线。详见[校园安全](../health/safety)。

:::

### 停放在哪

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm) 学生宿舍住宿规定第 11 条

> **自行车应停放在指定地点。**

违反宿舍住宿纪律的（含乱停乱放），情节较轻通报批评，情节严重按学校有关规定处分。

## 机动车

来源：[保卫处《机动车业务》](https://bwc.zua.edu.cn/info/1096/3481.htm)（2023-11-02，内含附件）

机动车进校相关手续由保卫处办理，详见附件。

::: info 📌 新生报到日车辆可进校

保卫处每年发布报到期间交通管制通知和**车辆进校路线示意图**，例如 [2026 级的通知](https://bwc.zua.edu.cn/info/1045/4154.htm)（2026-09-05 发布，含两张路线图）。

**报到日送新生车辆按示意图路线进校**，具体管制措施以当年通知为准。新生和家长留意录取通知书里的说明和学校公告。

:::

## 网约车与打车

::: warning ⚠️ 本页无官方依据

学校未发布网约车上车点的官方规定。一般做法是定位到**最近的校门**（东门/南门/西门/北门）上车，具体哪个门方便以当日校门开放情况为准。

:::

::: danger ⚠️ 打车防骗

- 上车前核对**车牌和司机信息**，别上错车
- 用平台内支付，别私下转账
- 夜里打车把行程分享给室友
- 机场/火车站的"黑车"一律不坐，用平台叫车或地铁

详见[电信诈骗与防骗](../health/antifraud)。

:::

## 假期回家

| 目的地 | 参考路线 |
| --- | --- |
| **郑州东站** | 地铁 12 号线（龙子湖西站，梁湖方向）→ 高铁公园站换 8 号线（鲁庙方向）→ 郑州东站，约 25 分钟 |
| **郑州站** | 参考导航软件，距学校较远 |
| **新郑国际机场** | 参考导航软件，可地铁换乘 |

来源：[交通出行](transportation)

::: tip 💡 赶车留足时间

开学、放假高峰地铁**非常挤**，郑州东站周边也容易堵车。赶高铁至少提前 **1.5–2 小时**出发，节假日再多留半小时。

:::

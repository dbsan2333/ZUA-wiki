# 外卖与跑腿 <Badge type="tip" text="持续维护" />

外卖能不能进校、在哪儿取、校内送餐与门禁的关系。

::: warning ⚠️ 本页暂无官方依据

**学校官网、后勤管理处、保卫处均未发布外卖进校管理的规定或取餐点公告。** 本页不凭印象描述"外卖放在哪个门""几点后不让进"——这类规则由物业和保卫处动态调整，写了很快就会过时，反而误导。

**到校后看班级群通知、宿舍楼公告，或问辅导员。**

:::

## 校门与门禁

哪一家外卖能不能送到楼下，取决于校门和宿舍楼的管理方式和企业与学校的合作方式。这些是有官方出处的：

### 行人道闸

来源：[保卫处《龙子湖校区行人道闸信息录入办理须知》](https://bwc.zua.edu.cn/info/1096/4115.htm)（2025-09-18）

进出校门需要录入道闸信息。**新生入学后一般由学院统一组织录入**，具体以学院通知为准。

### 宿舍楼门禁

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)

- 宿舍 **6:00 开门、23:00 关门**，周五周六及节日推迟 30 分钟
- 宿舍楼配有**智能门锁**（服务商：王闯 15516920410，后勤楼一楼联通营业厅）

### 校门管理

来源：[保卫处办事流程](https://bwc.zua.edu.cn/bslc.htm)

- [非机动车业务](https://bwc.zua.edu.cn/info/1096/3485.htm)（含附件，2023-11-08）
- [机动车业务](https://bwc.zua.edu.cn/info/1096/3481.htm)（含附件，2023-11-02）

保卫处 24 小时值班电话：**61916110**。

## 可送外卖到宿舍楼下的企业

以本篇目更新时间（2026年10月）为止，可以送外卖到宿舍楼下的企业有两家：**淘宝（原饿了么）、美团**。

采用**接力送**的方式进行外卖送达：即校外骑手负责送到接收点，校内人员（大部分是学生兼职）负责从接收点送到宿舍楼下。

这些企业还特别提供了校园食堂入口，部分餐厅窗口和商业街提供外卖渠道，由校内骑手直接送达。

## 校内食堂开到 22:00

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)

| 餐厅 | 供餐时间 |
| --- | --- |
| 东苑餐厅 | **7:00–22:00** |
| 西苑餐厅 | **7:00–22:00** |
| 民族餐厅 | **7:00–22:00** |
| 教工餐厅 | 11:30–13:00 |

一日三餐在食堂吃，日均大概 **20~30 元**。品种详见[食堂指南](canteen)。

::: tip 💡 食堂 22:00 才关门

东苑、西苑、民族餐厅都开到 **22:00**，晚自习回来还能吃上热饭。真没必要天天点外卖。

:::

## 取餐地址怎么写

学校**没有官方规定的外卖交接点**，所以地址只能写到"楼"这一级，楼下有外卖架供放置外卖。地址规范可参考《后勤服务指南》对收件地址的写法：

```
河南省郑州市郑东新区文苑西路 15 号 郑州航院龙子湖校区
XX 学院 XX 班级 姓名 电话
```

::: tip 💡 备注里写清这三样

1. **楼号**（如"6 号楼正门"），外卖员才知道进哪个门
2. **不要打电话 / 放某某处**（如果那儿确实允许）—— 别默认能送上楼
3. **电话留真实可接的号**。找不到人外卖员会直接放宿舍楼下，要维权的时候难。

:::

## 外卖 vs 食堂：算笔账

| 项目 | 食堂 | 外卖 |
| --- | --- | --- |
| 供餐时间 | 东苑/西苑/民族餐厅 **7:00–22:00** | 更晚也能点到，但取决于商家 |
| 取餐成本 | 走过去，顺路 | 要下楼到交接点，雨雪天更麻烦 |
| 出问题怎么办 | 找**红马甲值班经理**，可主张退款与赔偿 | 走平台售后，配送环节难追责 |
| 食品安全 | 学校后勤与市场监管双重管理 | 商家资质看不见 |

::: info 📌 结论

**食堂开到 22:00，比很多人以为的晚。** 晚自习回来还赶得上热饭，见[食堂指南](canteen)。外卖留给"真不想动""宿舍聚餐""夜里饿了"这三种场景，别当日常。

:::

## 什么情况外卖更合适

- **食堂关门后**（22:00 之后）——但注意宿舍 **23:00 关门**，周五六及节日推迟 30 分钟
- **恶劣天气**不想起床排队
- **生病**没力气下楼 —— 可以让跑腿送上门到楼下
- **室友凑单**，多人拼一单分摊配送费最划算

## 点外卖的一般建议

这些是通行经验，不是校方规定：

- **地址写到宿舍楼**，备注楼号
- **及时取餐**，放久了会凉，丢了也难追
- **注意食品安全**，夏天超过 2 小时别吃
- **跑腿代买**同理，一般送到楼下
- **留好订单截图和支付记录**，出问题在 APP 内申请售后
- **别信"餐品有问题要理赔"的来电**，见下方反诈提醒

::: danger ⚠️ 外卖相关的诈骗

有人冒充外卖/快递客服，说"餐品有问题要理赔"，诱导你**开屏幕共享**或点链接填银行卡 —— 全是诈骗。

平台退款一律**在 APP 内操作**，不会让你加微信、不会要验证码。详见[电信诈骗与防骗](../health/antifraud)。

:::

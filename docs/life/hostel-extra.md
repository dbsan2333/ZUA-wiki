## 作息与供电

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)（后勤管理处，2025-06-24）

| 项目 | 时间 |
| --- | --- |
| 宿舍开门 | **6:00** |
| 宿舍关门 | 23:00（周五、周六、节日推迟 30 分钟） |
| 宿舍供电 | **6:00** – 23:00（周五、周六顺延 30 分钟，节日全天供电） |

### 断电后空调能开吗？

**能，空调不断电。** 宿舍照明等普通插座限时供电，但空调独立供电。

### 其他用电注意

- 排插买大品牌，宿舍用电安全第一
- 大功率电器（热得快、电炉等）**禁止使用**
- 台式机注意功率限制

## 洗衣与晾晒

### 洗衣机能脱水吗？

**可以。** 夏天衣服洗完脱水后，第二天早上基本就干了。

### 晾晒

宿舍楼下有晾晒区。军训服、床单等大件建议看好天气再洗。

## 床品尺寸

宿舍床常见为 **1.9m × 0.9m**。

买床垫、床单、蚊帐时注意尺寸，网购前量一下实际床位。

## 军训服别扔

::: danger ⚠️ 重要

**大部分专业后面有金工实习，要求穿军训外套。** 军训完别急着扔。

:::

详见 [军训指南](../enroll/military-training)。

## 报修

宿舍设施损坏，按项目找对人最快：

| 项目 | 找谁 |
| --- | --- |
| 水、电、暖、门窗锁具 | **报修电话 0371-61911999** |
| 洗衣机、吹风机、直饮水 | 对应外包公司（见[常用部门与电话](../quick/phones)） |
| 空调 | 空调服务中心 15538326015 |
| 智能门锁 | 15516920410（后勤楼一楼联通营业厅） |
| 投诉、咨询、物业 | 后勤服务热线 **0371-61913110** |

宿管阿姨/大爷也可以直接报修（报楼栋号 + 房间号 + 问题）。

**建议**：开学第一天就问清本楼的报修方式。

## 宿舍关系

- 4/6 人间，空间有限，**互相体谅**是长久相处的基础
- 作息不同尽早商量，可约定统一的熄灯/静音时间
- 金钱往来（合买物品、代买）要记清，别因小钱伤感情
- 矛盾找辅导员调解，别憋着也别激化

::: tip 💡 实在处不来，可以正规申请换

**新生住宿安排结束后 30 天内**，可根据实际情况申请**个别宿舍调整**，其他时间一般不作调整。流程：本人书面申请 → 学院审核 → 后勤管理处宿舍服务部批准。

只能**在本年级、本学院范围内调整，不得跨年级、跨学院**。详见[宿舍](hostel)的换宿舍流程。

:::

## 钥匙与门锁

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)"钥匙管理"

- **随身携带自己的钥匙，不得随意外借、乱放**
- **严禁私自撬门**
- 钥匙丢失后**应及时报知公寓管理员**，该房间要**更换锁具**，**后果由丢失者承担责任**

::: danger ⚠️ 钥匙丢了别拖

不只是"配一把"的事——按规定房间要**换锁**，费用与责任归丢失者。宿舍值班室备有**工作钥匙**（应急用），借须持本人或担保同学的学生证**登记、抵押证件、签字**，一般不予借用。

:::

## 用电：跳闸断电了怎么办

官方给的处置很明确：

> 若发现宿舍内插座、照明**跳闸断电**（除抢修、维修等情况外），应**到所在楼宇的值班室向值班人员报修**，或拨打 24 小时报修电话 **0371-61911999**。

::: warning ⚠️ 别自己折腾配电箱

一是**没用**（不是你能修的），二是**私自改变室内电压电路本身就是违规用电**，视情节给予警告以上处分，违禁电器一经发现**予以没收**。

:::

**买插座、台灯认准 3C 认证**、出厂证明和检验合格证（后勤指南"温馨提示"）。有医疗设备等特殊情况需要用电的，可向学院**申请专项用电许可**。

## 用水：两条明令禁止

来源：《后勤服务指南》"注意事项"

- **禁止私自改装**：不得拆卸、改装宿舍内供水管道或热水设备
- **禁止占用资源**：不得用桶长时间占用水龙头或热水机
- 洗漱间、卫生间、淋浴间是公共设施，**禁止倾倒杂物堵塞下水道**

::: tip 💡 破坏供水设施要赔偿，还可能背处分

官方原话：**破坏供水设施可能需赔偿，并视情节给予纪律处分**。

:::

## 暖气：能做的和不能做的

| 项 | 内容 |
| --- | --- |
| 供暖时间 | 郑州集中供暖每年 **11 月 15 日至次年 3 月 15 日**（因天气或政策可能调整），龙子湖校区根据学校寒假安排实行供暖 |
| 供暖范围 | **1–27 号学生公寓**、`01`/`02`/`03`/`05`/`07` 教学楼、南行政楼、青年教师公寓等 |
| 室内温度 | 一般 **18℃±2℃**，实际受市政供水温度、供暖管道、公寓楼层、**朝向**等影响 |
| 不热或漏水 | 打 **0371-61911999** |

::: warning ⚠️ 别遮挡暖气片

**禁止私自改装：不得拆卸、遮挡暖气片或私接供暖设备。** 想靠暖气片烘衣服、把床挪过去靠着，都属于遮挡。

**离开宿舍时建议关闭门窗**，避免浪费热能——这条是真有用的，暖气被风吹走，屋里最不暖的是你自己。

:::

::: tip 💡 暖气不热先想想朝向和楼层

官方承认温度"受楼层、朝向等因素影响"。如果是**整栋普遍不热**，直接打报修电话；如果只是你这间凉，报修时**说明温度不达标**，让维修人员上门测，别只说"有点凉"。

:::

## 洗衣与晾晒的补充

- **建议饮用开水或过滤水，避免直接饮用自来水**（后勤指南原文）
- 宿舍楼内直饮水机**需刷卡付费**；想免费就打**开水房**（东苑餐厅外部西侧、西苑餐厅外部南侧，07:00–22:30）
- 单脱水只要 **0.01 元/次**，夏天衣服甩干第二天基本就干

价格、故障代码、报修电话全在[洗浴与洗衣](bath-laundry)。

## 防盗

- 出门随手锁门，**笔记本电脑、手机、钱包**重点保管
- 宿舍钥匙不外借
- 大额现金不留宿舍

::: tip 💡 贵重物品拍照留底

开学就把电脑、相机的**序列号、外观照片**存一份。万一丢了，报警和理赔都用得上。丢了第一时间联系保卫处 **61916110**，见[校园安全](../health/safety)。

:::

## 公寓内的纪律红线（容易忽略的几条）

来源：《后勤服务指南》"住宿纪律"

| 别做 | 说明 |
| --- | --- |
| **不私自留宿非本寝室人员** | 同学、朋友、亲戚都算 |
| **男女生不互串宿舍** | 明文禁止 |
| **不把饭菜、酒精类饮品带进公寓区** | 包括啤酒零食 |
| **不在宿舍内吸烟** | 禁止 |
| **不在公寓内推销、贩卖** | 未经许可不得张贴、散发宣传品和广告 |
| **不往窗外和楼道扔杂物、泼水** | 高空坠物性质更严重 |
| 不存放易燃易爆剧毒品和管制刀具 | 禁止 |

违规者**情况较轻给予通报批评，情节严重者按学校规定处分**。完整清单见[宿舍](hostel)。

# 关于本项目 <Badge type="tip" text="持续维护" />

ZUA Wiki 是由郑航学子们共同编写的**非官方**百科手册，涵盖学生们学习和生活的方方面面。

启航时间：2024 年 6 月 13 日

最新维护时间：2026 年 10 月

持续更新中……

**本站内容精心编写，是所有贡献者的劳动成果。任何复制、转载请注明出处！严禁用于商业用途！**

::: warning ⚠️ 本站与学校无隶属关系

本站是**学生自发维护**的经验站，内容来自学校官网、各部门通知、迎新系统与学长学姐的实际经验。**与官方冲突时，一律以官方为准**——这也是每个页面顶部挂"以官方为准"提醒的原因。

:::

## 站点结构

全站按**办事场景**分区，不按学校机构分。左侧目录 8 个主板块 + 社区：

## 怎么贡献内容

不需要会写代码，也不需要提交整篇文章。四种参与方式，从轻到重：

1. **提 Issue 报错或补缺** —— 看到数字错了、电话变了、页面有"待补充"，直接开 [Issue](https://github.com/dbsan2333/ZUA-wiki/issues) 说明，附上官方通知链接最好
2. **补充一段话** —— 你有确切信息（比如你所在学院的实际流程），提 Pull Request 补进去
3. **上传官方文件** —— 通知原文 PDF、校历图、宿舍实拍图，都是稀缺资源
4. **新建整页** —— 动手前先读仓库根目录的 **`AGENTS.md` 写作规范**，本站风格是"学长学姐写给学弟学妹的手册"，不是官方通知也不是审计报告

::: tip 💡 投稿最看重的是出处

本站的原则是**查不到就写"待补充"，绝不编造数字、URL、月份**。所以你给的信息最好带上官方来源（哪个部门、哪份通知、哪天发布），宁可少写也不要写错——**写错会误导一大片人**。

:::

::: warning ⚠️ 这类内容本站不收

- **群号、联系方式**：只收经核实的、非营销的，且会标注"请自行甄别"，见[社区](../community/)各页的收录规则
- **具体分数、分数线表格**：官方查询系统是动态的，抄下来必然过时，见[历年录取分数](../enroll/admission-score)为什么只写"怎么查"
- **社团与组织名单**：年审增减频繁，见[学生组织与社团](../affairs/club-org)为什么不列举
- **传言、听说、应该吧**：直接标"待核实"，别当事实写

:::

## 为什么有些内容本站不写

本站的取舍是刻意的，理解这些能帮你更快找到真正需要的信息：

| 不写 | 原因 | 去哪儿查 |
| --- | --- | --- |
| **历年录取分数线表** | 官方查询系统是动态筛选的，抄进静态页必然过时 | [历年录取分数](../enroll/admission-score) 教你怎么用官方系统 |
| **具体社团名单** | 社团每年注册、年审、增减，写死即错 | [学生组织与社团](../affairs/club-org) 给了找法（招新现场、校团委、学社联） |
| **外卖、快递的具体取餐点** | 属物业和保卫处动态调整，学校无官方规定 | 到校看班级群通知与楼内公告 |
| **校内超市位置、价格** | 外包商业网点变动频繁，后勤指南不含此内容 | [超市与便利店](../life/supermarket) 只收录有官方出处的外包电话 |
| **完整入党流程** | 由党委组织部和学院党委执行，各环节时间要求需官方文件 | [党团组织](../affairs/party-league) 给出官方流程图 PDF |
| **群号** | 除已核实的贴吧迎新群外，一律不收录 | 见各社区页面的"收录规则" |

::: tip 💡 原则

**查不到就写"待补充"，绝不编造数字、URL、月份。** 所以你会在站内看到一些"待补充""本页暂无权威出处"——那不是偷懒，是为了不误导。有确切信息欢迎补上。

:::

## 本站怎么维护

- **数据来源**：学校各部门官网（教务处、招生信息网、校团委、后勤管理处、保卫处、校医院等）、智慧迎新系统、录取通知书、官方公众号推文，以及学长学姐的实践经验（会明确标注为社区经验）
- **更新方式**：**实时页**（不带年份）永远是最新版本；有旧版本的页面底部用 `::: details 历史版本` 折叠指向归档
- **历史归档**：[archive 目录](../archive/)保留历年冻结版本（招生章程、招生计划等），便于对比政策变化
- **技术栈**：[VitePress](https://vitepress.dev/) 静态站，Markdown 编写；图片、PDF存于站内，视频与宣传片**直接引用学校官网等官方源的地址**，地图用高德 JS API
- **源码仓库**：[dbsan2333/ZUA-wiki](https://github.com/dbsan2333/ZUA-wiki)（GitHub 开源）

::: warning ⚠️ 时效声明

页面标题后的徽章（"2026年10月更新""持续维护"）表示内容的时效属性。招生、政策类页面**每年都可能变**，**办理重要事务前请务必核对官方当年通知**。

:::

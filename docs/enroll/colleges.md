## 各学院专业明细

### ✈️ 航空发动机学院

飞行器动力工程、飞行器质量与可靠性、能源与动力工程、飞行器运维工程 —— 全部要求**物理+化学**。

### 🚀 航空宇航学院

飞行器设计与工程、无人驾驶航空器系统工程、航空航天工程，以及飞行器设计与工程（中外合作办学）。全部**物理+化学**。

学校**低空技术与工程**专业挂在计算机学院，不在本学院。

### ⚙️ 机械工程学院

机械设计制造及其自动化、车辆工程、飞行器制造工程、智能制造工程，以及机械设计制造及其自动化（中外合作办学）。全部**物理+化学**。

::: tip 💡 金工实习

机械类的金工实习在[工程训练中心](http://jxxy.zua.edu.cn/)，军训服别扔，那会儿要穿军训外套。

:::

### 💻 计算机学院

计算机科学与技术、软件工程、网络工程、人工智能、低空技术与工程。全部**物理+化学**。

### 📡 电子信息学院

电子信息工程、通信工程、智能测控工程。全部**物理+化学**。

### 🔌 自动化学院

电气工程及其自动化、自动化、探测制导与控制技术。全部**物理+化学**。

### ✈️ 民航学院

飞行器适航技术、安全工程、交通运输（空管与签派）、飞行技术、航空服务艺术与管理。

飞行技术是**民航招飞**专业，走单独流程，详见 [hyzs.zua.edu.cn](http://hyzs.zua.edu.cn/)；航空服务艺术与管理属艺术类，不提科目要求。

### 🧪 材料学院

材料科学与工程、功能材料、材料成型及控制工程。全部**物理+化学**。

### 🏗️ 土木与环境学院

土木工程、给排水科学与工程、环境工程（**物理+化学**）、城乡规划（不提科目要求）、工程管理（物理）。

### 🎨 艺术与设计学院

产品设计、视觉传达设计、环境设计、动画（不提科目要求）、工业设计（**物理+化学**），以及产品设计（中外合作办学）、环境设计（中外合作办学）。

::: info 📌 注意工业设计

艺术与设计学院里**只有工业设计要求物理+化学**，其余艺术类专业都是"不提科目要求"。别以为整个学院都是艺术生招法。

:::

艺术类专业详见[艺术类招生](special-types)。

### 📖 文法学院

汉语言文学、汉语国际教育、行政管理、法学。全部**不提科目要求**。

### 🌍 外国语学院

英语、翻译、法语。全部**不提科目要求**。学校有省内首家法语联盟"郑州法语联盟"。

### 📐 数学学院

数学与应用数学、数据计算及应用。全部**物理+化学**。

### 💰 商学院

会计学、会计学（注册会计师方向）、工商管理、审计学、财务管理、人力资源管理、市场营销。全部要求**物理**。

::: info 📌 会计学是国家级特色专业

商学院的会计学是学校 3 个国家级特色专业之一，注册会计师方向单独招生。

:::

### 📊 管理工程学院

工业工程、质量管理工程、物流管理（物理）、供应链管理（不提科目要求）、交通运输（**物理+化学**）。

### 📈 经济学院

经济学、经济统计学、金融学、金融科技（物理）、贸易经济、国际经济与贸易（不提科目要求）。

### 🗂️ 信息管理学院

图书馆学、档案学（不提科目要求）、信息管理与信息系统、大数据管理与应用（物理）。

::: tip 💡 图书馆学和档案学

这两个专业在河南省内开设的院校不多，是郑航的特色方向，别一听名字就以为"冷门"——档案学有国家档案局重点实验室支撑。

:::

### 🌏 国际学院（南乌拉尔学院）

中外合作办学机构，开设信息管理与信息系统、质量管理工程（物理）、材料成型及控制工程、自动化（**物理+化学**）四个中外合作办学专业。

::: warning ⚠️ 中外合作办学看这里

中外合作办学专业**学费明显高于普通专业**，且飞行器设计与工程、机械设计制造及其自动化、产品设计、环境设计等专业**部分专业课程为英语教学**，高考外语语种非英语的考生慎报。详见[招生章程](brochure)。

:::

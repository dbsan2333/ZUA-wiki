::: info 📌 2026年招生总体情况

来源：[学校招生办访谈](https://gaokao.haedu.cn/517/522/525/2026/0630/155698.html)（河南省阳光高考信息平台 2026-06-30 转载）。招生章程原文**未**给出下列具体数字。

2026年普通本科招生计划 **6300人**（与2025年持平），面向全国31个省（区、市）招生。其中河南省约 **4100人**，省外约 **2200人**。

新增 4 个普通类专业：**低空技术与工程、智能制造工程、智能测控工程、供应链管理**。

新增 1 个中外合作办学专业：**机械设计制造及其自动化（中外合作办学）**。

2026年本科招生专业共 **69个**，其中国家级特色专业3个、省级特色专业9个，约40%的专业为国家或省级一流本科专业。
:::

## 河南省本科招生专业组设置

::: tip 📌 分组变化
相比2025年，专业分组设置更加细化：以河南省为例，**历史类普通专业组由原来的1个调整为2个组，物理类普通专业组调整为10个组**（另含中外合作办学等单列组）。目的是将关联度高、培养要求相近的专业编入同一组，合理控制专业数量，提升考生志愿满足率。
:::

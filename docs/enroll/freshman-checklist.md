# 新生入学清单 <Badge type="tip" text="持续维护" />

::: tip 💡 怎么用
照着本页逐项打勾。**标 🔴 的是录取通知书明确要求、缺了会麻烦的**；其余按需准备。直接邮寄到校或到校买都行，能减轻行李负担。
:::

## 🔴 证件材料（缺了会麻烦）

| 项目 | 说明 |
| --- | --- |
| **录取通知书** | 原件，报到核验 |
| **身份证** | 原件 + 正反面复印件若干 |
| **高考准考证** | 可能要求，带上保险 |
| **学籍档案** | 密封完好，**不要私自拆封** |
| **团员档案袋** | 团员证、入团志愿书、介绍信等（团员） |
| **党团组织关系转接材料** | 党员/团员需办理 |
| **户口迁移证** | 仅迁户口同学需要，不迁则忽略 |
| **家庭经济困难证明材料** | 申请助学金/贷款用（录取通知书内"绿色通道"材料） |
| **证件照** | 一寸、二寸，蓝/红/白底都备几张 + **电子版** |

::: danger ⚠️ 档案千万别拆
学籍档案、团员档案一般是**密封**的，私自拆封可能不被认可。到校后按通知交到指定地点。
:::

## 证件照

- **纸质**：一寸、二寸 × 若干张，蓝底为主（学生证要求**一寸蓝底**），红白底备用
- **电子版**：务必存好，开学后教务系统会要求上传
- 建议在家附近的照相馆一次拍好，比到校后排队便宜

## 生活用品

| 类别 | 物品 |
| --- | --- |
| 清洁 | 毛巾、盆、牙刷、牙膏、洗面奶、沐浴露、洗衣液、鞋刷 |
| 床上 | 褥子、床单、被子、枕头、蚊帐（床常见 **1.9m × 0.9m**，见[宿舍](../life/hostel)） |
| 学习 | 中性笔、铅笔、2B 涂卡笔、橡皮、笔记本 |
| 其他 | 卫生纸、雨伞、拖鞋、指甲剪、常用药品、防晒霜（军训用） |

::: tip 💡 怎么带
- **建议到校买**：盆、衣架、洗衣液等大件或重的，校内超市都有
- **建议从家带**：个人习惯用的洗漱用品、药品、床品（合身习惯）
- **可提前邮寄**：被子等大件，算好快递到达时间
:::

## 军训相关

- **防晒霜**：必带，郑州九月仍很晒
- 大容量水杯
- 军训服按学校通知购买，**买一套够换洗即可**，别急着提前网购
- **军训服别扔**：大部分专业后面金工实习要穿军训外套

详见 [军训指南](military-training)、[宿舍生活技巧](../life/hostel-extra)。

## 钱与卡

| 项目 | 说明 |
| --- | --- |
| 学费 | **按录取通知书里的流程缴纳**，不要向任何个人转账 |
| 一卡通 | 到校后办理，食堂、超市、洗浴都用它，见[日常消费](../life/consumption) |
| 银行卡 | 通知书里要求办的卡（通常用于代扣学费、发放奖助学金） |
| 少量现金 | 应急备用 |

::: danger ⚠️ 缴费只走官方渠道
学费缴纳**只按录取通知书里的流程**。任何自称"代缴""内部名额"的个人都别信。
:::

## 到校交通

- **地址**：郑州市郑东新区文苑西路 15 号（龙子湖校区）
- 学校南门、东门有公交站，北门有地铁
- 报到期间学校对龙子湖校区实行交通管制，进校路线见[智慧迎新系统](https://yx.zua.edu.cn/)

详见 [交通出行](../life/transportation)。

## 报到前线上必做

见 [开学前必做](freshman-before)：迎新系统、缴费、选宿舍、查班级。

## 报到当天

1. **查好自己的报到地点/流程**（智慧迎新系统或学院通知）
2. 交验材料 → 领取一卡通 → 领宿舍钥匙 → 办军训服
3. **认准官方接待点**，别跟陌生人走
4. 加**学院官方群**（学校官方公众号开学前公布）

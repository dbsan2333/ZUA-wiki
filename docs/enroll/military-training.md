# 军训指南 <Badge type="tip" text="持续维护" />

::: info 📌 时间与地点
- **时间**：通常在 9 月中下旬，新生报到后开始，持续约 2–3 周
- **地点**：龙子湖校区（东操场等）
- **具体安排**：以学院通知为准
:::

::: tip 💡 数据说明
军训的具体起止日期、科目安排每年由学校统一部署，**本页未列出确切日期**。请留意班级群和学院通知。
:::

## 军训内容

通常包括：

| 类别 | 内容 |
| --- | --- |
| 队列训练 | 站军姿、齐步走、正步、停止间转法 |
| 军体拳/战术 | 视学校安排 |
| 内务整理 | 叠被子、宿舍卫生 |
| 理论学习 | 国防教育、校史校情 |
| 急救培训 | 校医院会开展新生军训急救知识专项培训 |
| 拉练/汇演 | 部分年份有，军训末常有汇报表演 |

## 军训服

### 长什么样
近几年都是**蓝色海军服**，但每年款式要到开学才能确定。

### 能买二手/自己网购吗
可以，只要保证军训期间服装统一。但：

- **开学前别急着买**，款式不确定
- 近年每届款式一样，但**徽标可能有差异**
- 二手建议**当面查验**磨损情况

### 军训完别扔

::: danger ⚠️ 重要
**大部分专业后面有金工实习，要求穿军训外套。** 别军训一结束就扔了。
:::

## 防暑与防晒

郑州 9 月仍可能很热：

| 物品 | 作用 |
| --- | --- |
| **防晒霜** | 必带，训练前涂，午休补涂 |
| 大容量水杯 | 及时补水，别等口渴 |
| 湿巾/纸巾 | 擦汗降温 |
| 清凉贴/风油精 | 防中暑（按需） |
| 常用药 | 藿香正气类、创可贴 |

## 身体不适怎么办

- **不要硬撑**。头晕、恶心、心慌立即报告教官/指导员
- 校医院急诊 **61912730**（东校区 24 小时），见[校医院](../health/hospital)
- 有不适合剧烈运动的疾病，提前准备**医院证明**

## 免训与缓训

::: warning ⚠️ 待核实
免训/缓训的申请条件、流程、需提交的证明材料**尚未从官方渠道核实**。

一般做法：凭医院证明（不宜参加剧烈运动）向学院申请免训或缓训，由学院和武装部审批。**具体规定请咨询学院辅导员。**
:::

## 实用建议

1. **鞋袜要合脚**。军训鞋偏硬，可垫软鞋垫
2. **早上吃饱**。训练强度大，别空腹
3. **午休抓紧睡**。下午还有训练
4. **内务提前练**。叠被子是技术活，提前学
5. **和同学互相照应**。晕倒时有人能扶一把、报告教官
6. **防晒霜蹭到衣服上难洗**，穿深色训练服时注意

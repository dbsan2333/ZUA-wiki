# 军训指南 <Badge type="tip" text="持续维护" />

::: info 📌 时间与地点

- **时间**：通常在 9 月中下旬，新生报到后开始，持续约 2–3 周
- **地点**：龙子湖校区（东操场等）
- **具体安排**：以学院通知为准

:::

::: tip 💡 数据说明

军训的具体起止日期、科目安排每年由学校统一部署，**本页未列出确切日期**。请留意班级群和学院通知。

:::

## 军训内容

通常包括：

| 类别 | 内容 |
| --- | --- |
| 队列训练 | 站军姿、齐步走、正步、停止间转法 |
| 军体拳/战术 | 视学校安排 |
| 内务整理 | 叠被子、宿舍卫生 |
| 理论学习 | 国防教育、校史校情 |
| 急救培训 | 校医院会开展新生军训急救知识专项培训 |
| 拉练/汇演 | 部分年份有，军训末常有汇报表演 |

## 军训服

### 长什么样
近几年都是**蓝色海军服**，但每年款式要到开学才能确定。

### 能买二手/自己网购吗
可以，只要保证军训期间服装统一。但：

- **开学前别急着买**，款式不确定
- 近年每届款式一样，但**徽标可能有差异**
- 二手建议**当面查验**磨损情况

### 军训完别扔

::: danger ⚠️ 重要

**大部分专业后面有金工实习，要求穿军训外套。** 别军训一结束就扔了。

:::

## 防暑与防晒

郑州 9 月仍可能很热：

| 物品 | 作用 |
| --- | --- |
| **防晒霜** | 必带，训练前涂，午休补涂 |
| 大容量水杯 | 及时补水，别等口渴 |
| 湿巾/纸巾 | 擦汗降温 |
| 清凉贴/风油精 | 防中暑（按需） |
| 常用药 | 藿香正气类、创可贴 |

## 身体不适怎么办

- **不要硬撑**。头晕、恶心、心慌立即报告教官/指导员
- 校医院急诊 **61912730**（东校区 24 小时），见[校医院](../health/hospital)
- 有不适合剧烈运动的疾病，提前准备**医院证明**

## 免训与缓训

::: warning ⚠️ 待核实

免训/缓训的申请条件、流程、需提交的证明材料**尚未从官方渠道核实**。

一般做法：凭医院证明（不宜参加剧烈运动）向学院申请免训或缓训，由学院和武装部审批。**具体规定请咨询学院辅导员。**

:::

## 实用建议

1. **鞋袜要合脚**。军训鞋偏硬，可垫软鞋垫
2. **早上吃饱**。训练强度大，别空腹
3. **午休抓紧睡**。下午还有训练
4. **内务提前练**。叠被子是技术活，提前学
5. **和同学互相照应**。晕倒时有人能扶一把、报告教官
6. **防晒霜蹭到衣服上难洗**，穿深色训练服时注意

## 内务与查寝

内务是军训期被扣分最多的地方。学校宿舍的内务要求是白纸黑字写的（来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)"内务规定"）：

- 地面、窗台、桌面无杂物；门窗、墙壁、天花板**无灰尘、无蜘蛛网、无脚印、无污迹**
- **被子、枕头摆放整齐统一，鞋整齐摆放在床铺下面**；书籍摆放整齐
- 暖瓶、香皂盒、漱口杯、毛巾放在适当位置；暂不用的物品整齐放进柜子
- **每周排定宿舍值日表，每天设专人值日**
- 宿舍服务部配合学校有关部门实施**学生宿舍日常内务检查**

::: tip 💡 鞋子放床下这件事，提前养成习惯

很多人是被查寝之后才开始天天塞鞋。六个人的鞋乱摆一眼就看出来了，**从第一天就统一塞床下**，比临时抱佛脚省事。宿舍规定也明确禁止"往墙上蹬脚印""乱写乱画乱刻乱贴"。

:::

## 军训期间外出与请假

::: warning ⚠️ 离校必须走审批

**军训期间离校需填写[《军训期间学生外出请假条》](https://bwc.zua.edu.cn/info/1096/3684.htm)**（保卫处），按流程审批。

同时提醒一条红线：按《本科生学籍管理规定（修订）》（校教字〔2024〕44号）第三十六条，**未经批准连续两周未参加学校规定的教学活动的，应予退学处理**。军训属于教学活动，别不办手续就消失。详见[请假与留校](../affairs/leave-stay)。

:::

## 考勤怎么算

军训**计入考勤范围**。《学籍管理规定》里明确：理论课、实验、上机、实习、参观、劳动、**军训**、时事政治教育和思想品德教育都算考勤。

| 情形 | 折算 |
| --- | --- |
| 迟到、早退 **5 次** | 折算旷课 **1 学时** |
| 学校统一组织的活动（劳动）旷课 1 天 | 按 **4 学时**计 |
| 未请假或请假未准而不参加 | 一律按**旷课** |

::: danger ⚠️ 一学期旷课满 10 学时就要处分

不是小事。**处分会影响学位授予**——在校受**记过及以上处分且尚未解除**的，不授予学士学位。详见[毕业与学位](../future/graduation)。

:::

## 认真训，是有分的

来源：[校团字〔2022〕2号《第二课堂积分评定参照表》](https://tuanwei.zua.edu.cn/info/1004/2616.htm)

| 荣誉 | 级别 | 第二课堂积分 |
| --- | --- | --- |
| **军训标兵** | 校级 B 类 | **3 分** |
| 宿舍先进个人 | 校级 B 类 | 3 分 |
| 社会实践先进个人 | 校级 B 类 | 3 分 |

::: tip 💡 3 分不多，但"至少三类不为零"用得上

第二课堂要求本科修满 **5 学分（25 积分）**，且**六大类中至少三类不为零**。军训拿的是**思想引领类**的分——这一类很多人一辈子攒不够，**开学第一仗就顺手拿 3 分**，很划算。想拿"军训标兵"一般要靠训练表现 + 内务，教官和辅导员会看。

:::

## 常见疑问

**Q：军训计入成绩吗？**
A：按培养方案安排，**以你所在学院和专业说明为准**。本页未检索到统一口径，不确定时直接问辅导员。

**Q：生理期/生病能不能请假？**
A：可以。**当天不舒服当场跟教官报告**，别硬撑，去旁边休息或去[校医院](../health/hospital)（急诊 61912730，24 小时）。需要长期免训的走上面的免训/缓训流程。

**Q：军训完要干嘛？**
A：① **外套别扔**，金工实习要穿；② 留意**第二课堂积分有没有到账**，属"学生自主录入"的要自己在 PU 口袋校园提交，见[第二课堂学分](../affairs/second-classroom)。

**Q：要买军训服吗？**
A：**优先在[智慧迎新系统](https://yx.zua.edu.cn/)里选**（8 月 17 日起开放），到校就领，见[开学前必做](freshman-before)。自己网购或买二手虽可以，但款式要到开学才定，别提前下单。

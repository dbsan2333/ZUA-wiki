# 开学前必做 <Badge type="tip" text="持续维护" />

录取到手到报到之间的一个月，按这个时间线打勾，别到校手忙脚乱。

::: warning ⚠️ 特别提醒

各事项以**录取通知书内的说明和[智慧迎新系统](https://yx.zua.edu.cn/)通知**为准！本页时间线以 2026 级为例，年份间流程可能微调。

:::

## 智慧迎新系统：所有线上环节都在这里

来源：[智慧迎新系统](https://yx.zua.edu.cn/)首页公布的 2026 年安排

| 环节 | 2026 年开放时间 | 说明 |
| --- | --- | --- |
| **完善个人信息** | **8月17日 – 9月8日** | 信息填报、证件照上传 |
| **在线缴费** | **8月28日 13:00 起** | 学费住宿费线上缴 |
| **网上选床** | **9月4日 中午12:00 起** | 先到先得，选完就没得挑了 |
| **绿色通道** | 8月28日 – 9月8日 | 办了助学贷款/家庭困难的走这个 |
| **来校方式登记** | 8月17日 – 9月8日 | 填报到交通方式 |
| 自选服务：校园智慧生活卡 / 校园无线网 / **军训服装选购** | 8月17日 开放 | 按需选购 |
| 自选服务：**空调租赁** | 9月1日 开放 | 见[宿舍生活技巧](../life/hostel-extra) |

::: tip 💡 新生登录方式
迎新系统新生登录用**姓名 + 考生号 + 身份证号**。首页还有「报到流程」「报到须知」栏目和《2026级本科生入学手册》（2026-07-30 发布），先通读一遍。
:::

::: danger ⚠️ 别错过选床时间
**网上选床 9月4日中午12点开始**，先到先得。想挑到好床位，定好闹钟，提前把系统登录好。错过就只能等系统分配了。
:::

## 时间线

### 拿到录取通知书 → 7月底

1. **通读通知书里的全部文件**——报到流程、缴费方式、户口迁移、资助材料都在里面
2. **按通知书流程缴纳学费**：只走官方渠道，任何「代缴」「内部优惠」都是骗子
3. **办生源地助学贷款**（需要的话）：趁暑假在户籍地学生资助管理中心办理，回执开学交给学校；经济困难的可申请迎新**绿色通道**，先报到后缴费
4. **准备困难认定材料**（需要的话）：填好通知书里的家庭经济困难学生申请表

### 8月

1. **登录[智慧迎新系统](https://yx.zua.edu.cn/)**：8月17日起完善个人信息、上传证件照，按上面的时间表逐项完成
2. **拍好证件照电子版**：一寸蓝底，迎新系统和教务系统都要用
3. **团员转接**：登录「智慧团建」系统，按通知书说明转团组织关系
4. **关注学校官方公众号**：开学前学校公众号会公布各**学院官方新生群**——在那之前拉你的"新生群"基本都是卖卡的，见[新生群与官方群识别](../community/freshman-groups)
5. **军训服在系统里选**：8月17日起可在迎新系统选购，到校就领，别等开学排队（款式见[军训指南](military-training)）
6. **买票**：2026级报到为 9月7日–8日（见[新生入学须知](starting)），车票按报到日买

### 报到前一周

1. **完成网上选床**（9月4日12:00 起，先到先得）
2. **对照[新生入学清单](freshman-checklist)收拾行李**：证件材料原样带齐，生活用品能到校买就轻装
3. **填「来校方式」登记**：迎新系统里报你的到站信息，学校好安排接站
4. **查好报到路线**：龙子湖校区（文苑西路15号），地铁 12 号线龙子湖西站，见[交通出行](../life/transportation)；报到期间校区周边交通管制，进校路线看迎新系统
5. **备少量现金**：应急用，其余都线上支付

## 报到日

- **认准官方接待点**：学院迎新点有统一标识，别跟陌生人走，行李别交给"帮忙看行李"的人
- **2026 级有免费接送**：学校在报到期间发了《2026级新生报到免费接送服务通知》（迎新系统首页公告栏），按公布站点坐校车
- 交验材料 → 领一卡通 → 领宿舍钥匙 → 领军训服（系统里选过的）
- 加上**学院官方群**（以学校公众号公布的为准）
- 见到辅导员记下联系方式

::: danger ⚠️ 报到日的坑
宿舍里上门推销电话卡、夏令营、报纸、化妆品的，一律不办不买；要你扫码登记个人信息的，一律不扫。真有需要，等人齐了去正规营业厅。更多套路见[开学防坑](../community/faq-antifraud)。
:::

## 报到后两周内

1. **学信网确认学籍**（9月底–10月中旬，见[证件与学籍办理](../affairs/id-xueji)）
2. **学生证办理**（10月上旬，学校出钱）
3. **医保参保**（10月起集中缴费，见[医保与转诊](../health/insurance)）
4. **困难认定与奖助学金申请**（9–10月，见[奖助与资助](../affairs/scholarship-aid)）
5. **河南省资助系统信息录入**（2026级全体本科生，9月上旬通知）

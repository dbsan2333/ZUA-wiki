### 能看到什么

每条记录包含：

| 字段 | 含义 |
| --- | --- |
| 年份 | 录取年度 |
| 省市 | 生源地 |
| 类型 | 招生类型（普通类/艺术类等） |
| 科类 | 理/物理、文/历史 |
| **专业** | 具体专业名称 |
| **录取人数** | 该专业在该省录取人数 |
| **最低分** | 该专业录取最低分 |
| **平均分** | 该专业录取平均分 |
| **最高分** | 该专业录取最高分 |
| 备注 | 特殊说明 |

::: tip 💡 最低分比平均分更值得看

**最低分**代表"踩线进"的极限，**平均分**代表这个专业的常态水平。

参考时一般这么用：自己的分数**高于平均分**比较稳；**接近最低分**属于冲一冲，有风险。

## 怎么看懂这些数据

### 三个容易踩的坑

**1. 科类改革前后的分数不可直接比较**

河南 2025 年起实行新高考，此前的"理工/文史"与之后的"物理/历史"**不是一回事**，分数线也不可直接对比。跨年份比较时务必看清科类字段。

**2. 专业组分省不同**

2026 年河南设 **16 个专业组**，同组内专业可互相调剂。你看到的某个专业"最低分"，可能是被调剂进去的考生拉低的。详见[专业详解](majors)。

**3. 中外合作办学单独成组、分数通常更低**

2026 年第 13–16 组是中外合作办学专业，**学费高出一大截**（如艺术类中外合作 18000 元/年 vs 普通 8000 元/年）。看到"低分上郑航"要留意是不是中外合作。详见[特殊类型招生](special-types)。

::: info 📌 位次比分数更可靠

高考分数每年受试题难度影响波动，但**省内位次**相对稳定。参考价值：**位次 > 分差 > 绝对分数**。

官方系统提供的是分数，位次需要你自己对照当年的一分一段表。

:::

:::

## 分数不够怎么办

::: info 📌 进档后还有几条路

如果分数刚好在郑航投档线附近，或者进了档但没够到心仪专业，还有这些机会：

:::

**转专业**：入学后第一学期末可申请转专业（一般在大一下学期），具体要求见[转专业](../study/changing-majors)。转专业不看高考分数，看大一成绩。

**辅修/双学位**：部分专业开放辅修，毕业时拿双学位。详见[辅修与交流](../study/minor-exchange)。

**考研跨专业**：本科专业的限制不等于一辈子的限制。郑航每年有不少同学跨专业考研成功。

## 中外合作办学值不值得报

2026 年第 13–16 专业组是中外合作办学，分数通常比普通专业低一截。但要注意：

| 对比项 | 普通专业 | 中外合作办学 |
|---|---|---|
| 学费 | 约 5000–8000 元/年 | 约 18000 元/年（艺术类） |
| 四年学费差额 | — | 约 **4 万元** |
| 部分课程语言 | 中文 | **部分专业课程英语教学** |
| 转专业 | 有机会 | **一般不能转到普通专业** |

::: warning ⚠️ 报中外合作前想清楚

- 家庭经济条件能否承担四年高额学费
- 外语语种是否为英语（非英语考生慎报）
- 录取后基本**锁死**在该专业，转专业通道极窄

如果分数够普通专业，优先普通专业；如果分数不够普通专业但想上郑航，中外合作是一条路。

:::

## 志愿填报小技巧

::: tip 💡 几个实用建议

**1. 位次比分数更重要**

高考分数每年因试题难度波动，但**省内位次**相对稳定。参考历年数据时，优先看位次，其次看分差，最后才看绝对分数。

**2. "冲稳保"策略**

- **冲**：位次略高于自己位次的专业组（有希望但有风险）
- **稳**：位次与自己位次相当的专业组（大概率能进）
- **保**：位次明显低于自己位次的专业组（兜底）

**3. 专业组内调剂要看清**

同组内专业可以互相调剂。如果组里有你不喜欢的专业，填这个组就要做好被调剂的心理准备。详见[专业详解](majors)的专业组设置。

**4. 别忽视"冷门"专业**

郑航的图书馆学、档案学在河南省内开设院校不多，是特色方向。别一听名字就放弃——档案学有国家档案局重点实验室支撑，就业面比想象中宽。

:::

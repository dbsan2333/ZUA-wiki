入馆须知、数字资源

::: info 📌 基本信息

- **官网**：[lib.zua.edu.cn](https://lib.zua.edu.cn/)
- **馆藏规模**：纸质图书 **246 万册**、中外文数据库 **31 个**（学校简介口径，截至 2025 年 11 月）
- **阅览座位**：**5499 个**
- **开放时间**：7:00 – 22:30（节假日、假期另行通知），**周开放时间 108.5 小时**
- **网上资源**：**24 小时**开放
- **馆内直饮水**：06:00 – 22:30（比教学楼早一小时）
- **位置**：龙子湖校区，东侧沁湖、南侧"航威威"雕塑广场

:::

::: tip 💡 数据来源

开放时间、座位数、周开放时长来自学校**智慧迎新系统公布的《图书馆入馆须知》**。具体以[图书馆官网](https://lib.zua.edu.cn/)最新公告为准。

:::

## 怎么进门

图书馆门禁**仍需使用一卡通**——学校大门和宿舍已改人脸识别，图书馆没改。所以**一卡通别弄丢**，丢了进不去也借不了书，补办见[证件与学籍办理](../affairs/id-xueji)。

::: tip 💡 NFC 拷贝在这里能用

一卡通是加密卡，手机 NFC 拷贝**只能复制卡号**，消费场景用不了；但**图书馆门禁可以正常刷**——手机没电时这是条后路。原理见[日常消费](../life/consumption)。

:::

## 入馆须知

读者服务包括：**馆藏书目查询、全开架借阅、通借通还、多媒体阅览**。

- **阅览座位需提前通过座位预约系统预约就座**
- 遵守馆内秩序：**勿占座、勿大声喧哗**

::: warning ⚠️ 占座是明令禁止的

座位由预约系统管理，**人走长时间占着位子会被处理**。期末想找座，正确做法是提前在系统里约，而不是放本书就走。

:::

## 自习与考研

**5499 个座位**平时够用，**考试周和考研季是例外**。

| 时段 | 情况 |
| --- | --- |
| 平时 | 座位相对宽松 |
| **期末考试周** | 非常紧张，**务必早预约**，按[校历](jw-system)提前几天开始抢 |
| **考研冲刺（9–12 月）** | 固定座位需求大，靠系统预约，别指望现场捡漏 |

::: tip 💡 图书馆是期末最能熬的地方

教学楼 **22:30 清场**，图书馆同样到 22:30，但**网上资源 24 小时**。真要学到很晚，要么提前在图书馆抢座，要么回宿舍——宿舍供电到 23:00（周五六顺延 30 分钟），**空调独立供电不断电**。见[宿舍](../life/hostel)。

:::

## 借书还能攒第二课堂积分

这条很少有人知道。来源：[校团字〔2022〕2号《第二课堂积分评定参照表》](https://tuanwei.zua.edu.cn/info/1004/2616.htm)（[PDF 原文](https://tuanwei.zua.edu.cn/__local/1/A8/CA/63A1AC34623160C4F58FCAE6818_05EE3EB4_4BF5B.pdf)）

**每借阅 1 册且借期 ≥ 10 天，计 0.05 积分**，学年上限 **3 分**；多次借阅、续借同一册**按一册计**。

::: tip 💡 顺手的事，别浪费

第二课堂是**毕业硬要求**（本科 5 学分 = 25 积分），见[第二课堂学分](../affairs/second-classroom)。借书这项零门槛，虽然一学年最多 3 分不多，但反正要借。**记得借期凑够 10 天再还**，不然不计分。

:::

## 数字资源（校外也能用）

::: tip 💡 不用校园网也能访问

图书馆电子资源（知网、万方等数据库）在校外通过 **[webvpn](https://webvpn.zua.edu.cn/)** 即可访问，**不需要额外开通校园网**，也不用办校园卡。见[校园网络](../life/network)。

:::

| 类型 | 内容 |
| --- | --- |
| 中文数据库 | 知网、万方、维普等 |
| 外文数据库 | 以图书馆官网公布为准 |
| 电子图书 | 馆藏电子图书 |
| 学位论文 | 本校及合作机构学位论文 |

学校简介口径为**中外文数据库 31 个**，完整清单与访问方式见[图书馆官网](https://lib.zua.edu.cn/)「数字资源」栏目。

## 写论文、查文献的路径

1. **找文献** → webvpn 进知网/万方，或用馆藏书目查询
2. **要原文** → 数据库下载；纸质书走全开架借阅
3. **学检索** → 图书馆通常会开**信息素养 / 文献检索讲座**，留意官网通知与馆内海报
4. **毕业论文格式要求** → 以**学院和指导教师**的要求为准，见[毕业与学位](../future/graduation)

::: warning ⚠️ 具体借阅规则请现场确认

借阅册数、借期、续借次数、逾期处理、预约规则等**尚未从官方页面核实**，本页不写数字。请通过以下方式确认：

1. [图书馆官网](https://lib.zua.edu.cn/)「读者服务」栏目
2. 馆内服务台咨询
3. 入馆时发放的读者手册

:::

## 图书馆学专业

郑航**图书馆学**专业设立于 2007 年，为**河南省重点学科、硕士学位授权点**，隶属[信息管理学院](https://sim.zua.edu.cn/)。别一听名字就当冷门——同院的**档案学有国家档案局重点实验室支撑**。专业详情见[专业详解](../enroll/majors)、[学院介绍](../enroll/colleges)。

## 馆内温度不适找谁

图书馆空调为**地源热泵**，温度不合适可拨打 **15290863070** 反馈。

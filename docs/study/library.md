# 图书馆使用 <Badge type="tip" text="持续维护" />

::: info 📌 基本信息
- **官网**：[lib.zua.edu.cn](https://lib.zua.edu.cn/)
- **智慧图书**：[lib.zua.edu.cn](https://lib.zua.edu.cn/)（学校官网快捷入口）
- **馆藏规模**：纸质图书 246 万册、中外文数据库 31 个（学校简介口径，截至 2025 年 11 月）
- **阅览座位**：5499 个
- **周开放时间**：108.5 小时
- **开放时间**：7:00 – 22:30（节假日、假期另行通知）
- **网上资源**：24 小时开放
:::

::: tip 💡 数据来源
开放时间、座位数、周开放时长来自学校**智慧迎新系统公布的《图书馆入馆须知》**。具体以[图书馆官网](https://lib.zua.edu.cn/)最新公告为准。
:::

## 入馆须知

- 读者服务包括：馆藏书目查询、全开架借阅、通借通还、多媒体阅览
- **阅览座位需提前通过座位预约系统预约就座**
- 请遵守馆内秩序，勿占座、勿大声喧哗

## 数字资源（校外也能用）

::: tip 💡 不用校园网也能访问
图书馆电子资源（知网、万方等数据库）在校外通过 [webvpn](https://webvpn.zua.edu.cn/) 即可访问，**不需要额外开通校园网**。
:::

常见数字资源：

| 类型 | 内容 |
| --- | --- |
| 中文数据库 | 知网、万方、维普等 |
| 外文数据库 | 以图书馆官网公布为准 |
| 电子图书 | 馆藏电子图书 |
| 学位论文 | 本校及合作机构学位论文 |

## 借阅常识

::: warning ⚠️ 具体规则待补充
借阅册数、借期、续借次数、逾期处理、预约规则等**尚未从官方页面核实**。请通过以下方式确认：

1. [图书馆官网](https://lib.zua.edu.cn/)「读者服务」栏目
2. 馆内服务台咨询
3. 入馆时发放的读者手册
:::

::: tip 💡 常规做法（仅供参考，非官方规定）
高校图书馆常见规则为：本科生可借 10–30 册、借期 30–60 天、可续借 1–2 次。**郑航的确切数字请以官方为准。**
:::

## 自习与研讨

- **自习座位**：通过座位预约系统预约，考试周尤其紧张，建议早预约
- **研讨间**：多数高校图书馆设研讨间供小组讨论使用，需预约；郑航是否提供及预约方式待核实
- **开放时间**：7:00 – 22:30，考试周可能延长

## 图书馆学专业

郑航**图书馆学**专业设立于 2007 年，为河南省重点学科、硕士学位授权点，隶属[信息管理学院](https://sim.zua.edu.cn/)。想了解该专业见[专业详解](../enroll/majors)。

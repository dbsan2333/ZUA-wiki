# 考试与成绩 <Badge type="tip" text="2026年10月更新" />

考试安排在哪查、成绩怎么算、挂科了怎么办——这一页说清楚。

::: warning ⚠️ 特别提醒

本页整理自[教务处官网](https://jwc.zua.edu.cn/)通知与制度文件，具体执行以教务系统和学院通知为准！

:::

## 考试安排在哪查

- **期末考试**：教务处发《关于查询期末考试安排的通知》（2026年春季学期的查询通知见[教务处官网](https://jwc.zua.edu.cn/info/1155/6714.htm)），登录教务管理系统查自己的考试时间、地点、座位号
- **补、缓考安排**：新学期开学初教务处发查询通知，2026年秋季补缓考查询发布于 9月7日
- **大型考试调课**：四六级、研究生考试等占用教室时教务处会发调课通知（如[龙子湖校区大型考试调课通知](https://jwc.zua.edu.cn/info/1155/6673.htm)），留意别跑错教室
- **缺考和缓考是两回事**：病事假提前办了缓考手续的不算缺考；无故缺考可能被记违纪，后果比考挂了重得多

## 成绩与绩点

- **成绩查询**：教务管理系统，每学期期末考试结束后陆续出分
- **绩点规则**：按《普通本专科学生课程考核与成绩记载管理办法（修订）》（[校教字〔2020〕30号](https://jwc.zua.edu.cn/info/1199/3927.htm)，自2020级开始实施）执行
- **成绩复核**：对成绩有异议，通过学院教学办提交成绩更正申请，流程见教务处[服务指南·在校生](https://jwc.zua.edu.cn/fwzn/zxs.htm)

### 缓考怎么办手续

来源：[教务处《缓考申请办理流程》](https://jwc.zua.edu.cn/info/1156/3425.htm)（教学培训科）

::: danger ⚠️ 缓考必须在考试结束前申请
流程是四步：**学生申请 → 授课教师确认 → 学院审核 → 教务处终审**。第一步就在教务系统里办（位置：我的课程 → 缓考申请），选课程、写原因、**上传证明材料**（诊断证明等，word/excel/pdf 附件）——考完试就没法申请了！
:::

1. **学生申请**：考试结束前在教务系统提交，提交后**主动联系授课教师**去系统确认
2. **授课教师确认**：确认该课程是否有缓考安排（有补考安排的课程应当安排缓考）
3. **学院审核**：教学院长审缓考原因和材料是否合规
4. **教务处终审**

## 免修：拿证书直接换学分

依据[《课程免修实施办法》](https://jwc.zua.edu.cn/info/1199/3931.htm)（校教字〔2021〕2号）和[《大学英语、计算机类、体育课程免修实施细则》](https://jwc.zua.edu.cn/info/1199/5386.htm)（**教发〔2024〕21号，现行版**）。

::: danger ⚠️ 网上搜到的旧版对照表别用
教务处官网"规章制度"栏目还挂着一版 2021 年 3 月的旧细则（无文号），门槛低得多（如四级 480 就能免英一、六级 430 就能免）——**它已被教发〔2024〕21号明文废止**（"原教发〔2021〕30号同时废止"）。本页对照表以 2024 版为准；拿不准就问学院教学办。
:::

::: info 📌 免修的基本规则
- **每学期开学 4 周内**在教务系统申请，上传证书/成绩单等实证材料
- 免修 = 免去该课的学习和考试，**按认定成绩计入学分和绩点**（英语按对照表、计算机优秀95/良好85/合格75）
- **一份成绩只能免修一门课**，且不能同时申请创新学分认定——重复申请两个都取消，还按违纪处理
- 已经修过且及格的课程**不追认**
:::

### 大学英语免修对照表（教发〔2024〕21号原文）

免修前正常上课，获准后不再参加该学期英语课学习与考核，成绩按下表换算：

| 你的成绩 | 能免修的课程 | 认定成绩 |
| --- | --- | --- |
| **四级 631+** | 大学英语(三) 95 / 大学英语(四) 90 | 按所选课程记 |
| 四级 611–630 | 英(三) 90 / 英(四) 85 | 按所选课程记 |
| 四级 581–610 | 英(三) 85 / 英(四) 80 | 按所选课程记 |
| 四级 550–580 | 英(三) 80 / 英(四) 75 | 按所选课程记 |
| **六级 581+** | 大学英语(四) | **95** |
| 六级 561–580 | 大学英语(四) | 90 |
| 六级 541–560 | 大学英语(四) | 85 |
| 六级 520–540 | 大学英语(四) | 80 |
| **雅思 6.5+** | 大学英语(四) | 95 |
| 雅思 6.0+ | 大学英语(三) | 90 |
| 雅思 5.5+ | 大学英语(二) | 85 |
| 雅思 5.0+ | 大学英语(一) | 80 |
| **托福 100+** | 大学英语(四) | 95 |
| 托福 95–99 | 大学英语(三) | 90 |
| 托福 90–94 | 大学英语(二) | 85 |
| 托福 85–89 | 大学英语(一) | 80 |
| 国才考试高级优秀 | 大学英语(四) | 90 |
| 国才考试高级良好 | 大学英语(三) | 85 |

::: warning ⚠️ 几个关键点
- 雅思、托福成绩有**两年有效期**，过期不算
- **高分可以认定低分对应课程**，成绩按高分档算（如六级 590 可免英四记 95）
- **一份成绩只能免一门**——四六级成绩免了大学英语，就不能再拿它认定创新学分
- 托业（TOEIC）仅限**空中乘务专业**使用
- 同一档分数免英(三)比免英(四)记分高（如四级 631+ 免英三记 95、免英四记 90），**免哪门按培养方案要求**，找教学办确认
:::

### 怎么办

教务管理系统申请 → 上传实证材料 → 开课单位审核原件 → 通过后成绩学分直接入账。具体找学院教学办。

## 挂科了怎么办

### 补考

- 上一学期不及格的课程，**下学期开学初参加补考**，具体时间地点看教务处开学初的补缓考查询通知
- 补考成绩录入后，可按成绩调整重修选课（2026 年秋季的第三轮选课调整窗口就在补考成绩录入后的 9月28-29日，见[选课指南](select-course)）

### 重修

- 补考仍不及格的课程需**重修**：原则上选**课程代码相同**的课程，在第三轮选课时操作
- 重修课与现有课表冲突时，第三轮允许冲突选课；也可申请**免听**（校教字〔2021〕3号）
- 体育课重修补修直接到**新体育馆三楼 312 办公室**找吴老师

### 学业警示（别走到这一步）

来源：[《关于做好2026年度本科生学业警示工作的通知》](https://jwc.zua.edu.cn/info/1155/6814.htm)，[《郑州航空工业管理学院本科生学业警示实施办法》](https://jwc.zua.edu.cn/info/1199/6469.htm)

| 情形 | 后果 |
| --- | --- |
| 上一学年培养方案内课程有不及格 | **学业预警**（辅导员/负责人找你谈话，制定帮扶计划） |
| 2025级学生不及格学分累计达 **15 分** | 学院约谈**家长** |
| 2024级学生不及格学分累计达 **20 分** | 学院约谈家长，可能**留级** |
| 达到留级处理 | 下达书面通知单，通知家长，一人一档管理 |

::: danger ⚠️ 学分红线
留级不是吓唬人：各学院 10 月上旬就要把留级处理名单报教务处学籍科，每年都有真实案例。挂科了尽早补考、重修补回来，别攒到触发红线。
:::

## 四六级

来源：[《关于2026年下半年全国大学英语四、六级考试报名工作的通知》](https://jwc.zua.edu.cn/info/1155/6787.htm)（教学培训科 2026-09-17）

- **开考科目**：英语四级、六级笔试。**四级达 425 分才能报六级**
- **报名资格**：2022–2025级本科生、全体专升本在校生、全体在籍研究生（**大一新生不能报**，学校规定如此）
- **报名官网**：[cet-bm.neea.edu.cn](https://cet-bm.neea.edu.cn/)（教育部教育考试院统一报名系统）
- **2026下半年报名时间**：9月18日 08:00 – 9月23日 17:00
- **报名后 24 小时内缴费**，并回系统确认状态——逾期不缴费**系统自动删报名信息**，每年都有人白报
- 报名前学校会先发**学籍信息校验**通知（2026下半年校验于 9月14日发布），学籍有问题先解决再报名
- 报名咨询：**0371-61912505**

## 计算机等级考试

- 全国计算机等级考试（NCRE）：3 月、9 月、12 月开考，视考点安排报名
- 大学英语、计算机类课程**免修**政策见[教发〔2024〕21号实施细则](https://jwc.zua.edu.cn/info/1199/5386.htm)（如四六级/等级考试成绩达标可申请免修对应课程）

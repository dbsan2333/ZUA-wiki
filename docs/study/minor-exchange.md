# 辅修与交流 <Badge type="tip" text="持续维护" />

辅修双学位的申请条件、流程、学分与收费，以及国际交流交换的渠道。

来源：[《郑州航空工业管理学院本科生双学位管理规定（试行）》校教〔2013〕60号](https://jwc.zua.edu.cn/info/1199/3915.htm)、[《郑州航空工业管理学院双学位教育实施细则（试行）》校教〔2014〕9号](https://jwc.zua.edu.cn/info/1199/3914.htm)（教务处·学业修读指导栏目）

::: warning ⚠️ 先看这条

上面两份文件发布于 **2013 / 2014 年**（网页发布时间 2021-05-20），是本页目前能查到的最权威依据。但**双学位政策可能已调整**，且文件第九条明确写着"实施双学位教育的专业以学校每年公布的双学位专业信息为准"。

**申请前务必先看当年教务处通知**（[教务通知栏目](https://jwc.zua.edu.cn/jwgl/jwtz.htm)），本页只讲规则框架。

:::
## 什么是"双学位"

按校教〔2013〕60号的定义：在校普通本科生在保证完成主修专业的同时，**学有余力**，经自愿申请、学校考核同意，再完成**跨学科门类**的另一专业的学位课程，达到授予条件后，可获得**另一个学科门类的学士学位**。

::: info 📌 证书上会写"辅修"

学位证书上在专业前**注明"辅修"字样**。它不是一个独立的新学位证书，而是在你主修学位之外的第二个学科门类学位，标注为辅修。

:::

## 申请条件

两个文件的表述略有差异，**以更严格的那条为准**：

| 条件 | 校教〔2013〕60号 | 校教〔2014〕9号 |
| --- | --- | --- |
| 绩点 | 主修专业平均学分绩点 **2.5 以上** | 修读课程平均学分绩点 **2.5 以上** |
| 成绩记录 | 没有**补考和重修**记录 | **无不及格课程**记录 |
| 年级 | 在校**一年级**本科学生 | 在校**一年级**普通本科学生 |
| 纪律 | 无考试违纪、作弊和纪律处分记录 | 无考试违纪或其它纪律处分记录 |
| 学科门类 | 双学位专业与主修专业须**分属不同学科门类** | 同左 |
| 数量 | 在校期间**限修读一个**双学位专业 | 同左 |

::: danger ⚠️ 两个硬门槛容易忽略

1. **只有一年级能申请** —— 大二大三想修已经来不及了
2. **必须跨学科门类** —— 比如你是工学（机械），就不能再修一个工学的双学位，得选经管、文学、法学等不同门类的

另外**绩点 2.5 且无不及格/补考重修记录**，这个要求不低。大一上就得把成绩稳住。

:::

## 申请与审批流程

按校教〔2014〕9号第四条：

| 时间 | 环节 |
| --- | --- |
| **每年 4 月** | 教务处发布申请辅修双学位专业工作通知 |
| 4 月 | 学生申请 → **学生所在院系审核** |
| 4–5 月 | **双学位专业所在院系审核**（按本院系选拔办法组织选拔） |
| — | 教务处**公示预录取名单** |
| — | **主管教学副校长批准** |
| — | **公布正式录取名单**，发放修读双学位专业录取通知书 |

::: tip 💡 时间就卡在 4 月

整个申请窗口只有**每年 4 月**一次，错过等一年。想修双学位的话，大一下学期（3 月左右）就要开始盯[教务通知](https://jwc.zua.edu.cn/jwgl/jwtz.htm)了。

:::

**双学位资格审核**每年 **11 月**进行，由双学位专业所在院系负责，学生所在院系、教务处、学生处配合。

## 上课与学分

| 项目 | 内容 |
| --- | --- |
| 教学形式 | **单独开班**，每班不少于 **30 人** |
| 上课时间 | 一般安排在**周末、晚上或假期** |
| 学分要求 | 一般**不低于 50 学分** |
| 培养方案 | 含该专业的学科基础课、专业主干课和主要实践教学环节，课程规格与主修专业一致 |
| 制定流程 | 学年第一学期第 1–8 教学周院系制定，9–12 周教务处审批 |

::: warning ⚠️ 周末和晚上的课

这意味着你**整个大学期间基本没有完整的周末**。报之前想清楚：考研复习、实习、社团活动都要往后排。

:::

## 免修

修读双学位的课程与**主修专业已修读课程相同**的，可申请免修：

1. 学生提出申请（申请表在教务处网页"常用下载"栏下载）
2. 经**双学位专业所在院系**审核批准（60号文还要求课程所在院系和双学位院系教学院长/主任审核签字，报教务处批准备案）
3. 免修课程可将主修专业成绩和学分记入双学位成绩单，**备注"免修"字样**

## 什么时候会被取消资格

出现以下任一情况，取消修读双学位资格：

- 修读期间主修专业课程**不及格门数超过 5 门（含 5 门）**
- **考试作弊**
- 受**记过及其以上**违纪处分

另外，**获准修读后原则上不得转专业、不得自行退选**。确因无法坚持或有特殊原因要中止的，须本人申请，经有关院系和教务处批准。

## 收费

- 实行**按修读课程学分缴费**制度
- 标准按《河南省教育厅 河南省发展和改革委员会 河南省财政厅关于进一步规范普通高校收费管理的通知》（**豫教财〔2007〕74号**）执行
- 须按学期在学校规定时间内到财务处缴纳
- **每学期开学初凭财务处缴费收据办理注册手续**，逾期不办理视为自动放弃资格
- 因故中止的不再缴纳学费，但**已缴学费不再退还**

::: warning ⚠️ 本页不写具体金额

文件只说了"按豫教财〔2007〕74号执行"，**没有给出每学分多少钱**。官方没写的数字本页不猜，请以当年教务处通知和财务处公示为准。

:::

## 拿不到双学位怎么办

| 情况 | 结果 |
| --- | --- |
| 主修毕业时未修满双学位学分，仍想要证书 | 须**申请延长学制** |
| 未获得主修专业学士学位资格 | **无论是否修满双学位学分，均不颁发**双学位证书 |
| 未获得双学位资格，但已修了一些课 | 已获学分经院系审核、教务处批准后，可**冲抵全校公共选修课学分** |

::: danger ⚠️ 主修学位是前提

**主修专业的学士学位拿不到，双学位一律不发。** 别为了双学位把主修成绩拖垮，本末倒置。

:::

## 国际交流交换

来源：[学校简介](https://www.zua.edu.cn/xxgk/xxjj.htm)（数据截至 2025 年 11 月）

学校和**美国、俄罗斯、英国、法国、德国、波兰、韩国、坦桑尼亚等 30 多个国家和地区**的 **80 余所**高校与机构建立了友好合作关系，开展多形式、深层次、宽领域的国际交流与合作。

已落地的合作形式：

- 与**英国高地与群岛大学**、**波兰华沙人文社科大学**举办本科层次中外合作办学项目
- 与**坦桑尼亚多多马大学**合作建立孔子学院，获"全球先进孔子学院""公共外交工作先进单位""中坦友好使者奖"
- 建成省内首家法语联盟"**郑州法语联盟**"

::: info 📌 中外合作办学 ≠ 交换生

想走**中外合作办学**（拿双学位、在国内上课），看[专业详解](/enroll/majors#中外合作办学)和[学院介绍](/enroll/colleges)里的南乌拉尔学院。

想走**出国交换/交流**，本页暂未检索到学校官方发布的交换生选拔办法，**不做推测**。建议直接咨询：

- [国际交流与合作处（dwhzjlc.zua.edu.cn）](http://dwhzjlc.zua.edu.cn/)
- 所在学院的教学办

具体的交换项目、名额、资助、学分互认规则，以当年通知为准。

:::

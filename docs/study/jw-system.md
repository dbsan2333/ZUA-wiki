# 教务系统与校历 <Badge type="tip" text="持续维护" />

教务系统是大学四年用得最多的网站：选课、查成绩、看课表、核对培养方案都在里面。

::: warning ⚠️ 特别提醒

本页整理自[教务处官网](https://jwc.zua.edu.cn/)公开信息，系统入口和密码政策以信息管理中心与教务处最新通知为准！

:::

## 系统入口

| 系统 | 网址 | 用途 |
| --- | --- | --- |
| **教务处官网** | [jwc.zua.edu.cn](https://jwc.zua.edu.cn/) | 通知、选课指南、规章制度 |
| **教务管理系统** | [jwglxt.zua.edu.cn](http://jwglxt.zua.edu.cn/) | 选课、成绩、课表、学籍 |
| **智慧门户（统一身份认证）** | [sfrz.zua.edu.cn](https://sfrz.zua.edu.cn/) | 多个校内系统的统一登录 |
| **webvpn** | [webvpn.zua.edu.cn](https://webvpn.zua.edu.cn/) | **校外访问教务系统就走这里** |

::: tip 💡 校外也能用

没有校园网也能访问教务系统——通过 webvpn 登录即可，见[校园网络](../life/network)。

:::

## 常用功能

- **我的课表**：每学期开学先核对课表，欠费未置课、漏置的必修课要在选课轮次内自己补选
- **培养方案/计划完成审核**：对照毕业要求查学分完成情况，转专业、学业警示都以此为准
- **选课**：按轮次开放，见[选课指南](select-course)
- **成绩**：期末陆续出分，见[考试与成绩](exam-score)
- **评教**：每学期末评教，**不评教不能选下一轮课**

## 密码问题

::: warning ⚠️ 别乱试密码

教务系统密码**连续输错两次，账号冻结 2 分钟**，2 分钟后自动解冻。忘了就找辅导员或学院教学办重置，别瞎猜着试。

:::

- **密码重置**：到**所在学院教学办**重置（[官方流程](https://jwc.zua.edu.cn/info/1156/1180.htm)），各学院教学办电话见[常用部门与电话](../quick/phones)
- 统一身份认证（智慧门户）密码相关问题找[信息管理中心](https://xxglzx.zua.edu.cn/)（02A104，61912718）
- 账号是学号

## 教务系统照片：一次传对，关系到毕业证

来源：[《教务系统上传照片要求》](https://jwc.zua.edu.cn/info/1156/4433.htm)（学籍管理科）

教务系统那张照片用途极广：**所有校内考试、四六级、办学生证，甚至毕业证和学位证的辅助照片**都用它。

::: danger ⚠️ 上传前逐条核对

| 要求 | 标准 |
| --- | --- |
| 背景 | **蓝色**，禁用窗帘布当背景 |
| 姿态 | 素颜、不露齿、脱帽摘镜、刘海离眉至少 1cm、耳朵露出来、不戴耳环项链美瞳、不修伤疤痣 |
| 尺寸 | **宽 480px × 高 640px**，上部空 1/10、头部占 7/10、肩部占 1/5 |
| 格式 | **.jpg**，文件以**学号命名**，**10–40KB** |
| 禁止 | 手机自拍、生活照、艺术照、大头贴、PS、翻拍、水印 |

**入学照片审核通过后不允许更换**。不按要求上传 → 考试成绩无效、学生证不能用、毕业证学位证拿不到，后果自负、一律审核不通过。

已有在校照片的原则上不再更换；确实因整形、疾病等容貌大变的，持病历、缴费单据、身份证、学生证找辅导员和教学办核实后才可换。

:::

## 校历

学校每学年发布校历（含开学、考试周、寒暑假安排），官方入口：[外国语学院·郑航校历页](https://wyx.zua.edu.cn/zydh/zhxl.htm)，历年校历都在那里存档（2026–2027 学年版本发布于 2026-09-05）。

![郑航校历2026-2027学年](/img/校历2026-2027.jpg)
*2026–2027 学年校历（来源：外国语学院网站）*

::: tip 💡 校历怎么看

校历是**周次对照表**：左侧是日期，每个数字对应教学周次。查「第几周上课」「第几周考试」，拿当前日期对照就行。老师布置作业说的「第 8 周交」也是按这个表。

:::

参考节奏（2026–2027学年第一学期）：

| 节点 | 参考时间 |
| --- | --- |
| 2026级新生报到 | 9月7日–8日 |
| 开学典礼 | 9月9日 |
| 第二轮选课（开学第一周） | 9月7日–9日 |
| 第三轮选课（重修补修） | 9月18日–22日 |
| 学信网学籍确认（新生） | 9月30日–10月14日 |
| 期末考试 | 学期末（以校历为准） |

::: warning ⚠️ 校历以最新发布为准

校历每年可能微调，放假、考试周安排以教务处当期公布的版本为准。关键时间点汇总见[重要时间表](../quick/calendar)。

:::

## 开学第一周必做清单

新生最容易漏的几件事，按顺序做：

| # | 要做的事 | 在哪儿 |
| --- | --- | --- |
| 1 | **上传教务系统照片** | 蓝底、480×640px、`.jpg`、以**学号命名**、**10–40KB**，规格见[证件与学籍办理](../affairs/id-xueji) |
| 2 | **核对课表** | 「我的课表」——欠费未置课、漏置的必修课要在选课轮次内自己补选 |
| 3 | **选课 / 补选** | 见[选课指南](select-course)，开学第一周有改选轮次 |
| 4 | **对照培养方案** | 「计划完成审核」，看毕业要求还差多少学分 |
| 5 | **记住账号密码规则** | 账号是**学号**；**连续输错两次冻结 2 分钟**，别反复试 |
| 6 | **确认校外能登录** | 用 [webvpn](https://webvpn.zua.edu.cn/) 试一次，别等回家才发现登不上 |

::: danger ⚠️ 第 1 条最要命

照片**审核通过后不允许更换**。它关系到**所有校内考试、四六级、学生证，甚至毕业证和学位证的辅助照片**。不按要求上传可能导致**考试成绩无效、学生证无法使用、影响毕业证学位证**——糊里糊涂传张生活照，后面麻烦不断。

:::

## 成绩与绩点速查

| 事项 | 要点 |
| --- | --- |
| 出分时间 | 期末**陆续**出分，不是一次全出，见[考试与成绩](exam-score) |
| **学位线** | 课程（含实践环节）**平均学分绩点 ≥ 2.0** |
| **重修红线** | 2023 年 9 月 1 日后入学者，毕业时必修课**因不及格重修学分超过 20 学分**不授予学位 |
| 学业警示 | 有明确标准，**以教务系统提示和学院通知为准**，见[考试与成绩](exam-score) |
| 成绩单打印 | 在校生走[教务处流程](https://jwc.zua.edu.cn/info/1156/5917.htm)，**盖章才算数** |

::: tip 💡 每学期都查一次「计划完成审核」

别等大四。转专业、辅修、学分置换都会让培养方案对不上，**早点发现还能补修**，最后一年才发现就只能延长学制。见[辅修与交流](minor-exchange)、[毕业与学位](../future/graduation)。

:::

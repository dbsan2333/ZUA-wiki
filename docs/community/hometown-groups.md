## 如何补充

如果你建立了可靠的老乡群，或知道某个群的信息，欢迎：

- 在 [GitHub](https://github.com/dbsan2333/ZUA-wiki) 提 Pull Request
- 或联系 Wiki 维护者

**补充时请注明**：省份/地区、群号、建群时间、管理员身份，以便核实。

## 进群注意

1. **群主/管理员应做好入群审核**，避免营销号混入
2. 老乡群多用于假期拼车、家乡信息交流，**不要涉及金钱往来**
3. 群内同样可能有推销，保持警惕

## 老乡群能干什么

老乡群不是必须加的，但有几件事确实方便：

| 场景 | 说明 |
| --- | --- |
| **假期拼车** | 放假、开学时同城同学拼车到车站或直接回家，分摊油费 |
| **结伴出行** | 第一次独自坐长途车/飞机的同学，找同路人心里踏实 |
| **家乡信息** | 家乡的实习、招聘、考公考编消息，群里往往比学校通知早 |
| **生活互助** | 谁家寄了特产、谁需要带东西，顺手的事 |
| **节假日约饭** | 端午中秋回不了家的，凑一桌 |

::: tip 💡 大一加不加都行

老乡群的实际活跃期主要是**放假前后**。平时消息不多，不加也不影响什么。想加的话，问同省的学长学姐最快。

:::

## 怎么找自己的老乡群

按可靠程度排序：

1. **问同省学长学姐** —— 最直接，也最容易验证真假
2. **学院官方新生群**里问一句 —— 开学后学院群里有各省同学
3. **郑航贴吧**发帖问 —— 见[新生群与官方群识别](freshman-groups)的辨别方法
4. 老乡群常有**总群 + 分市群**，先加总群再问分市群

::: warning ⚠️ 别信"官方老乡群"

学校**不会**组织老乡群，所有老乡群都是学生自发建的。任何自称"学校官方老乡群"并以此收费、拉你办卡的，直接退群。

:::

## 假期拼车注意

拼车是老乡群最高频的用途，也是出事最多的地方：

- **只和熟人拼**，或至少群内可查、有实名管理的同学
- **上车前把车牌、司机信息、行程发给家人或室友**
- **不坐超载车**，不坐没有营运资质的"黑车"
- **费用提前说清**（油费、过路费怎么摊），别到地方扯皮
- **不单独和陌生异性拼车**，多人同行更稳妥
- 深夜到站尽量结伴，或直接打车回学校

::: warning ⚠️ 涉及钱就警惕

老乡群常见的骗局：**"代买票""帮带东西""家里急用钱借点"**。老乡身份不等于可信，凡是转账前一律电话/视频核实本人。

:::

## 进群注意

1. **群主/管理员应做好入群审核**，避免营销号混入
2. 老乡群多用于假期拼车、家乡信息交流，**不要涉及金钱往来**
3. 群内同样可能有推销，保持警惕
4. **别在群里发身份证、车票、录取通知书照片**（含个人信息）

## 常见问题

### Q：表里没有我们省/市的群怎么办？

A：三件事按顺序试——① 在**学院官方群**里问一句有没有同省的；② 到**郑航贴吧**发帖找同乡；③ 自己建一个，再按下面"如何补充"提交给本页收录。

**别去 QQ 搜群加陌生的"郑州航院XX老乡群"**，搜索出来的群绝大多数是营销号建的。

### Q：想自己建老乡群，有什么要求？

本站的收录规则是：**非第三方、真实、非营销目的、由本地老乡亲自建立**。具体建议：

| 项目 | 建议 |
| --- | --- |
| 群名 | 规范写法，如「郑航 XX 老乡群（20XX 级）」 |
| 管理员 | **至少 2 人**，一人失联不至于变广告群 |
| 入群审核 | **开启验证**，要求答对"你是郑航哪个学院/哪一级"这类问题 |
| 群规 | 第一条就写清**禁止商业推广、禁止收费、禁止私加人** |
| 定位 | 假期拼车 + 家乡信息，**不做兼职、不做团购** |

::: warning ⚠️ 建群容易，管好难

老乡群一旦被营销号渗透，很快就被踢出同学。开入群验证、发现广告立刻清人，这两件事要坚持做。

:::

### Q：群满了 / 群主失联了怎么办？

A：满群不用挤，**问群主要分群或二级群**。群主长期失联、群里只剩广告的，直接退——这类群对本站的收录价值也归零，可以提 [Issue](https://github.com/dbsan2333/ZUA-wiki/issues) 让维护者撤下。

### Q：老乡群里能拼车，费用怎么算不伤感情？

A：提前说清三件事，别到地方再谈：

1. **总额包含什么**——油费、过路费、停车费是否都算进去
2. **怎么摊**——按人头还是按座位，空位算谁的
3. **什么时候给**——上车前给还是下车给，**转账留记录**

::: tip 💡 熟人之间也要留凭证

拼车纠纷九成是"当时没说清"。**群聊里把金额和分摊方式写一遍**，比事后翻脸便宜。

:::

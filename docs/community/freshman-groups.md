# 新生群与官方群识别 <Badge type="tip" text="持续维护" />

::: danger ⚠️ 先记住这条
**目前网上的新生群基本都是非官方的。** 除贴吧迎新群外，大部分是为卖卡、推销引流的群。
:::

## 学院官方群什么时候有？

**开学前**，学校会在**官方微信公众号**上公布各学院官方群。

- 2025 年官方群公布入口：[学校公众号推文](https://mp.weixin.qq.com/s/CVePWwdvpb6gPUc0alNMSg)
- **2026 年待入学前通知**，请留意学校官方公众号

## 怎么辨别群的真假

| 特征 | 官方群 | 推销/引流群 |
| --- | --- | --- |
| 公布渠道 | 学校官方微信公众号 | 贴吧、小红书、QQ 搜索、私聊拉人 |
| 群主/管理员 | 学院老师、辅导员、学生干部 | 不明身份，多为校外人员 |
| 群名 | 规范，如"XX学院2026级新生群" | 花哨，常带"福利""速进" |
| 主要行为 | 答疑、通知、报到指引 | 推销校园卡、驾校、电话卡、兼职 |
| 是否主动私加你 | 不会 | **会** |

::: tip 💡 一个实用办法
对群里私加你的人保持警惕，可以把对方 QQ 号/微信号发到群里让大家辨识。
:::

## 进群后要注意

1. **不要**在群里透露考生号、身份证号、银行卡号
2. **不要**轻信"代缴费""内部名额""提前选宿舍"
3. 学费缴纳**只按录取通知书里的流程**
4. 有人私加你先核实，可发到群里问

更多防骗内容见 [开学防坑](faq-antifraud)。

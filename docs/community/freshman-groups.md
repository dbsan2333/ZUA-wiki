# 新生群与官方群识别 <Badge type="tip" text="持续维护" />

::: warning ⚠️ 先记住这条

**目前网上的新生群基本都是非官方的。** 除贴吧迎新群外，大部分是为卖卡、推销引流的群。

:::

## 学院官方群什么时候有？

**开学前**，学校会在**官方微信公众号**上公布各学院官方群。

- 2025 年官方群公布入口：[学校公众号推文](https://mp.weixin.qq.com/s/CVePWwdvpb6gPUc0alNMSg)
- **2026 年待入学前通知**，请留意学校官方公众号

## 怎么辨别群的真假

| 特征 | 官方群 | 推销/引流群 |
| --- | --- | --- |
| 公布渠道 | 学校官方微信公众号 | 贴吧、小红书、QQ 搜索、私聊拉人 |
| 群主/管理员 | 学院老师、辅导员、学生干部 | 不明身份，多为校外人员 |
| 群名 | 规范，如"XX学院2026级新生群" | 花哨，常带"福利""速进" |
| 主要行为 | 答疑、通知、报到指引 | 推销校园卡、驾校、电话卡、兼职 |
| 是否主动私加你 | 不会 | **会** |

::: tip 💡 一个实用办法

对群里私加你的人保持警惕，可以把对方 QQ 号/微信号发到群里让大家辨识。

:::

## 进群后要注意

1. **不要**在群里透露考生号、身份证号、银行卡号
2. **不要**轻信"代缴费""内部名额""提前选宿舍"
3. 学费缴纳**只按录取通知书里的流程**
4. 有人私加你先核实，可发到群里问

更多防骗内容见 [开学防坑](faq-antifraud)。

## 常见话术对照表

看到这些话，基本可以直接判定是引流或诈骗：

| 对方说 | 实际是什么 |
| --- | --- |
| "我是学长/学姐，帮你办校园卡更便宜" | **卖卡赚提成**，见[校园网络](../life/network) |
| "提前登记能优先选宿舍 / 选好床位" | 选床只在**[智慧迎新系统](https://yx.zua.edu.cn/)统一开放**，没有提前通道 |
| "我们有内部新生群，辅导员也在" | 官方群由学校公众号公布，不靠私拉 |
| "学费先转我，我帮你代缴" | **诈骗**。学费只走通知书里的官方流程 |
| "驾照 / 四六级 / 考研班，群里拼团特价" | 商业推销，与学校无关 |
| "加我微信，把录取通知书照片发我看看" | 采集个人信息，**别发** |
| "帮忙砍价、投票、扫码注册，送小礼品" | 收验证码、拉注册的引流套路 |
| "兼职日结，动动手指就行" | 大概率是刷单——**所有刷单都是诈骗** |

## 该关注哪些官方渠道

与其在各种群里找答案，不如盯住这几个官方出口：

| 渠道 | 用途 |
| --- | --- |
| [学校官网](https://www.zua.edu.cn/) | 权威公告、现任领导、校史 |
| [招生信息网](https://zsxxw.zua.edu.cn/) | 招生章程、计划、专业组、历年分数 |
| [智慧迎新系统](https://yx.zua.edu.cn/) | 报到流程、缴费、选床、入学手册 |
| **学校官方微信公众号** | **学院官方新生群在开学前由公众号公布** |
| 录取通知书内材料 | 报到要求、缴费方式、资助材料，**最权威的第一手** |

::: tip 💡 正确的找信息姿势

先在**录取通知书 + 迎新系统**里找，找不到再打**招办电话 0371-61916161** 问。在群里问"这是不是真的"效率最低——**回答你的那个人，可能正是卖你东西的人**。

:::

## 那要不要加非官方群

不一定要退，但要清楚加了能得到什么、不能得到什么：

- **能得**：往届同学的真实经验、课程和宿舍的一手感、找老乡找队友
- **不能得**：任何涉及缴费、录取、选宿舍、转专业的"内部消息"
- **底线**：**不加私聊、不转账、不给验证码、不发证件照**——做到这四条，基本不会出事

## 进官方群第一周该做的三件事

1. **改群昵称**，按群里格式来（一般是"专业+姓名"）——方便别人确认你是本人
2. **翻一遍群公告和历史消息**，开学要交什么、在哪儿领材料，往往早有人说过了
3. **记下辅导员的官方联系方式**，别只认群里那个"学长"

::: tip 💡 群里问什么最靠谱

问生活经验、问"你们当年怎么准备的"、问课程和宿舍——这些**问同学比问官网快**。但涉及钱、证件、录取，一律回官方渠道核实。

:::

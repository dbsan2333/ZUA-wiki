## 招新时间

**两类不一样，别搞混**（与[学生组织与社团](../affairs/club-org)一致）：

- **学生组织（学生会、青协、红十字会等）**：开学后 **9–10 月**，面向大一招新
- **社团集中招新（"百团大战"）**：**3 月下旬**，全校各社团集中亮相
- **实验室/科创团队**：时间不固定，部分在学期中或春季补招

## 加入建议

::: tip 💡 怎么选

1. **别贪多**。1–2 个足矣，太多会严重影响学业
2. **想学技术**优先找实验室、科创类（软协、机器人实验室）
3. **想锻炼组织能力**考虑学生会、青协
4. **想拓展社交**按兴趣选社团
5. 加群后先观察，**警惕收高额会费或强制消费的组织**

:::

## 先分清：社团、学生组织、实验室

这三类不是一回事，能拿到的东西也不同：

| 类型 | 招新节奏 | 特点 |
| --- | --- | --- |
| **学生社团** | 开学后集中"百团大战" | 兴趣导向，人数多，活动看社团自己安排 |
| **学生组织**（学生会、团委部门、青协、红十字会） | 开学后面向大一招新，一般有面试 | 干活为主，**职务计入第二课堂"团学履历类"** |
| **实验室 / 科创团队** | 时间不固定，部分学期中或春季补招 | 打比赛、做项目，**产出计入"科技创新类"**，最值钱 |

## 加了对第二课堂有什么用

第二课堂是**本科毕业硬要求**（须修满 5 学分 = 25 积分），见[第二课堂学分](../affairs/second-classroom)。来源：[校团字〔2022〕2号](https://tuanwei.zua.edu.cn/info/1004/2616.htm)

### 当社团干部有分（团学履历类）

| 职务 | 积分 |
| --- | --- |
| **优秀社团** 会长 / 副会长 | **5** |
| 优秀社团 部长 / 副部长 | 3 |
| 优秀社团 干事 / 委员 | 2 |
| **良好社团** 会长 / 副会长 | 4 |
| 良好社团 部长 / 副部长 | 2 |
| 良好社团 干事 / 委员 | 1 |

::: warning ⚠️ 两个坑，报之前必须知道

1. **仅担任一学期的不予加分** —— 大一秋天加入，得干满学年才算数
2. **社团分"优秀""良好"两档** —— 同样是会长，优秀社团 5 分、良好社团 4 分。**社团的年度考核评级直接影响你的分**

:::

### 做志愿服务有分（实践服务类）

志愿服务活动按级别计：**省级 5 / 校外 2 / 校级 0.8 / 院级 0.3**。寒暑假社会实践（三下乡等）：**省级 8 / 校级 6 / 院级 2**。

::: tip 💡 想要"值钱的分数"，走竞赛那条

青协、红十字会拿的是**实践服务分**（单次数额小）；实验室、科创团队带你打比赛，拿的是**科技创新分**（国家级 A 类三等奖及以上 **25 分**，一场就顶半个毕业要求）。**目的不同，选的地方就不同。**

:::

## 招新前该准备什么

| 环节 | 建议 |
| --- | --- |
| **百团大战现场** | 别第一天就冲进去交表。先逛一圈，把感兴趣的**扫码进群**，回宿舍再比较 |
| **面试**（学生组织/实验室） | 准备好"你想做什么、能投入多少时间"——问得最多的就是这个。**说真话**，报了却没时间，两边都难受 |
| **进群后** | 先潜水看几周，看这个组织**平时到底在干什么**，再决定要不要留 |
| **关于会费** | 正规学生组织不收取高额会费。**开口就要几百块、还要买装备/服装的，先问清去向** |

## 群号会变，这两件事要理解

- 上表群号来自郑航贴吧迎新群 & ZUA Wiki 维护的汇总表，**每年招新季都会变**，本页不保证当前有效
- 学校**不发布统一的社团名单**：社团每年注册、年审、增减频繁，写死了必然过时。想了解现在有哪些社团，看[校团委官网](https://tuanwei.zua.edu.cn/)与公众号、以及百团大战现场

::: warning ⚠️ 别把招新群当成组织本身

真正决定你体验的是**线下活动和带你的学长学姐**，不是群。加了群发现没人说话、只有转发通知的，退了不亏。

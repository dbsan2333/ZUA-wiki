## 竞赛组队

::: info 📌 学校有组织的竞赛

- **"郑航挑战杯"**：学校自办选拔赛，2026 年为**第二十三届**
- **"互联网+"、挑战杯**省赛国赛：由校团委组织选拔
- 各学院也有自己的科创赛事

关注[校团委通知公告](https://tuanwei.zua.edu.cn/tzgg.htm)和各学院官网。

:::

::: tip 💡 找队友的三个渠道

1. **学院科创类社团 / 实验室** —— 见[社团与部门招新群](clubs-groups)，软协、机器人科创实验室这类
2. **专业课老师 / 导师** —— 很多竞赛队是老师组队的，主动去问
3. **班级群** —— 课程大作业组队最方便

:::

::: warning ⚠️ 参赛就有第二课堂积分

国家级 A 类**参赛即 10 分**、B 类 5 分，获奖最高 25 分。这个激励很实在 —— 详见[考证与竞赛](../future/certificates)、[第二课堂学分](../affairs/second-classroom)。

:::

## 找考研搭子的注意事项

考研是长跑，**搭子中途放弃很常见**：

- 别把全部动力寄托在搭子身上
- 目标院校/专业不同也能组队（公共课一样）
- **考前 1–2 个月是弃考高峰**，提前有心理准备
- 定固定时间地点，形成习惯比靠意志力管用

::: tip 💡 别让"学习群"变成"聊天群"

最常见的失败模式：建了群，然后每天聊八卦、发表情包，一学期下来书没翻几页。

**判断标准很简单：这个群让你多学了，还是多聊了？**

:::

发现错误、内容过期或有新信息？欢迎提 [Issue](https://github.com/dbsan2333/ZUA-wiki/issues) 或 Pull Request。

:::

::: warning ⚠️ 加群防骗

找学习搭子时也会遇到骗子：**收费"保过班"、卖"内部资料"、诱导刷单兼职**都要警惕。

学校明确**不举办考研辅导班、不提供往年试题、不出售参考资料**（见[考研全流程](../future/kaoyan)）。凡是声称"郑航内部真题"的一律是诈骗。详见[电信诈骗与防骗](../health/antifraud)。

:::

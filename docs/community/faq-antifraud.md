## 校园卡：最常见的坑

::: danger ⚠️ 核心建议
**开学不用着急办校园卡。** 没有校园卡、校园网，对选课等活动没有任何影响。只能用校园网访问的，都能用 [webvpn](https://webvpn.zua.edu.cn/) 访问。
:::

### 套路一：把活动优惠算进月租

三家运营商的校园卡套餐**本质是同一个**，月租基本固定（早年 39 元/月，近年约 49 元/月），开校园网再加 10 元/月。

各家通过**叠活动**让每月实付便宜一点，还有些中介拿提成后让利一部分充你话费。

**问题在于**：活动**不在套餐内**。到期后可能需要重新换卡，之前承诺的优惠找不人兑现。

### 套路二：预存话术

> "预存 xx 元，每月扣 10 元，多少月扣清。"

玩文字游戏就是把预存的钱也算进每月月租里，显得每月消费很低，**实际这笔钱是你自己提前消费的**。

### 怎么问清楚

办卡前逐条问：

1. 什么套餐？套餐**原本月资费**多少？
2. 活动什么时候**到期**？
3. 到期后**需不需要换卡**？
4. 承诺的优惠**能否兑现、找谁兑现**？

::: tip 💡 一句话判断
只要是能开校园网的校园卡套餐，月租就是那个统一价。**过于低价的，要么是叠活动、要么是文字游戏。**
:::

## 其他常见套路

### 群里私加你的人

从群里**私自加你**的要提防。可以把对方信息发到群里让大家辨识。

### 钓鱼邮件

**学校从来不会发电子邮件。** 不要点击邮件里的链接，尤其是"通知你缴费""账号异常"之类。

### 非官方新生群

开学前学校公众号会公布各学院官方群。**在此之前各种群都是非官方的**，大部分是为卖卡、推销引流的群。

识别方法见 [新生群与官方群识别](freshman-groups)。

### 抢人头与文字游戏

开学那几天各种抢人头。给你承诺的优惠到后面可能找不到人。**等人少了、了解清楚了再办。**

## 通用防骗原则

| 原则 | 说明 |
| --- | --- |
| 不轻信"限时优惠" | 越是催得急越要冷静 |
| 不扫来源不明的码 | 二维码可能带木马或引到钓鱼站 |
| 不向个人转账 | 学费按通知书流程交，任何个人收款都可疑 |
| 不透露敏感信息 | 考生号、身份证号、银行卡号、验证码 |
| 遇到事先问官方 | 打学校官网电话，或问辅导员 |

更多骗局类型（刷单、冒充客服、校园贷）见 [电信诈骗与防骗](../health/antifraud)。

## 如果你已经上当了

1. **保留证据**：聊天记录、转账记录、对方账号
2. **立即止损**：联系运营商/银行冻结，修改密码
3. **报警**：61916110 或前往派出所
4. **告知学校**：联系辅导员，避免其他同学受害

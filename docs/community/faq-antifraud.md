## 校园卡：最常见的坑

::: warning ⚠️ 核心建议

**开学不用着急办校园卡。**，新学期的开学时间一般都会有一周的免费校园网。没有校园卡、校园网，对选课等活动没有任何影响。只能用校园网访问的，都能用 [webvpn](https://webvpn.zua.edu.cn/) 访问。

:::

### 套路一：把活动优惠算进月租

三家运营商的校园卡套餐**本质是同一个**，月租基本固定（早年 29 元/月，近年约 39 元/月），开校园网再加 10 元/月。

各家通过**叠活动**让每月实付便宜一点，还有些中介拿提成后让利一部分充你话费。

**问题在于**：活动**不在套餐内**。到期后可能需要重新换卡，之前承诺的优惠找不人兑现。

### 套路二：预存话术

> "预存 xx 元，每月扣 10 元，多少月扣清。"

玩文字游戏就是把预存的钱也算进每月月租里，显得每月消费很低，**实际这笔钱是你自己提前消费的**。

### 怎么问清楚

办卡前逐条问：

1. 什么套餐？套餐**原本月资费**多少？
2. 活动什么时候**到期**？
3. 到期后**需不需要换卡**？
4. 承诺的优惠**能否兑现、找谁兑现**？

::: tip 💡 一句话判断

只要是能开校园网的校园卡套餐，月租就是那个统一价。**过于低价的，要么是叠活动、要么是文字游戏。**

:::

## 其他常见套路

### 群里私加你的人

从群里**私自加你**的要提防。可以把对方信息发到群里让大家辨识。

### 钓鱼邮件

**学校不会用邮件通知你缴费、也不会让你点邮件里的链接改密码。** 凡是"教务系统升级请点击修改密码""奖学金到账请确认银行卡"的邮件，一律不点。

::: warning ⚠️ 别把这句理解成"学校从不发邮件"

学校有自己的邮箱系统（[mail.zua.edu.cn](https://mail.zua.edu.cn/)），正式通知也可能走邮件。**判断标准不是"有没有邮件"，而是"这封邮件要你干什么"**：要你先输账号密码、先转账、先点陌生链接的，就是钓鱼。

真要办正事，**手动输入官方网址**或用[智慧门户](https://sfrz.zua.edu.cn/)登录，别从邮件里的链接进。

:::

### 非官方新生群

开学前学校公众号会公布各学院官方群。**在此之前各种群都是非官方的**，大部分是为卖卡、推销引流的群。

识别方法见 [新生群与官方群识别](freshman-groups)。

### 抢人头与文字游戏

开学那几天各种抢人头。给你承诺的优惠到后面可能找不到人。**等人少了、了解清楚了再办。**

## 到校第一周的高发场景

这些是学长学姐反复提到的具体场景，比抽象原则好记：

| 场景 | 套路 | 正确反应 |
| --- | --- | --- |
| **宿舍上门推销** | 卖电话卡、化妆品、报纸、英语报纸订阅、"学姐帮你办" | 不开门、不办、不扫码 |
| **"帮忙看行李"** | 趁你搬东西顺手牵羊 | 行李不离眼，或先交室友再看别的 |
| **扫楼"社团/机构"** | 收个人信息、拉你进群、卖考研课 | 正规组织在**百团大战**摆摊，见[社团与部门招新群](clubs-groups) |
| **班级群/年级群里的"收费"** | 自称辅导员收材料费、体检费 | **电话或当面找辅导员核实** |
| **"提前选宿舍"** | 说交钱能选朝向、选楼层 | 选床只在**[智慧迎新系统](https://yx.zua.edu.cn/)统一开放**，见[开学前必做](../enroll/freshman-before) |
| **帮忙扫码/注册** | 送小礼品，要你的手机号和验证码 | 不给。**验证码 = 钱** |
| **兼职群** | 打字员、点赞员、刷单返利 | 全是刷单诈骗马甲，见[电信诈骗与防骗](../health/antifraud) |
| **"学长卖军训服/教材"** | 二手可以，但款式尺码要当面验 | 当面交易、别先转账 |

::: tip 💡 一条万能判据

**凡是让你先掏钱、先给验证码、先扫码登记个人信息的，一律拒绝。** 学校的正规流程从来不需要你"先付一点"。

:::

## 通用防骗原则

| 原则 | 说明 |
| --- | --- |
| 不轻信"限时优惠" | 越是催得急越要冷静 |
| 不扫来源不明的码 | 二维码可能带木马或引到钓鱼站 |
| 不向个人转账 | 学费按通知书流程交，任何个人收款都可疑 |
| 不透露敏感信息 | 考生号、身份证号、银行卡号、验证码 |
| 遇到事先问官方 | 打学校官网电话，或问辅导员 |
| **不在群里发证件照** | 录取通知书、身份证、车票都能被拼出来骗你家人 |

## 如果你已经上当了

1. **保留证据**：聊天记录、转账记录、对方账号
2. **立即止损**：联系运营商/银行冻结，修改密码
3. **报警**：**61916110**（校内 24 小时）或 **110**，前往派出所
4. **告知学校**：联系辅导员，避免其他同学受害
5. **别因为羞愧不报警**——被骗不丢人，越早报追回可能性越大

::: danger ⚠️ 小心"二次诈骗"

已经被骗之后，网上搜"怎么追回钱"遇到的"黑客""维权代理""内部解冻"，**基本都是第二波骗子**。**任何说"先交钱帮你追回"的都别信**，正规途径只有报警。详见[电信诈骗与防骗](../health/antifraud)。

:::

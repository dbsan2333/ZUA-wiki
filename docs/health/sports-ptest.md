### 预约方式

通过微信公众号「郑航体育」预约：

1. 关注公众号「郑航体育」
2. 点击右下方**场馆预约** → 开始预约
3. 选择功能馆 → 选择预约时段
4. 显示预约信息及预约二维码

::: warning ⚠️ 约满为止
体育馆在保障体育教学、训练和公务活动的前提下，**按先后顺序约满为止**。热门时段（工作日晚、周末）建议尽早约。
:::

## 体测（国家学生体质健康标准）

::: warning ⚠️ 待核实
郑航每年的体测通知、测试项目、评分标准、免测申请流程**尚未从官方页面核实**。

请通过以下渠道确认：
1. [体育部官网通知公告](https://tyjxb.zua.edu.cn/index/tzgg.htm)
2. 学院或班级通知
:::

### 通用参考（全国标准，非郑航专属）

《国家学生体质健康标准》通常测试：

| 类别 | 项目 |
| --- | --- |
| 身体形态 | 身高、体重（算 BMI） |
| 身体机能 | 肺活量 |
| 耐力 | 800m（女）/ 1000m（男） |
| 柔韧 | 坐位体前屈 |
| 力量 | 立定跳远、引体向上（男）/ 仰卧起坐（女） |

### 体测与评优的关系

截止2026年10月为止，两者并无关系，建议尽量达到及格，请以学校通知为准。

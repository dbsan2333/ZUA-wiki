## 保卫处能帮你做什么

保卫处（党委保卫部、人民武装部、国防教育中心）下设栏目包括治安管理、消防管理、政策法规、人民武装、办事流程。

几个跟学生直接相关的办事流程（均挂在保卫处[办事流程栏目](https://bwc.zua.edu.cn/bslc.htm)）：

| 事项 | 说明 |
| --- | --- |
| 非机动车业务 | 电动车登记相关（[内含附件](https://bwc.zua.edu.cn/info/1096/3485.htm)，2023-11-08） |
| 机动车业务 | 机动车进校相关（[内含附件](https://bwc.zua.edu.cn/info/1096/3481.htm)，2023-11-02） |
| 行人道闸信息录入 | [龙子湖校区行人道闸信息录入办理须知](https://bwc.zua.edu.cn/info/1096/4115.htm)（2025-09-18） |
| 监控调阅 | [郑州航院保卫处监控调阅流程](https://bwc.zua.edu.cn/info/1096/4114.htm) —— 东西丢了想查监控走这个 |
| 军训外出请假 | [军训期间学生外出请假条](https://bwc.zua.edu.cn/info/1096/3684.htm) |

::: tip 💡 东西丢了怎么查监控

流程来自[《郑州航院保卫处监控调阅流程》](https://bwc.zua.edu.cn/info/1096/4114.htm)（保卫处，2024-04-03）：

1. 填《保卫处监控调阅申请表》（保卫处领取），写清调阅事由（失物查找等）、监控点位、时间区间
2. 经**所属部门负责人签字**；涉重大突发事件或涉密信息还需分管校领导审批
3. 保卫处**治安交通科（值班班组）**审核、登记备案、安排时间
4. 按约定时间带**本人有效证件**到龙子湖校区消防控制指挥中心或保卫处监控室，由工作人员**全程陪同**调阅
5. 如需留作证据，可申请**监控备份**，经保卫处负责人审批后操作；备份一般留存**不少于 3 个月**，重大事件不少于 **1 年**

调阅时严禁私自操作设备、复制传播监控内容、篡改数据，违者通报批评直至追究责任。

**申请表附件**：[保卫处监控调阅申请表.docx](https://bwc.zua.edu.cn/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=1411299640&wbfileid=12389236)

:::

::: warning ⚠️ 学生本人能直接调阅吗

上述流程的申请人是"调阅人所属部门"，实际执行里学生一般**先报辅导员，由学院出面申请**。自己去保卫处要监控基本不受理。别为这个跟值班人员起冲突。

:::

### 宿舍用电红线

这条最容易踩，说清楚：

::: warning ⚠️ 违禁电器一律没收

在宿舍内使用**违规电器**（电热水壶、电热锅、电吹风、卷发棒等）或私自改变室内电压电路的：

- 视情节给予**警告以上处分**
- 拒不承认的，视情节给予**宿舍全体成员**相应处分
- 造成火险的，给予**记过以上处分**
- 造成火灾事故的，给予**开除学籍处分**，并赔偿全部损失，依法追究法律责任的移交司法机关

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)，依据《普通高等学校学生管理规定》《郑州航空工业管理学院学生违纪处分规定（修订）》。

:::

::: tip 💡 两个替代方案

想喝热水 → 宿舍楼有**直饮水机**和**开水房**（免费）；想吹头发 → 楼道有**公用吹风机**（0.2 元/分钟）。详见[洗浴与洗衣](../life/bath-laundry)。

:::

买插排、台灯认准 **3C 认证**、出厂证明和检验合格证。特殊情况（如医疗设备用电）可向学院申请专项用电许可。

### 暖气

- **供暖时间**：郑州市集中供暖为每年 11 月 15 日至次年 3 月 15 日，龙子湖校区根据学校寒假安排实行供暖
- **供暖范围**：1–27 号学生公寓、`01`/`02`/`03`/`05`/`07` 教学楼、南行政楼、青年教师公寓等，学生公寓采用暖气片
- **温度**：室内一般 18℃±2℃
- 暖气不热或漏水打 **0371-61911999**（来源：[后勤处联系方式](https://hqfwzgs.zua.edu.cn/lxfs1.htm)，东区报修电话）

禁止私自拆卸、遮挡暖气片或私接供暖设备。

## 电动车充电

校内充电桩**扫码或刷卡**支付，24 小时可用。按功率计价：

| 功率 | 价格 |
| --- | --- |
| 150W 以内 | 0.15 元/小时 |
| 150–300W | 0.25 元/小时 |
| 300–400W | 0.35 元/小时 |
| 400–600W | 0.5 元/小时 |
| 600–1000W | 0.75 元/小时 |
| 电动汽车服务费 | 0.45 元/小时度 |

**充电桩报修**：朱风光 13937173137

::: danger ⚠️ 安全充电五条

1. **停稳再充**：车停在指定充电区域，确保完全静止
2. **检查设备**：充电枪、线缆有无破损裂口松动，指示灯是否正常
3. **插紧**：按指引插入直至保险锁扣紧
4. **远离火源**：充电站内严禁吸烟，不使用明火
5. **人离车**：充电时尽量离开车辆

充电站**不负责车辆看管**，发生碰撞、剐蹭、丢失等请立即报警。触摸充电设备前确保双手干燥。

:::

## 教学楼与夜间自习

- 教学楼、实验楼开放时间 **06:00–22:30**
- 宿舍 **6:00 开门、23:00 关门**，周五周六及节日推迟 30 分钟
- 宿舍供电 **6:00–23:00**，周五周六顺延 30 分钟，节日全天供电

::: tip 💡 晚归怎么办

宿舍 23:00 关门是硬规矩。真有特殊情况，提前跟辅导员和公寓管理员沟通，别硬等到门口。

:::

## 实验室安全

实验楼为 `02`、`06`、`08`、`09` 号，各学院另有自己的[实验室安全管理规定](https://dzxxxy.zua.edu.cn/ywgk.htm)（如电子信息学院）。进实验室前必须遵守所在学院的安全培训和准入要求。

国家层面有教育行业标准《高等学校实验室消防安全管理规范》，各校据此制定细则。

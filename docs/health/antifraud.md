# 电信诈骗与防骗 <Badge type="tip" text="持续维护" />

刷单、冒充客服、杀猪盘、校园贷——大学生被骗的头号套路就那几种，认清了就很难中招。

::: warning ⚠️ 特别提醒

本页整理自[保卫处官网](https://bwc.zua.edu.cn/)安全教育栏目（如《大学生一堂反诈课》）与国家反诈中心公开提示，具体案件求助以警方为准！

:::

## 先记住一个号码

::: danger ⚠️ 全国反诈专线 96110

接到 **96110** 打来的电话，**一定要接**——那是反诈中心在预警：你或你的家人可能正在被骗。

下载**国家反诈中心 APP**，开启来电预警，能提前拦截大部分诈骗电话和链接。

:::

## 大学生最常中的五类骗局

### 1. 刷单返利

「动动手指日赚三百」。前几单小额返利让你尝甜头，然后大单连单，说「任务未完成不返款」——本金进去就没了。**刷单本身就是违法行为，所有刷单都是诈骗。**

### 2. 冒充客服/公检法

「你的快递丢失双倍理赔」「你涉嫌洗钱需要配合调查」——让你下载屏幕共享软件、往「安全账户」转账的，全是骗子。记住：**公检法不会电话办案，更没有"安全账户"。**

### 3. 虚假购物/游戏交易

低价代充、卖游戏账号、演唱会门票——让你脱离平台私下转账就拉黑。二手交易走官方平台，不点对方发来的链接。

### 4. 校园贷/注销校园贷

「不注销影响征信」——**凡是让你"注销校园贷"的都是诈骗**。国家从未出台过这类政策。真缺钱走正规渠道（[助学贷款](../affairs/scholarship-aid)），别碰任何非正规网贷。

### 5. 冒充熟人/老师

「我是你辅导员，急事借钱」「你儿子出车祸了」。凡是涉及转账，**当面或电话核实**，视频也可能是AI换脸。

## 校园里的新型套路

保卫处安全教育栏目每学期都会发针对高校的预警（如[《大学生一堂反诈课》](https://bwc.zua.edu.cn/info/1027/4049.htm)（2026-03-25）、[反诈宣传视频](https://bwc.zua.edu.cn/info/1027/3948.htm)，郑东新区博学路派出所也进校开过[高校反诈座谈会](https://bwc.zua.edu.cn/info/1027/3935.htm)），常见校内场景：

| 场景 | 套路 |
| --- | --- |
| 新生群 | 私加好友卖卡、推销、拉兼职群——见[开学防坑](../community/faq-antifraud) |
| 兼职群 | 刷单、打字员、点赞员，全是刷单诈骗的马甲 |
| 帮忙扫码 | 以"拉票""注册"为由收验证码——**验证码=钱，打死不给** |
| 租借银行卡/电话卡 | "躺着赚钱"实为**帮信罪**，判刑加征信黑名单，千万别碰 |
| AI换脸/拟声 | "视频里明明是你妈"——语音能克隆、脸能换，涉及转账一律打回去核实 |
| 共享屏幕 | 冒充客服教你"取消会员"，共享屏幕=把银行卡密码递过去 |

::: warning ⚠️ 钓鱼邮件也盯上了大学生

「教务系统升级，点击链接修改密码」「奖学金到账，请确认银行卡」——**学校发通知不会让你点链接输密码**。认不准就上官网（[jwc.zua.edu.cn](https://jwc.zua.edu.cn/)）手动进系统，别从邮件里的链接进。

:::

## 三个万能反问

接到可疑电话/信息，问自己三个问题：

1. **是不是要我先转账/垫付/交保证金？** —— 正规机构从不
2. **是不是叫我开屏幕共享/给验证码？** —— 正规客服从不
3. **是不是催得特别急、不许我告诉别人？** —— 制造恐慌是骗术核心

三个里中一个，挂断，打 96110 求证。

## 万一被骗了

1. **立即报警 110**，同时打学校保卫处 **61916110**（24小时）——黄金止付时间就是转账后的几十分钟，越快越可能冻结对方账户
2. **保存证据**：聊天记录、转账凭证、对方账号、通话录音
3. 联系辅导员说明情况
4. **不要因为羞愧不报警**——被骗不丢人，越早报，追回可能性越大

## 报案之外，这几件事同时做

| 要做 | 为什么 |
| --- | --- |
| **联系银行** | 冻结账户、止付、挂失卡片，问清"这笔转账能不能撤回" |
| **联系平台举报** | 微信/支付宝/银行 APP 里都有"欺诈举报"入口，能拖慢对方账户 |
| **改所有相关密码** | 密码泄露过就全改，含统一身份认证、邮箱、学号相关账号 |
| **留存所有原始凭证** | 转账记录、聊天截图、通话记录、链接、对方账号，**一条都别删** |
| **告诉辅导员** | 一是学校可能发后续提醒，二是避免同班同学接着中招 |

::: warning ⚠️ "二次诈骗"专挑已经被骗的人

网上搜"被骗了怎么追回钱"，遇到的"黑客""维权代理""内部解冻"，**几乎全是第二波骗子**——他们就等着你已经付了钱、正在到处找追回渠道这个时机。

**任何说"先交钱帮你追回"的都别信。** 唯一正规途径是报警，由警方处置。

:::

## 平时怎么把风险降下来

1. **装好国家反诈中心 APP**，开启来电预警
2. **验证码不给任何人**——包括自称老师、客服、警察的
3. **不开屏幕共享**，不管对方说什么理由
4. **不点邮件、短信里的链接**登校内系统，手动输网址或走官方入口，见[常用网站](../quick/websites)
5. **不租不借银行卡、电话卡**，这是帮信罪，判刑加征信黑名单
6. **大额转账前用原有号码打回去核实**，不是回拨对方来电
7. **别在群里发身份证、录取通知书、车票照片**——这些信息能被拼出来骗你家里人

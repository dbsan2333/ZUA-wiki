## 预约方式

1. **扫码登录**：识别心理咨询预约二维码，自动跳转登录页面
2. **账号**：学号
3. **初始密码**：`A` + 学号后六位
   > 例：学号 202220331，初始密码为 `A220331`
4. **忘记密码**：拨打办公电话或发邮件重置
5. **选咨询师/时段**：登录平台后，在主页下方选择咨询师或时间段进行预约

::: tip 💡 预约入口
咨询预约二维码公布在[学工部通知](https://xsc.zua.edu.cn/info/1012/3331.htm)页面内，也可关注学校官方公众号获取。
:::

## 常见咨询主题

- 适应问题（新环境、想家、人际疏离）
- 学业压力与焦虑
- 情绪困扰（持续低落、失眠、易怒）
- 人际关系（宿舍矛盾、社交恐惧、恋爱困扰）
- 生涯规划与自我认同
- 家庭与突发变故带来的冲击

::: tip 💡 心理咨询不是"有病"
就像感冒看医生一样，情绪"感冒"了也可以找咨询师聊聊。**主动求助是照顾自己，不是软弱。**
:::

# 心理咨询 <Badge type="tip" text="持续维护" />

心里不舒服、睡不着、学不进去、跟室友处不来——都可以去聊聊。**面向全校学生免费**，不用转介、不用先找辅导员。

::: info 📌 联系方式

- **咨询邮箱**：xljk#zua.edu.cn（发邮件时把 `#` 换成 `@`）
- **地点**：`07` 教学楼 **B405、B406、B407、B420**
- **负责部门**：[党委学生工作部 · 心理健康教育中心](https://xsc.zua.edu.cn/)

:::

来源：[党委学生工作部《2026春季学期线下心理咨询服务安排》](https://xsc.zua.edu.cn/info/1012/4314.htm)（2026-03-01 发布）

## 服务对象与时间

官方通知原文三条要点：

> - 服务时间：**本学期第一周至第十九周**
> - 心理健康教育中心**面向全校学生免费开放**
> - 心理咨询老师将遵循**保密原则**

::: tip 💡 注意"学期第 1–19 周"

服务期跟着学期走，**寒暑假不在其中**。假期在家或留校期间需要帮助，走全国心理援助热线 **12356**，见[心理危机与求助](crisis)。

:::

## 怎么预约

1. **扫码登录**：识别心理咨询预约二维码，自动跳转登录页面
2. **账号**：学号
3. **初始密码**：`A` + 学号后六位
   > 例：学号 202220331，初始密码为 `A220331`
4. **忘记密码**：拨打办公电话或发邮件重置
5. **选咨询师 / 时段**：登录后在主页下方选择咨询师或时间段进行预约

::: tip 💡 预约入口

咨询预约二维码公布在[学工部通知](https://xsc.zua.edu.cn/info/1012/4314.htm)页面内，也可关注学校官方公众号获取。建议**开学就先把二维码存到手机相册**，真要用的时候不用临时翻通知。

:::

## 第一次去，会是什么样的

很多人卡在"不知道会不会很奇怪"这一步，其实流程很平：

- **地点在 `07` 教学楼**，四个房间（B405 / B406 / B407 / B420），不是医院那种环境，**别紧张**
- 首次一般是**先聊**：说说你的情况、你想解决什么，咨询师判断适不适合做后续咨询
- **免费**，不收费，也不记入你的学籍档案
- 不想说话、不知道怎么开口都可以，**"我也不知道该怎么说"本身就是个开场**

::: warning ⚠️ 关于保密的边界

通知只写明老师遵循**保密原则**。但咨询行业普遍存在**保密例外**（如涉及自身或他人人身安全等情形）。**这属于咨询师的专业判断，本页不推测具体条款**——第一次咨询时**直接问清楚**："我们聊的内容会告诉辅导员或学院吗？"问不丢人，反而让咨询更有效。

:::

## 常见咨询主题

这些是这个中心实际受理的范围，**不用等到"很严重"才去**：

- **适应问题**：新环境、想家、人际疏离——大一最常见
- **学业压力与焦虑**：挂科、绩点、考研考公的焦虑
- **情绪困扰**：持续低落、失眠、易怒
- **人际关系**：宿舍矛盾、社交恐惧、恋爱困扰
- **生涯规划与自我认同**：不知道自己想干什么
- **家庭与突发变故**带来的冲击

## 别把"想不开"才当回事

::: tip 💡 心理咨询不是"有病"

就像感冒看医生一样，情绪"感冒"了也可以找咨询师聊聊。**主动求助是照顾自己，不是软弱。**

真正需要立刻处理的危机信号（自伤、自杀念头、伤人风险），**不要等预约**——直接走[心理危机与求助](crisis)的紧急通道。

:::

## 你的朋友不太对劲，你能做什么

| 能做 | 别做 |
| --- | --- |
| **直接问**："你最近是不是不太好？" | 别替他保守"要出事"的秘密 |
| **陪他去**约咨询、走到 `07` 教学楼 | 别自己当咨询师、别劝"想开点" |
| 有危险信号立刻联系**辅导员 / 校医院急诊 / 保卫处** | 别答应"我谁都不说" |
| 持续在场，别只问一次 | 别指责、别讲道理 |

::: danger ⚠️ 涉及安全，不能替他保密

如果朋友流露**自伤、自杀**的想法，**第一时间通知辅导员或拨打紧急电话**，不要因"他让我别说"而拖延。这时候**保住人比保住承诺重要**。完整处置见[心理危机与求助](crisis)。

:::

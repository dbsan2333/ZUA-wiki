# 附近医院 <Badge type="tip" text="持续维护" />

校医院看不了的病去哪儿、怎么走、报销需要什么手续。

::: warning ⚠️ 先看这条

学校医保实行**校医院首诊制** —— 参保学生就医应先在[校医院](hospital)就诊，因校医院条件有限确需转诊的，**由校医院办理转诊手续**。

**无转诊手续的非急诊门诊费用，个人自付。**

:::

来源：[郑州航院在校学生参加郑州市城乡居民医疗保险门诊医疗费统筹管理办法（试行）](https://xyy.zua.edu.cn/info/1022/1873.htm)、[关于参保学生校外医保定点医院门诊医疗费报销的通知](https://xyy.zua.edu.cn/info/1022/1863.htm)

## 转诊与报销流程

### 第一步：先去校医院

绝大多数小病[校医院](hospital)都能处理，而且报销比例最高（校内门诊统筹支付 **80%**，检验辅助检查 **90%**）。别嫌麻烦直接往外跑。

来源：[校医院官网 - 医院简介](https://xyy.zua.edu.cn/yygk/yyjj.htm)：校医院现有职工 **33 人**，设有**内科、外科、皮肤科、放射科、B 超室、心电图室、配镜室**等科室，可做 X 光、B 超、心电图等检查。东校区实行 **24 小时值班制**。

::: info 📌 两个来源人数不一样

[校医院官网](https://xyy.zua.edu.cn/yygk/yyjj.htm)写职工 **33 人**、科室含皮肤科/放射科/配镜室；[后勤服务指南](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)（2025-06）写 **24 人**、科室为内外科/急诊科/预防保健科/药房。官网是校医院自述且更新更全，科室以此为准；人数差异不排除统计口径不同，本页不做取舍。

:::

::: tip 💡 校医院能配眼镜

官网上有**配镜室**，这是很多人不知道的。当然能不能配、怎么收费，去之前打个电话问（0371-61912732）。

:::

### 第二步：校医院开转诊单

校医院判断需要转诊的，由医生开**转诊证明**。这是校外报销的必备材料之一。

### 第三步：去校外医保定点医院就诊

"医保定点医院"指省、市医保定点医院。郑州的三甲综合医院基本都在范围内，但**去之前先跟校医院确认是否属于定点**，别自己想当然。

### 第四步：每周四交材料

| 项目 | 说明 |
| --- | --- |
| 验收材料时间 | **每周四**上班时间（上午 8:00–12:00，下午 2:30–5:00），寒暑假及节假日除外 |
| 验收地点 | **校医院一楼 115 室** |
| 到账时间 | 三个月内，寒暑假依学校工作安排顺延 |

**要带的材料**：

- 校医院**转诊证明**，或就诊医院的**急诊证明**
- 检查报告单
- 门诊发票（原件）
- 费用清单
- 实习期间就医还需**实习证明**

::: danger ⚠️ 三个会让你白跑的规定

1. **电子发票**需打印在 A4 纸上，**一张发票一页**，切勿重复打印报销 —— 一经发现，**取消当年度门诊报销资格**
2. **当年的发票当年内完成报销，跨年不能报销**
3. 报销的钱转入在**学校财务平台绑定**的银行卡，卡号要登记准确

:::

## 能报多少

来源：[门诊医疗费统筹管理办法（试行）](https://xyy.zua.edu.cn/info/1022/1873.htm)

| 情形 | 支付比例 | 年度限额 |
| --- | --- | --- |
| 总限额 | — | **1800 元**/人 |
| 校内门诊 | 检验、辅助检查 **90%**；其他 **80%** | 900 元 |
| 校外（经转诊）门诊 | **65%** | 900 元 |
| 意外伤害门诊（不含第三方责任、工伤） | **65%** | 1000 元 |

### 这些不报

- 自杀、自残引发的医疗费
- 打架斗殴、酗酒、吸毒及其他违法犯罪违纪所致伤病
- 交通事故、他人伤害、医疗事故中由他方承担赔偿责任的部分
- 工伤（含职业病）
- **未经转诊的校外普通门诊医疗费**
- 美容、镶牙、义齿、非治疗性洗牙、保健、**疫苗**费用

### 这些能报（容易忽略）

除了校内和转诊校外，以下情况也在支付范围内：

- 校期间在郑州市正规医疗机构产生的**急诊**门诊费
- **实习期间**在实习地正规医疗机构产生的门诊、急诊费
- **寒暑假**在原籍地正规医疗机构产生的门诊、急诊费

::: tip 💡 寒暑假在家看病能报

假期在老家看病也能报，但要留齐发票、费用清单、检查报告，**返校后当年内**交到校医院，别拖到跨年。

:::

## 急诊怎么办

| 情形 | 做法 |
| --- | --- |
| 校内突发 | 打校医院急诊 **0371-61912730**（24 小时） |
| 校外突发、危及生命 | **先打 120**，同时联系辅导员 |
| 夜间校外就医 | 保留**急诊证明**，急诊费用不受转诊限制 |

::: tip 💡 急诊不用先转诊

办法里写得很清楚：参保学生在郑州市正规医疗机构产生的**急诊门诊医疗费**属于支付范围。半夜肚子疼去挂急诊，只要留好急诊证明、发票、清单，一样能报。

:::

## 能看什么

《后勤服务指南》列出的服务内容：

| 类别 | 内容 |
| --- | --- |
| **常见病诊疗** | 感冒、发烧、肠胃炎、皮肤过敏等基础疾病 |
| **急救处理** | 突发伤病的初步救治**及转诊协调** |
| **预防保健** | 健康体检、传染病防控（如**结核病筛查**）等 |
| **公共卫生** | 健康教育讲座、大学生健康档案、医保政策咨询 |
| **学生医保** | 协助办理大学生外诊治疗**门诊医保报销及转诊手续** |

服务对象面向**全校在校师生、教职工及家属**，提供日常医疗、预防保健和应急救治。

## 就诊程序

官方流程（[校医院官网](http://xyy.zua.edu.cn/)）：

```
挂号 → 到各科室就诊 → 医生诊断处理 → 药房划价 → 挂号收费室缴费 → 药房取药
```

::: tip 💡 提示

- 挂号需携带一卡通或身份证
- 缴费在挂号收费室，取药在药房，**分两处**
- 按《门诊统筹管理办法》，**身份证就是参保凭证**——忘带一卡通也能挂号报销，见[医保与转诊](insurance)

:::

## 在校医院看，还是直接去校外

这是最实用的一条。来源：《后勤服务指南》"医保政策解读"

| 情形 | 能不能报 |
| --- | --- |
| **在校医院就诊** | 纳入郑州市大学生医保后，**可享受部分费用 80% 报销** |
| **经校医院转诊后去校外** | 可报销（比例见[医保与转诊](insurance)） |
| **自己直接去校外非急诊门诊** | **不予报销，个人自付** |

::: danger ⚠️ 先在校医院首诊

学生医保实行**首诊制**：就医先在校医院首诊，校医院条件有限确需转诊的，由校医院**开具转诊单**。没有转诊手续的校外非急诊门诊费用报不了。校外门诊报销材料交在**校医院一楼 115 室（每周四上班时间）**，见[医保与转诊](insurance)。

:::

## 什么情况建议直接去校外

- 需要**专科诊疗、进一步检查、住院** → 市区三甲医院，见[附近医院](nearby-hospital)
- **夜间、门诊不开放的时段** → 东校区急诊 **61912730**（24 小时）
- **突发急重伤病** → 先拨 **120**，同时通知辅导员和保卫处 **61916110**，见[心理危机与求助](crisis)

## 新生体检

校医院每年发布本科新生、研究生与专升本新生的体检工作方案。体检通常在入学后进行，具体安排见[校医院官网通知](http://xyy.zua.edu.cn/)或班级通知。

除新生体检外，校医院还负责**大学生健康档案**建立与**传染病防控**（如结核病筛查）——这两项是每年例行工作，班级通常会通知。

## 校园就医的几条实用提醒

- 校医院在**南大门西侧 200 米**，从宿舍区走过去不近，**不舒服时叫上室友一起**
- **医保每年 10–12 月集中缴费**，错过有等待期，见[医保与转诊](insurance)
- 需要**病假诊断书**（请假用），就诊时**当场跟医生说开**，事后补很麻烦，见[请假与留校](../affairs/leave-stay)
- 校医院价格低廉，但药品种类有限，需长期用药的**建议在校外配齐**

## 就诊程序

官方流程（[校医院官网](http://xyy.zua.edu.cn/)）：

```
挂号 → 到各科室就诊 → 医生诊断处理 → 药房划价 → 挂号收费室缴费 → 药房取药
```

::: tip 💡 提示
- 挂号需携带一卡通或身份证
- 缴费在挂号收费室，取药在药房，**分两处**
:::

## 能看什么

校医院为高校基层医疗机构，主要处理：

- 常见内科疾病（感冒、发热、肠胃不适等）
- 外科小创伤处理、换药
- 常规检验（血常规、尿常规等）
- 疫苗接种与体检
- 健康教育、传染病预防、计划生育服务

## 新生体检

校医院每年发布本科新生、研究生与专升本新生的体检工作方案。体检通常在入学后进行，具体安排见[校医院官网通知](http://xyy.zua.edu.cn/)或班级通知。

## 大学生医保

校医院官网设有**社会医保**专栏，公布：

- 参保缴费通知（每年集中参保期）
- 门诊医疗费统筹管理办法
- 校外医保定点医院门诊报销流程

# 重要时间表 <Badge type="tip" text="2026年10月更新" />

本页汇总郑航本科生**全年的关键时间节点**。标注「2026 年实际」的是已确认日期，其余为**往年规律**，每年以学校通知为准。

::: warning ⚠️ 年度差异
转专业、大类分流、评奖评优等**每年时间不同**。表中"往年规律"仅供提前规划，请以当年教务处/学工部通知为准。
:::

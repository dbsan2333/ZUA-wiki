# 校园地标 <Badge type="tip" text="持续维护" />

龙子湖校区的打卡点、景观与绿化。

来源：[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)（后勤管理处，2025-06-24 发布）

## 四个官方打卡点

后勤指南里明确列了四个校园景观打卡点：

### 🛩 冯如广场

"冯如雕像"是为纪念"中国航空之父"**冯如**而命名的校园文化雕塑，广场位于学校**西南角**。中央设冯如雕像，周围点缀绿植和休闲座椅，是师生集会、活动的重要场所，也是郑航航空底色的精神地标。

### 🐯 "航威威"主题雕塑广场

**2023 年 3 月**揭幕的航空文化主题雕塑，位于**图书馆南侧**。雕塑顶端放置三枚霹雳系列空空导弹模型，寓意我国航空工业威风凛凛、威震八方。现在是毕业合影、航空主题活动的热门打卡点。

### 🌊 沁湖

位于**图书馆东侧**，在教学区与生活区之间。湖畔铺有蜿蜒步道，沿途设石凳、凉亭，是晨读、散步、交流的固定去处。

### 💧 亲水平台

沁湖边的木质栈道与廊檐，可以倚栏看书、围坐讨论。

## 校园绿化

::: info 📌 占地两个口径

[学校简介](https://www.zua.edu.cn/xxgk/xxjj.htm)说全校占地**约 2800 余亩**（含两校区），后勤指南说**龙子湖校区占地 1700 余亩**、建筑面积 101.54 万平方米。两个数不冲突，前者是全校，后者是龙子湖校区。

:::

自 2018 年起校园绿化进入大规模改造提升阶段：

| 年份 | 荣誉 |
| --- | --- |
| 2019 | 龙子湖校区被郑州市评为"**园林式绿化单位**" |
| 2020 | 获评河南省"**园林单位**" |
| 2024 | 获评"**绿色学校创建达标单位**" |

目前绿化覆盖面积已达 **65% 左右**。

道路行道树也按轴线分了品种：

| 道路 | 主要植物 |
| --- | --- |
| 南北凌云路两侧 | 孑遗植物**银杏**贯穿 |
| 东西腾飞路两侧 | 法桐、广玉兰、香樟等乔木 |
| 道路旁间植 | 碧桃、樱花、海棠、紫薇、紫荆、桂花、月季、女贞、石榴、枇杷、石楠、海桐、南天竹 |

官方的说法是形成了"春有花、夏有荫、秋有果、冬有青"的生态画卷 —— 秋天银杏道确实值得拍。

::: tip 💡 银杏季

凌云路的银杏大概 **11 月中下旬**变黄，那几周是拍照高峰。具体黄叶时间每年看天气，别照搬往年的日期。

:::

## 教学区楼栋

龙子湖校区教学楼与实验楼是**分开编号**的，找教室前先看清楚是"教学楼"还是"实验楼"：

| 楼栋 | 用途 |
| --- | --- |
| `01`、`03`、`05`、`07` 等教学楼 | 承担主要教学任务，教室数量充裕 |
| `02`、`06`、`08`、`09` 号实验楼 | 各类专业实验室 |

**开放时间**：教学楼及实验楼 06:00–22:30

**教室服务部**：0371-61910068 / 0371-61910060，办公地点在 01 教学楼 B 座二楼东侧办公室。

### 教学楼里的物业服务

教学区物业由**中建七局城市运营管理有限公司**负责。在楼里找人看马甲颜色：

| 马甲 | 是谁 | 管什么 |
| --- | --- | --- |
| 橙色马甲 / 白衬衣 | 值班员 | 在各楼值班室，有问题去值班室问，失物招领也找他们 |
| 蓝色马甲 | 保洁员 | 各楼层卫生清洁 |

报修（照明故障、水管漏水、门窗损坏、桌椅维修）可直接去值班室登记，或打 **0371-61911999**。

::: tip 💡 东西落在教室了

失物招领找**各楼宇值班员**（橙色马甲/白衬衣那位）。教室每天有人清扫，捡到东西一般会交到值班室。

:::

::: warning ⚠️ 教学楼 22:30 清场

教学楼、实验楼 **06:00–22:30** 开放，到点会清场。想熬夜复习去[图书馆](../study/library)，或者回宿舍 —— 别指望能在教学楼通宵。

:::

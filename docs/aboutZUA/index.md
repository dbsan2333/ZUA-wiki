# 学校简介 <Badge type="tip" text="2026年10月更新" />

::: info 🎉 郑航更名大学进展

- **2025年12月19日**，河南省教育厅发布《关于拟申报本科学校的公示》，拟按程序申报以郑州航空工业管理学院为基础设立**郑州航空航天大学**。
- **2026年5月25日**，河南省人民政府发布《河南省国民经济和社会发展第十五个五年规划纲要》，其中明确提到"设立河南电子科技大学、郑州航空航天大学等高校"。
- 学校已将 2026 年定为"实现更名大学目标的决胜之年"，当前处于**更名大学迎检**的关键节点。

⚠️ 截至本页更新时，教育部**尚未正式批复**，学校正式名称仍为**郑州航空工业管理学院**。

:::

郑州航空工业管理学院坐落在国家历史文化名城郑州市，地处华北平原南部，北临黄河，西依嵩山，交通便捷，是河南省唯一一所具有鲜明航空航天特色的全日制普通本科院校。

![郑航完整标识](/img/artical/学校完整标识.png)
*校徽与校名标准组合*

学校**始建于 1949 年**，与共和国同龄，时称平原省立财经学校。1964 年全国 16 所航空学校调整，更名郑州航空工业学校；1978 年升格为郑州航空工业管理专科学校；1984 年升格为郑州航空工业管理学院（本科）；1989 年获得学士学位授予权。

学校先后隶属于航空工业部、航空航天工业部、中国航空工业总公司，1999 年转为**中央与地方共建、日常管理以河南省为主**。此后几个关键节点：2008 年获批河南省硕士学位授予立项建设单位，2013 年获批硕士学位授予单位，2017 年入选国家中西部高校基础能力建设工程并于同年 12 月成为**河南省人民政府与中国民用航空局共建高校**，2020 年入选河南省特色骨干学科建设高校，2021 年获批河南省博士学位授予一般立项建设单位，2025 年获批**河南省博士学位授予重点立项培育单位**。

完整时间线见[校史与校庆](history)。

![郑航东操场](/img/artical/郑航东操场.jpeg)
*龙子湖校区东操场*

学校占地约 2800 余亩，建筑面积 102 万平方米，实验场所面积 10 万平方米；固定资产总值 26 亿元，教学科研仪器设备总值 4.2 亿元；图书馆馆藏纸质图书 246 万册、中外文数据库 31 个。

学科上，学校覆盖工、管、文、理、经、法、艺、教、交叉**九大学科门类**，下设 **19 个教学院（部）**、1 个书院、1 个中外合作办学机构（南乌拉尔学院）、1 个继续教育学院。学位点与专业的具体构成见下面的「数字速览」和「学科与专业层次」。

::: tip 💡 注：本科招生专业数量的口径

- 本节"65个本科招生专业"为学校官网**截至2025年11月**的口径。
- 2026年新增低空技术与工程、智能制造工程、智能测控工程、供应链管理 4 个专业后，[2026年招生](https://gaokao.haedu.cn/517/522/525/2026/0630/155698.html)口径为 **69个**本科招生专业。
- 两处数字均来自官方，差异源于统计时点不同。

:::

学校面向全国 **31 个省（区、市）**招生，全日制本科生、研究生、留学生 **25000 余人**；在职教职员工 **2000 余人**，其中高级职称教师 708 人、博士学位教师 703 人，有**中国工程院院士 1 人**。

![郑航航拍-西门](/img/artical/郑航航拍-西门.jpg)
*龙子湖校区西门航拍*

科研方面，学校有**省级及以上科研平台 46 个**，含国家地方联合工程研究中心 1 个、国家档案局重点实验室 1 个、省重点实验室 2 个、省实验室 1 个、省协同创新中心 3 个等；另建有**无人机研究院、低空经济研究院**等跨学科平台。逐个平台清单见[特色项目](featured)。

学校注重国际交流与合作，先后与美国、俄罗斯、英国、法国、德国、波兰、韩国、坦桑尼亚等 **30 多个国家和地区的 80 余所**高校与机构建立友好合作关系。与英国高地与群岛大学、波兰华沙人文社科大学举办本科层次中外合作办学项目，实现了中外合作办学**项目和机构全覆盖**；与坦桑尼亚多多马大学合作建立孔子学院，获"全球先进孔子学院""公共外交工作先进单位""中坦友好使者奖"等称号；建成省内首家法语联盟"**郑州法语联盟**"。

![郑航秋天](/img/artical/郑航秋天.jpg)
*校园秋景*

人才培养上，近五年在中国国际大学生创新大赛、"挑战杯"系列竞赛中获**国家级奖项 46 项、省级 450 项**；获批国家级和省级大学生创新训练计划 354 项；在数学建模、机械创新设计等单项学科竞赛中获省级及以上奖励 3000 余项。**郑航众创空间**入选国家级众创空间备案名单，学校获批河南省首批创新创业教育实践基地建设高校、省级职业技能等级认定中心。

学校还获"全国民族团结进步模范集体""全国模范职工之家""河南省文明校园""省级平安校园""河南省学分制管理示范高校""河南省国际化特色高校建设单位"等称号。

## 校训与办学理念

来源：[学校官网 · 学校标识](https://www.zua.edu.cn/dpzw.jsp?urltype=tree.TreeTempUrl&wbtreeid=1007)

| 项目 | 内容 |
| --- | --- |
| **校训** | 严谨、求实、开拓、进取 |
| **精神** | 空天报国 砺新图强 |
| **办学理念** | 德育首位、教学中心、质量至上、育人为本 |
| **行为准则** | 笃学敬业 严慎细实 |
| 学科建设思路 | 办强航空航天类工科、办精传统经管类学科，构建以航空航天工科为主、多学科协调发展 |

::: tip 💡 一句话记住郑航的底色

**河南省唯一一所具有鲜明航空航天特色的全日制普通本科院校**，同时又是从 1949 年财经学校起步、传统经管学科很强的学校——"**航空 + 管理**"两条腿走路，这是它和省内其他工科院校最不一样的地方。院系与专业分布见[学院介绍](../enroll/colleges)、[专业详解](../enroll/majors)，沿革细节见[校史与校庆](history)。

:::

## 龙子湖校区

学校主校区，位于郑州市区东北角的龙子湖大学城西边（属于金水区），紧邻东三环，不远处就是郑州东站。学校南门、东门有公交车站，北门有地铁，交通便利。

<amap style="width:100%;height:500px"/>

::: info 📌 校区规模两个口径

[学校简介](https://www.zua.edu.cn/xxgk/xxjj.htm)说全校占地**约 2800 余亩**（含各校区）、建筑面积 102 万平方米；[《后勤服务指南（学生版）》](https://hqfwzgs.zua.edu.cn/info/1174/3167.htm)说的是**龙子湖校区占地 1700 余亩**、建筑面积 101.54 万平方米、实验场所面积 8.7 万平方米。两个数不冲突：前者是全校口径，后者是单个校区口径。

:::

## 楼栋编号与功能

郑航的楼**按数字编号命名，不分"东西南北"**，认编号比认方向省事。全校区楼栋索引：

| 编号 | 类型 | 说明 |
| --- | --- | --- |
| `01`、`03`、`05`、`07` | **教学楼** | 主要教学任务，教室数量充裕、布局合理 |
| `02`、`06`、`08`、`09` | **实验楼** | 各类专业实验室，支撑实践教学与科研 |
| **图书馆** | 自习 + 馆藏 | 见[图书馆使用](../study/library) |
| **行政楼 A 楼** | 办公 | **校医院**就在南大门西侧 200 米、行政楼 A 楼，见[校医院](../health/hospital) |
| **综合楼** | 行政办事 | 教务处、学籍科、财务处等集中地，见[常用部门与电话](../quick/phones) |
| **后勤楼** | 后勤服务 | "110"综合服务中心、宿舍服务部、一楼联通营业厅 |
| **`1`–`27` 号** | **学生公寓** | 共 12 个楼组、27 栋楼，见[宿舍](../life/hostel) |

::: tip 💡 大教学楼内部再分 A / B / C 座

课表上写的"01B305"就是 **`01` 教学楼 B 座 3 楼 05 教室**。`01`/`03`/`05`/`07` 这些大教学楼都按 A、B、C 座划分——找教室先看清"几号楼 + 哪座 + 几层"。教学楼的物业、失物招领、开放时间等细节见[校园地标](landmarks)。

:::

::: warning ⚠️ 编号 ≠ 学院

`02` `06` `08` `09` 是**实验楼编号**，不是"第二学院"。各学院在哪个楼、办公电话多少，见[学院介绍](../enroll/colleges)。

:::

## 饮水与热水

龙子湖校区的饮水点分三类，按需选：

| 设施 | 分布 | 价格 |
| --- | --- | --- |
| **直饮水/热水机** | 教学区（含图书馆）共 **290 台**；宿舍区每栋每层 5 台，共 **767 台** | 直饮水 **0.24 元/升**，热水 **0.36 元/升** |
| **免费开水房** | **东苑餐厅外部西侧**、**西苑餐厅外部南侧** | **免费**，07:00–22:30 供应 |
| 直饮水开放时间 | 教学楼 07:00–22:00、图书馆 06:00–22:30、宿舍楼 06:00–次日 01:30 | — |

::: tip 💡 嫌直饮水贵就去开水房

直饮水 0.24 元/升；**开水房完全免费**，就是得走一趟。宿舍楼直饮机开到**次日凌晨 01:30**，深夜接水不用愁。详见[洗浴与洗衣](../life/bath-laundry)。

:::

## 冬季供暖范围

来源：《后勤服务指南》"学生宿舍暖气供应"

- **供暖范围**：**`1`–`27` 号学生公寓、`01`/`02`/`03`/`05`/`07` 教学楼、南行政楼、青年教师公寓**等区域，学生公寓室内采用**暖气片**
- **供暖时间**：郑州集中供暖为每年 **11 月 15 日至次年 3 月 15 日**（因天气或政策可能调整），龙子湖校区根据学校寒假安排实行供暖
- **室内温度**：一般 **18℃±2℃**

暖气不热或漏水打 **0371-61911999**，禁止私自拆卸、遮挡暖气片。详见[校园安全](../health/safety)。

## 怎么到龙子湖校区

- **地铁**：`12` 号线**龙子湖西站**，`C` 口近北门、`B` 口近东门
- **高铁**：郑州东站，地铁约 25 分钟（`12` 号线 → `8` 号线）
- 完整公交、打车、报到日交通管制路线见[交通出行](../life/transportation)

## 航空港校区

航空港校区位于郑州航空港经济综合实验区北港科创城片区（太湖路南、徐州路西、洛学路北、兖州路东），总占地面积约 **1312亩**，整体规划建设规模约 **80万㎡**，分三期建设。

- 一期工程入驻学生规模为 **5000人**，规划校舍规模 26.13万㎡。
- 建设内容包括公共教学楼、综合实验实训楼、信息与自动化学院楼组团、航空航天学院楼组团、科研综合楼、产学研及创业楼、学生宿舍、1#食堂及附属用房等。
- 一期工程于2025年10月由中建五局四公司承建的**二标段主体结构全面封顶**（三标段当时仍处基础施工阶段），2026年7月已进入**竣工冲刺阶段**，计划2026年底首批入驻。**截至2026年10月尚未启用**，2026级新生仍在龙子湖校区报到就读。

::: tip 💡 关于搬迁

据官方报道，一期 **6个学院**预计2026年底入驻、约5000名师生迁入。据郑州航空港区官方报道（[2025-01-19](https://news.qq.com/rain/a/20250119A03JXJ00)），拟入驻的学院为：**航空发动机学院、航空宇航学院、民航学院、机械工程学院、计算机学院、电子信息学院**。

具体搬迁时间与涉及专业请以学校官方通知为准。

:::

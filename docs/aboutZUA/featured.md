## 蓝天书院

来源：[学校简介](https://www.zua.edu.cn/xxgk/xxjj.htm)、[机构设置](https://www.zua.edu.cn/xxgk/jgsz.htm)

学校设 **1 个书院** —— **蓝天书院**，是学校的**直属机构**之一（与图书馆、档案馆、学报编辑部同级）。

官网：[ltsy.zua.edu.cn](http://ltsy.zua.edu.cn/)

::: info 📌 书院是干什么的

书院制是国内高校的一种学生管理模式，通常负责**通识教育、导师制、社区活动、学业指导**等，与专业学院（负责专业课教学）形成互补。

:::

::: warning ⚠️ 本页不转述书院具体制度

蓝天书院的**具体管理办法、覆盖范围（哪些年级/专业）、选拔方式**，未获取到官方文件，**不做推测**。想去书院或已被书院录取的同学，直接看[蓝天书院官网](http://ltsy.zua.edu.cn/)或问辅导员。

:::

## 南乌拉尔学院（国际学院）

来源：[学校简介](https://www.zua.edu.cn/xxgk/xxjj.htm)、[2026 年招生专业信息](https://zsxxw.zua.edu.cn/info/1032/2260.htm)、[2026 年招生专业选考科目要求](https://zsxxw.zua.edu.cn/info/1142/2253.htm)

学校设 **1 个中外合作办学机构** —— **南乌拉尔学院**，是与**俄罗斯**南乌拉尔国立大学合作的机构（学校官网"教学院部"栏目标注为"国际学院(南乌拉尔学院)"）。

::: info 📌 机构 ≠ 项目，这是两回事

学校实现了**中外合作办学"项目和机构全覆盖"**：

- **机构**：南乌拉尔学院（独立学院实体）
- **项目**：与英国高地与群岛大学、波兰华沙人文社科大学合作的本科层次项目

:::

## 无人机研究院与低空经济研究院

来源：[学校简介](https://www.zua.edu.cn/xxgk/xxjj.htm)

原文：

> 建立了**无人机研究院**、**低空经济研究院**等跨学科科研平台。

这是学校近年重点布局的方向，与**低空技术与工程**本科专业（代码 `140003`，2026 年新增，物理+化学，属计算机学院）相呼应。

::: tip 💡 低空经济是新增赛道

低空经济是国家新兴战略产业，郑航**2026 年新增"低空技术与工程"专业**，并配套建了低空经济研究院。对无人机、通航感兴趣的同学可以关注。

:::

## 创新创业中心

来源：[机构设置](https://www.zua.edu.cn/xxgk/jgsz.htm)

创新创业中心（工程实训中心）是学校直属机构，官网 [sczx.zua.edu.cn](http://sczx.zua.edu.cn/)。

学校的创新创业成绩（[学校简介](https://www.zua.edu.cn/xxgk/xxjj.htm)）：

- **郑航众创空间**入选**国家级众创空间**备案名单
- 获批河南省首批**创新创业教育实践基地**建设高校
- 获批省级**职业技能等级认定中心**
- 近五年在中国国际大学生创新大赛、"挑战杯"系列竞赛中获**国家级奖项 46 项、省级 450 项**
- 获批国家级和省级大学生创新训练计划 **354 项**

::: tip 💡 入驻众创空间有第二课堂积分

**创业项目入驻学校众创空间**：项目负责人 **6 分**、其他成员 3 分
**注册工商企业开展创业实践**：公司法人 **10 分**、其他成员 4 分

而且**休学创业**有特殊政策：**可连续申请休学 2 年，且休学时间不计入最长学习年限**。详见[考证与竞赛](../future/certificates)、[请假与留校](../affairs/leave-stay)。

:::

::: info 📌 工程实训中心 = 金工实习的地方

机械类等专业的**金工实习**通常在工程实训中心进行。军训服别扔，那会儿要穿军训外套。

:::
